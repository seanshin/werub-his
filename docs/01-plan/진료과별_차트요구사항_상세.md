# 한국형 병원 EMR 진료과별 차트 요구사항 상세 명세

## 1. 내과 (Internal Medicine)

### 1.1 차트 형식/구조

기본 SOAP에 POMR(Problem-Oriented Medical Record) 방식을 결합한다. 각 문제(Problem)별로 독립 SOAP을 작성하며, 만성질환 관리를 위한 연속 추적 차트가 추가된다.

**내과 공통 SOAP 확장 구조:**
```
[헤더] 내원유형(초진/재진), 주소(Chief Complaint), 내원경위
[S] Subjective
  ├── 현병력 (HPI): 발현시기, 양상, 지속시간, 악화/완화 요인, 동반증상
  ├── 과거력 (PMH): 질환목록, 수술력, 입원력
  ├── 가족력 (FH): 질환별 가계도
  ├── 사회력 (SH): 음주(주량/빈도), 흡연(pack-year), 직업, 운동
  ├── 복용약 (Current Medications): 처방약 + OTC + 건강기능식품
  └── ROS (Review of Systems): 14개 시스템 체크리스트
       General, HEENT, CV, Pulm, GI, GU, MSK, Neuro, Psych,
       Skin, Endo, Heme/Lymph, Allergy/Immuno, OB/GYN

[O] Objective
  ├── 바이탈 (VS): BP, HR, RR, BT, SpO2, 체중, 신장, BMI
  ├── 신체검사 (PE): 시스템별 구조화 입력
  │    General appearance, HEENT, Neck, Chest/Lung, Heart,
  │    Abdomen, Extremities, Neurological, Skin
  ├── 검사결과 (Labs): 자동 연동 (최근 결과 표시)
  └── 영상결과 (Images): 자동 연동

[A] Assessment
  ├── 진단목록 (KCD 코드 연동): Primary + Secondary
  ├── 감별진단 (Differential Dx)
  └── 임상 추론 (Clinical Reasoning)

[P] Plan
  ├── 처방 (Medications): OCS 연동
  ├── 검사 오더 (Labs/Imaging): OCS 연동
  ├── 시술/처치 (Procedures)
  ├── 상담/교육 (Counseling)
  ├── 전과/의뢰 (Referral/Consult)
  └── 다음 방문 계획 (Follow-up)
```

### 1.2 세부 전문과별 고유 필드

**순환기내과 (Cardiology)**
- 고유 필드: NYHA 기능 분류(Class I-IV), CCS 협심증 등급, LVEF(%), 심장 리듬(sinus/AF/VT 등), 인공심장박동기 정보(기종/삽입일/모드), 항응고제 관리(INR 목표, 실제치), 심전도 소견(구조화), 심초음파 요약(LVEF/chamber size/valve 등)
- 스코어링: CHA2DS2-VASc(심방세동 뇌졸중 위험), HAS-BLED(출혈 위험), TIMI Risk Score, GRACE Score, Framingham Risk Score, EuroSCORE II, HEART Score(흉통 평가)
- 주요 오더셋: ACS 초기 오더셋(ASA + 항혈소판 + 헤파린 + statin + beta-blocker + NTG), 심부전 오더셋(이뇨제 + ACEi/ARB + beta-blocker + MRA), AF 율동조절 오더셋, PCI 후 이중항혈소판요법

**호흡기내과 (Pulmonology)**
- 고유 필드: 폐기능검사(PFT) 결과표(FEV1, FVC, FEV1/FVC, DLCO, TLC), 산소요법 기록(유량, 방법, SpO2 목표), COPD GOLD 분류(Stage I-IV), 천식 조절 상태, 흉부 CT 소견(구조화), 객담 양상/양/색깔
- 스코어링: CURB-65(폐렴 중증도), PSI/PORT Score, CAT Score(COPD 평가), mMRC 호흡곤란 등급, ACT(Asthma Control Test), qSOFA(패혈증 선별)
- 주요 오더셋: 지역사회 획득 폐렴 경험적 항생제(3세대 세팔로스포린 + 마크로라이드), COPD 급성악화(전신 스테로이드 + 흡입 기관지확장제 + 항생제), 천식 급성 발작(SABA 네뷸라이저 + 전신 스테로이드)

**소화기내과 (Gastroenterology)**
- 고유 필드: 내시경 기록(검사 전 동의서, 시술 유형, 삽입/발거 시간, 세척 적절성, 소견 부위별 기록, 조직검사 부위/개수, 시술 중 합병증, 사진 연동), Child-Pugh 분류(간경변), 복수 양/성상, 식도정맥류 등급(F1-F3), 대장용종 분류(크기/형태/위치/개수)
- 스코어링: Child-Pugh Score(A/B/C), MELD Score(간이식 우선순위), Glasgow-Blatchford Score(상부위장관출혈), Rockall Score(재출혈 위험), Forrest 분류(궤양 출혈), 파리분류(표재성 종양)
- 주요 오더셋: 상부위장관출혈 초기(금식 + PPI 정주 + 수액 + 수혈 준비 + 내시경 예약), 간경변 복수 관리(저염식 + 이뇨제 + 알부민), 내시경적 점막절제술(EMR/ESD) 전후 오더

**내분비내과 (Endocrinology)**
- 고유 필드: 당뇨 관리 차트(HbA1c 트렌드, 자가혈당측정 로그, 인슐린 용량표, 저혈당 에피소드 기록, 당뇨 합병증 선별검사 일정), 갑상선 기능(TSH/fT4/fT3/항체), 골밀도(T-score/Z-score, 부위별), 부신 기능(코티솔/ACTH), BMI/체성분 분석
- 스코어링: FRAX(골절 위험 10년), 당뇨병 자가관리 평가(SDSCA), 인슐린 용량 조절 프로토콜(sliding scale), Klinefetter Index, FINDRISC(당뇨 위험)
- 주요 오더셋: 신규 당뇨 평가(HbA1c + 공복혈당 + C-peptide + 항체 + 안저검사 + 미세알부민뇨 + 지질 + 신기능), 갑상선결절 검사(TSH + 초음파 + FNAB), 골다공증 치료(비스포스포네이트 + 칼슘/비타민D)

**신장내과 (Nephrology)**
- 고유 필드: CKD 단계(G1-G5/D), eGFR 추이 그래프, 투석 기록(투석 유형/일정, 투석 전후 체중/혈압, 건체중, 혈관접근로 상태, Kt/V, URR), 수분 balance sheet, 전해질 추이표(Na/K/Ca/P/Mg), 이식 후 면역억제제 모니터링
- 스코어링: CKD-EPI eGFR, KDIGO AKI 기준, AKIN 분류, 투석 적절성(Kt/V >1.2), 이식 거부반응 Banff 분류
- 주요 오더셋: 투석 세션 오더(헤파린 + 에리스로포이에틴 + 철분 + 활성비타민D + 인결합제), AKI 초기(수액 + 전해질 보정 + 원인 검사 + 신장초음파)

**혈액종양내과 (Hematology-Oncology)**
- 고유 필드: 항암 프로토콜(레지멘명, 사이클/일, BSA, 각 약물 용량 계산, 감량 여부), 항암 반응 평가(RECIST 1.1), TNM 병기(AJCC), ECOG PS(Performance Status 0-4), 항암 부작용 등급(CTCAE v5.0), 골수검사 결과표, 수혈 기록
- 스코어링: ECOG PS(0-4), CTCAE v5.0 이상반응 등급(1-5), IPI(림프종 예후), IPSS-R(MDS 예후), Sokal/EUTOS(CML), CCI(Charlson Comorbidity Index)
- 주요 오더셋: CHOP(림프종), FOLFOX/FOLFIRI(대장암), AC-T(유방암), Cisplatin+Etoposide(폐암) 등 레지멘별 사전정의 오더, 호중구감소성 발열 경험적 항생제, 종양용해증후군 예방(수액 + allopurinol)

**감염내과 (Infectious Disease)**
- 고유 필드: 감염원/감염부위, 배양검사 결과(균명/감수성), 항생제 사용 기록(시작/종료일, 전환 이력), TDM(약물농도모니터링: vancomycin trough, aminoglycoside 등), 격리 유형(접촉/비말/공기), 법정감염병 신고 기록
- 스코어링: qSOFA, SOFA(패혈증 장기부전), Pitt Bacteremia Score, Dundee 분류(농양)
- 주요 오더셋: 패혈증 번들(1시간: 혈배양 2세트 + 광범위항생제 + 수액 30mL/kg + 젖산 + 소변량 모니터), 메티실린내성포도알균(MRSA) 경험적 치료, 면역저하자 발열 초기 오더

**류마티스내과 (Rheumatology)**
- 고유 필드: 관절 호모니큘러스(tender/swollen joint count, 28/66/68 관절), 질환 활성도, 자가항체 패널(ANA, anti-dsDNA, RF, anti-CCP, ANCA 등), 생물학적제제 투약 기록, 관절 변형 기록
- 스코어링: DAS28(질환활성도), CDAI, SDAI, HAQ-DI(기능장애), SLEDAI(루푸스 활성도), BASDAI(강직척추염), ACR/EULAR 분류기준
- 주요 오더셋: RA 초기 평가(RF + anti-CCP + ESR + CRP + X-ray hand/feet + 간/신 기능), RA 치료(MTX + 엽산 + NSAID), SLE 플레어(고용량 스테로이드 + 면역억제제)

### 1.3 내과 문서화 워크플로우

```
외래: 접수 → 대기열 → (문진표 확인) → SOAP 작성
     → 진단 입력(KCD) → 처방(약/검사/영상) → DUR 확인
     → 전자서명 → 수납 → 다음 예약

입원: 입원지시 → 입원초기평가(간호) → 입원 경과기록(매일 SOAP)
     → 다학제 회의 기록 → 퇴원 계획 → 퇴원요약
```

## 2. 외과 (General Surgery)

### 2.1 차트 형식/구조

외과는 수술 전후 3단계 문서화가 핵심이며, SOAP 외에 구조화 수술기록(Op Note)이 별도로 존재한다.

**수술 전 평가 (Pre-operative Assessment):**
```
preOpAssessment:
  ├── 수술 전 진단 (preOpDiagnosis): KCD 코드
  ├── 예정 수술명 (plannedProcedure): 수가코드 연동
  ├── 수술 적응증 (indication): String
  ├── 과거수술력 (previousSurgeries): Array
  ├── 마취 전 평가 의뢰 여부 (anesthesiaConsultRequested): Boolean
  ├── ASA 등급 (asaClass): I / II / III / IV / V / VI
  ├── Mallampati 등급 (mallampatiClass): I / II / III / IV
  ├── 금식 확인 (npoStatus): { lastMealAt, lastFluidAt }
  ├── 수술 전 검사 결과 확인:
  │    CBC, BMP, PT/aPTT, 혈액형+교차, 흉부X선, 심전도, UA
  ├── 수술 전 약물 조정:
  │    항응고제 중단일, 항혈소판제 중단일, 인슐린 조절
  ├── DVT 예방 계획 (vteProhylaxis): Boolean
  ├── 예방적 항생제 (prophylacticAbx): 약물/시기
  ├── 수술 동의서 확인 (consentVerified): Boolean
  └── 수술 전 체크리스트 (WHO Surgical Safety Checklist)
```

**구조화 수술기록 (Op Note) -- 현재 Surgery 모델 확장 필요:**
```
opNote (15개 구조화 필드):
  ├── preOpDiagnosis: String (수술 전 진단)
  ├── postOpDiagnosis: String (수술 후 진단)
  ├── procedureName: String (수술명)
  ├── procedureCode: String (EDI 수가코드)
  ├── surgeonId: UUID (집도의)
  ├── assistants: Array<UUID> (보조의)
  ├── anesthetistId: UUID (마취의)
  ├── anesthesiaType: Enum (전신/척추/경막외/국소/MAC)
  ├── incisionTime: DateTime (절개 시간)
  ├── closureTime: DateTime (봉합 시간)
  ├── findings: String (소견)
  ├── specimens: Array<{ type, site, count }> (검체)
  ├── estimatedBloodLoss: Int (추정실혈량 mL)
  ├── fluidBalance: { crystalloid, colloid, blood, urine }
  ├── implants: Array<{ name, manufacturer, lot, serial }> (삽입물)
  ├── drains: Array<{ type, site, size }> (배액관)
  ├── complications: String (합병증)
  ├── narrative: String (상세 수술 경과)
  └── postOpOrders: String (수술 후 지시)
```

**수술 후 기록 (Post-operative Note):**
```
postOpNote:
  ├── 수술 후 진단 (postOpDiagnosis)
  ├── 활력징후 (VS: 15분/30분/1시간 간격)
  ├── 의식 상태 (consciousness)
  ├── 통증 점수 (NRS 0-10)
  ├── 창상 상태 (woundStatus): 건조/삼출/출혈
  ├── 배액관 양/성상 (drainOutput): { amount, color, character }
  ├── I/O balance
  ├── PCA 사용 기록 (pcaUsage): { totalDose, requestCount, deliveredCount }
  ├── 장음 회복 (bowelSounds): 유무/시기
  ├── 보행 시작 (ambulation): 시기/거리
  ├── 식이 진행 (dietProgression): 금식→물→미음→죽→밥
  └── 합병증 모니터링 (complications):
       SSI(수술부위감염), DVT, PE, 장폐색, 출혈, 문합부누출
```

### 2.2 스코어링 도구
- ASA Physical Status Classification (I-VI)
- WHO Surgical Safety Checklist (Sign In / Time Out / Sign Out)
- Clavien-Dindo 합병증 분류 (I-V)
- NNIS Surgical Risk Index (0-3)
- Caprini DVT Risk Score
- Apgar Score for Surgery (수술 아프가)
- POSSUM / P-POSSUM (수술 사망률/이환율 예측)
- NRS (Numeric Rating Scale) 통증 평가

### 2.3 주요 오더셋
- 수술 전 오더: 금식 + 예방적 항생제(cefazolin 1-2g 절개 60분 전) + DVT 예방(LMWH/기계적) + 수술 전 검사 + 마취과 의뢰
- 수술 후 오더: 수액(LR/NS) + 진통제(PCA/IV/PO) + 예방적 항생제(24-48h) + DVT 예방 + NPO→식이진행 + 조기 보행 + 배액관 관리 + 창상 관리 + 바이탈 모니터링 빈도

## 3. 정형외과 (Orthopedics)

### 3.1 차트 형식/구조

표준 SOAP에 상세한 근골격 신체검사 기록이 추가되며, 관절별 ROM 표와 근력검사표가 핵심이다.

**정형외과 전용 Objective 섹션:**
```
orthopedicExam:
  ├── 시진 (inspection):
  │    변형, 부종, 발적, 반상출혈, 근위축, 보행 양상
  ├── 촉진 (palpation):
  │    압통 부위, 열감, 삼출, 불안정성
  ├── ROM (Range of Motion) — 관절별 테이블:
  │    ┌────────────┬──────────┬──────────┬──────────┐
  │    │ 관절/운동   │ 정상(도)  │ 환측(도)  │ 건측(도)  │
  │    ├────────────┼──────────┼──────────┼──────────┤
  │    │ 어깨 굴곡   │ 0-180    │ 0-120    │ 0-175    │
  │    │ 어깨 외전   │ 0-180    │ 0-100    │ 0-180    │
  │    │ 어깨 외회전 │ 0-90     │ 0-45     │ 0-85     │
  │    │ 어깨 내회전 │ 0-70     │ 0-30     │ 0-65     │
  │    │ 주관절 굴곡 │ 0-150    │          │          │
  │    │ 주관절 신전 │ 0        │          │          │
  │    │ 고관절 굴곡 │ 0-125    │          │          │
  │    │ 슬관절 굴곡 │ 0-135    │          │          │
  │    │ 족관절 배굴 │ 0-20     │          │          │
  │    │ 족관절 저굴 │ 0-50     │          │          │
  │    └────────────┴──────────┴──────────┴──────────┘
  ├── MMT (Manual Muscle Testing) — 관절별 근력:
  │    등급: 0(Zero) / 1(Trace) / 2(Poor) / 3(Fair) / 4(Good) / 5(Normal)
  │    기록 형식: 부위별 좌/우 구분
  ├── 특수검사 (Special Tests):
  │    어깨: Neer, Hawkins, Empty can, Speed, O'Brien, Apprehension
  │    무릎: McMurray, Lachman, Anterior/Posterior drawer, Valgus/Varus stress
  │    발목: Anterior drawer, Talar tilt, Thompson
  │    척추: SLR, FABER, Spurling
  ├── 신경혈관 검사 (NV check):
  │    감각(dermatome), 심부건반사(DTR), 맥박(dorsalis pedis/posterior tibial)
  └── 골절 분류 (Fracture Classification):
       AO/OTA 분류: [부위코드].[유형].[그룹].[하위그룹]
       예: 31-A2.1 (대퇴골 근위부 전자간 골절)
       추가 분류: Neer(상완골), Garden(대퇴경부), Weber(족관절),
                  Schatzker(경골 고평부), Gustilo-Anderson(개방골절 I-IIIC)
```

### 3.2 스코어링/분류 체계
- AO/OTA 골절 분류 체계
- Neer Classification (상완골 근위부)
- Garden Classification (대퇴 경부 I-IV)
- Gustilo-Anderson (개방 골절 I, II, IIIA, IIIB, IIIC)
- Weber/Danis-Weber (족관절 A, B, C)
- Schatzker (경골 고평부 I-VI)
- Kellgren-Lawrence (퇴행성 관절염 0-4)
- VAS/NRS 통증 평가
- DASH (상지 기능), WOMAC (고관절/슬관절), Lysholm (슬관절), ASES (어깨)
- Constant Score (어깨), Harris Hip Score

### 3.3 주요 오더셋
- 골절 초기: X-ray(해당부위 2-3방향) + 부목고정 + 진통제(NSAIDs + opioid PRN) + 부종관리(거상+냉찜질) + DVT 예방
- 인공관절치환술 후: 수액 + PCA → 경구진통제 전환 + DVT 예방(LMWH 14-35일) + 예방항생제 + 조기 재활(POD#1 보행) + 혈전표지자 모니터링
- 관절경 수술 후: 냉찜질 + NSAID + 재활 프로토콜(ROM 운동)

- Fisher Grade (CT 지주막하출혈 1-4)
- WFNS Grade (지주막하출혈)
- mRS (modified Rankin Scale, 0-6) (뇌졸중 결과)
- NIHSS (NIH Stroke Scale, 0-42)
- ICH Score (뇌출혈 사망률)
- Spetzler-Martin Grade (AVM 1-5)
- JOA Score (경추/요추 기능)
- WHO Grade (뇌종양 I-IV)

### 4.3 주요 오더셋
- 뇌졸중 급성기 오더: CT(non-contrast) → CTA → tPA(4.5시간 이내) + 항혈소판 + 고혈압 관리(labetalol/nicardipine) + 혈당 관리 + 신경학적 평가 매 1시간 + DTT

- 척추수술 후: 신경학적 검사 q2h + 진통(PCA) + 목보조기/허리보조기 + 조기보행

## 7. 소아청소년과 (Pediatrics)

```
pediatricHeader:
```

```
growthRecord:
  ├── 측정일 (measuredAt): DateTime
  ├── 연령 (ageMonths): Int (개월)
```

**발달 선별 검사:**

```
developmentalScreening:
  ├── K-DST (한국 영유아발달선별검사) -- 한국 표준

       9개월: 일어서기, 엄마아빠
```

## 9. 정신건강의학과 (Psychiatry)

### 9.1 차트 형식/구조

SOAP의 Objective가 MSE(Mental Status Exam)로 대체되며, 자살/타해 위험 평가가 필수 기록이다.

**정신과 SOAP 변형:**
```
[S] Subjective:
  ├── 주호소 (Chief Complaint): 환자 표현 그대로 인용
  ├── 현병력 (HPI): 증상 발현, 경과, 촉발요인, 이전 치료력
  ├── 과거 정신과력: 진단명, 입원력, 약물치료력, 자해/자살 시도력
  ├── 물질 사용력: 알코올(AUDIT), 약물(종류/빈도/경로/최종사용)
  ├── 법적 이력: 비자의 입원력, 법적 분쟁
  └── 발달력/가족력 (정신과 질환 가계도)

[O] → MSE (Mental Status Exam):
  ├── 외관 (Appearance):
  │    체형, 나이상응여부, 복장, 위생, 특이표식
  ├── 행동 (Behavior):
  │    정신운동활동(증가/감소/정상), 눈맞춤, 협조도,
  │    비정상운동(떨림/틱/지연운동이상)
  ├── 언어 (Speech):
  │    속도(빠름/보통/느림), 크기(큼/보통/작음),
  │    운율(단조/정상), 양(다변/보통/과묵), 유창성
  ├── 기분 (Mood): 환자 표현 인용 ("우울하다", "짜증난다")
  ├── 정동 (Affect):
  │    질(우울/불안/분노/행복/무감동), 범위(전범위/제한/둔마/평탄),
  │    기분과의 조화(조화/부조화), 적절성(적절/부적절)
  ├── 사고과정 (Thought Process):
  │    논리적, 우원증, 사고이탈, 사고차단, 사고비약,
  │    이완된연합, 음향연합, 보속증
  ├── 사고내용 (Thought Content):
  │    망상(유형: 피해/과대/관계/신체/허무/조종),
  │    강박사고, 공포, 과대감, 무가치감
  ├── 지각 (Perception):
  │    환각(환청/환시/환후/환촉/환미), 착각, 이인증, 비현실감
  ├── 인지 (Cognition):
  │    의식수준, 지남력(시간/장소/사람),
  │    주의집중(Serial 7s, spell WORLD backward),
  │    기억(즉각/최근/원격),
  │    추상적사고(속담해석), 판단력
  ├── 통찰 (Insight): 완전/부분적/없음
  ├── 판단 (Judgment): 양호/제한/불량
  └── 자살/타해 위험 평가 (SI/HI Assessment):
       ├── 자살사고 (Suicidal Ideation): 유/무
       │    구체성: 막연한 생각 / 구체적 계획 / 수단 접근성
       │    의도: 없음 / 모호 / 명확
       │    최근 시도: 유/무 (방법, 시기)
       ├── 타해사고 (Homicidal Ideation): 유/무
       │    대상, 구체적 계획 유무
       ├── 보호요인: 가족관계, 종교, 미래계획
       └── 위험수준: 저위험 / 중위험 / 고위험
            → 고위험 시 자동 알림/안전계획 필수 기록
```

### 9.2 스코어링/평가 도구

**우울/불안:**
- PHQ-9 (Patient Health Questionnaire, 우울 0-27)
- GAD-7 (Generalized Anxiety Disorder, 불안 0-21)
- BDI-II (Beck Depression Inventory, 0-63)
- BAI (Beck Anxiety Inventory, 0-63)
- Hamilton Depression Rating Scale (HAM-D, 0-52)
- Hamilton Anxiety Rating Scale (HAM-A, 0-56)
- Edinburgh Postnatal Depression Scale (EPDS, 산후우울)

**정신증:**
- PANSS (Positive and Negative Syndrome Scale, 양성/음성/일반)
- BPRS (Brief Psychiatric Rating Scale)
- CGI (Clinical Global Impression, 1-7)

**물질사용:**
- AUDIT (Alcohol Use Disorders Identification Test, 0-40)
- AUDIT-K (한국어판)
- CAGE (4문항 선별)
- DAST-10 (Drug Abuse Screening Test)

**인지:**
- MMSE-K (Korean Mini-Mental State Exam, 0-30)
- MoCA-K (Korean Montreal Cognitive Assessment, 0-30)
- CDR (Clinical Dementia Rating, 0-3)
- GDS (Global Deterioration Scale, 1-7)
- CERAD-K (한국판 치매 진단 배터리)
- KDSQ (Korean Dementia Screening Questionnaire)

**자살위험:**
- C-SSRS (Columbia Suicide Severity Rating Scale)
- SAD PERSONS Scale
- Beck Scale for Suicide Ideation (SSI)

**기타:**
- K-WAIS / K-WISC (지능검사)
- ADOS-2 (자폐 진단)
- K-CBCL (아동행동평가)
- YMRS (Young Mania Rating Scale, 조증)
- PCL-5 (PTSD Checklist)
- SCID-5 (구조화 면담)

### 9.3 주요 오더셋
- 급성 초조(acute agitation): IM haloperidol 5mg + IM lorazepam 2mg + 활력징후 모니터링 + 격리/억제 기록
- 주요우울장애 초기 치료: SSRI(escitalopram/sertraline) + PHQ-9 기준선 + 간/신기능 + TSH + 2주 추적
- 조현병 초발: 비정형 항정신병약(risperidone/olanzapine) + 기저 검사(CBC/간/신/지질/HbA1c/프로락틴/심전도) + PANSS 기준선

### 9.4 법적 특이사항
- 정신건강복지법에 따른 비자의입원 기록 (72시간 평가, 입원 적합성 심사위원회)
- 행동제한(격리/강박) 기록: 시작/종료시간, 사유, 30분 간격 모니터링, 의사 지시
- 자/타해 위험 환자 신고 의무

## 10. 안과 (Ophthalmology)

### 10.1 차트 형식/구조

SOAP 형식을 따르되, Objective가 안과 전용 검사 시리즈로 대체된다.

**안과 전용 검사 기록:**
```
ophthalmologyExam:
  ├── 시력 (Visual Acuity):
  │    ├── 나안시력: R___ / L___
  │    ├── 교정시력: R___ / L___ (안경/콘택트렌즈)

  │    └── 핀홀시력: R___ / L___
  │    표기: 소수(0.1~2.0) 또는 Snellen(20/20) 또는 LogMAR
  │    특수: FC(안전수지), HM(안전수동), LP(광각유), NLP(광각무)
  ├── 안압 (IOP, Intraocular Pressure):
  │    R___mmHg / L___mmHg
  │    측정 방법: Goldmann applanation / Non-contact / iCare
  │    측정 시간 (녹내장 환자 일중변동 기록)
  ├── 굴절검사 (Refraction):
  │    R: S___D C___D Ax___
  │    L: S___D C___D Ax___
  ├── 세극등 검사 (Slit Lamp Exam):
  │    ├── 안검 (Lids): 정상/내반/외반/종물
  │    ├── 결막 (Conjunctiva): 정상/충혈/여포/유두
  │    ├── 각막 (Cornea): 투명/혼탁/궤양/이물/내피세포수
  │    ├── 전방 (Anterior Chamber):
  │    │    깊이(정상/얕음), cell(0-4+), flare(0-4+)
  │    ├── 홍채 (Iris): 정상/후유착/신생혈관
  │    ├── 수정체 (Lens): 투명/핵경화/피질혼탁/후낭하/IOL
  │    └── 전방각 (Angle): Van Herick / Gonioscopy (Shaffer 0-4)
  ├── 안저검사 (Fundus Exam):
  │    ├── 시신경유두 (Optic Disc):
  │    │    색(창백/정상/충혈), C/D ratio (R___  L___), 변연부, 유두부종
  │    ├── 황반 (Macula): 정상/부종/드루젠/출혈/위축
  │    ├── 혈관 (Vessels): A/V ratio, 교차변화, 미세동맥류
  │    ├── 망막 (Retina): 출혈/삼출/박리/변성
  │    └── 유리체 (Vitreous): 투명/혼탁/출혈/세포
  ├── 안저촬영 (Fundus Photo): 이미지 연동
  ├── OCT (Optical Coherence Tomography):
  │    RNFL 두께, 황반두께, 망막층 분석
  ├── 시야검사 (Visual Field):
  │    MD(Mean Deviation), PSD(Pattern SD), VFI(Visual Field Index)
  │    신뢰도: FP/FN/Fixation Loss
  ├── 안구운동 (EOM): 정상/제한(방향 기재)
  ├── 동공 (Pupil): 크기, RAPD(상대구심동공장애)
  └── 색각검사 (Color Vision): Ishihara / HRR
```

### 10.2 스코어링/분류
- Snellen/LogMAR 시력 표기
- IOP 정상범위 (10-21 mmHg)
- Shaffer Angle Grading (전방각 0-4)
- LOCS III (수정체 혼탁 분류)
- Diabetic Retinopathy 분류 (NPDR mild/moderate/severe, PDR)
- AMD 분류 (Early/Intermediate/Late - dry/wet)
- Glaucoma Staging (초기/중기/말기)

### 10.3 주요 오더셋
- 백내장 수술 전: 시력 + IOL 계산(IOL Master) + 각막내피세포 + 안저검사 + 전신 평가
- 녹내장 추적: 안압 + 시야검사 + OCT RNFL + 안저촬영
- 당뇨망막병증: 형광안저촬영(FAG) + OCT + 범망막광응고 또는 항VEGF 주사
- 수술 후: 항생제 + 스테로이드 안약 + NSAID 안약 + 안대

## 12. 피부과 (Dermatology)

### 12.1 차트 형식/구조

```

  ├── 병변 기술 (Lesion Description) — 구조화 ABCDE:
  │    ├── 형태 (Morphology):

  │    │         종양(tumor)/소수포(vesicle)/수포(bulla)/농포(pustule)/
  │    │         팽진(wheal)/낭종(cyst)/반(patch)
  │    │    2차: 인설(scale)/가피(crust)/미란(erosion)/궤양(ulcer)/
  │    │         균열(fissure)/위축(atrophy)/흉터(scar)/태선화(lichenification)
  │    ├── 색깔 (Color): 홍색/자색/갈색/흑색/백색/황색/피부색
```

## 15. 응급의학과 (Emergency Medicine)

### 15.1 차트 형식/구조

응급실은 KTAS 트리아지 → 의사 진료 → 처치 → 배치(disposition)의 순서로, 시간 기반 기록이 핵심이다.

**KTAS 트리아지 기록 (현재 EmergencyVisit 모델 확장):**
```
ktasAssessment:
  ├── KTAS 1단계: 주증상 선택 (17개 대분류, 172개 소분류)
  │    대분류: 의식변화, 호흡곤란, 흉통, 복통, 두통, 외상,
  │            발열, 출혈, 중독, 알레르기, 안과, 이비인후과,
  │            비뇨생식기, 피부, 소아, 산과, 정신과
  ├── KTAS 2단계: 1차/2차 변별자(Modifier) 적용
  │    1차: 활력징후 이상, 통증 수준(NRS), 출혈, 의식수준,
  │         혈당, SpO2, 체온
  │    2차: 발병시간, 고위험 병력, 면역저하
  ├── KTAS 등급 결정: 1(소생)-5(비응급)
  │    LEVEL_1: 즉시 (0분)
  │    LEVEL_2: 긴급 (10분 이내)
  │    LEVEL_3: 응급 (30분 이내)
  │    LEVEL_4: 준응급 (60분 이내)
  │    LEVEL_5: 비응급 (120분 이내)
  ├── 재평가 (Reassessment):
  │    KTAS 1-2: 15분마다
  │    KTAS 3: 30분마다
  │    KTAS 4-5: 60분마다
  └── 소아 KTAS: 연령별 정상 바이탈 참고값 자동 적용
```

**외상 평가 (Trauma Assessment):**
```
traumaAssessment:
  ├── Primary Survey (ABCDE):
  │    A (Airway): 기도 개방성, 경추 보호
  │    B (Breathing): 호흡음, 호흡수, SpO2, 기흉/혈흉
  │    C (Circulation): 맥박, 혈압, 출혈 부위, 수액 반응
  │    D (Disability): GCS, 동공, 사지 운동
  │    E (Exposure): 전신 노출 검진, 체온 관리
  ├── Secondary Survey:
  │    ├── 두부/안면: 두피열상, 안면골절, 안구손상
  │    ├── 경부: 기관편위, 경정맥 팽창, 피하기종
  │    ├── 흉부: 흉벽 동요, 긴장성기흉, 심낭압전
  │    ├── 복부: 압통, 반발통, FAST 초음파
  │    ├── 골반: 불안정성
  │    ├── 사지: 골절, 구획증후군, 맥박
  │    ├── 신경: 상세 신경학적 검사
  │    └── 등/직장: 로그롤 검진
  ├── FAST (Focused Assessment with Sonography for Trauma):
  │    RUQ(Morrison pouch), LUQ(비장주위), 골반(방광주위), 심낭
  │    결과: 양성(액체 있음) / 음성 / 불확실
  └── 외상 체표도 (Injury Body Map):
       인체 도식에 손상 부위/유형 마킹
```

**소생술 기록 (Resuscitation Record, CPR):**
```
cprRecord:
  ├── 심정지 발견 시각
  ├── 심정지 유형: VF / pVT / PEA / Asystole
  ├── CPR 시작 시각
  ├── 제세동 (Defibrillation):
  │    각 회차: 시각, 에너지(J), 리듬 변화
  ├── 약물 투여:
  │    Epinephrine 1mg IV q3-5min
  │    Amiodarone 300mg → 150mg (shockable rhythm)
  │    기타: NaHCO3, CaCl2, MgSO4
  ├── 기도확보: 기관내삽관 시각, 튜브 크기, 깊이
  ├── ROSC (자발순환회복) 시각
  ├── 총 CPR 시간
  └── 결과: ROSC / 사망 선고(시각)
```

- KTAS (1-5, 한국형)
- GCS (3-15)
- ISS (Injury Severity Score, 외상 중증도)
- RTS (Revised Trauma Score)
- TRISS (Trauma and Injury Severity Score)
- APACHE II (ICU 전원 시)
- qSOFA (패혈증 선별)
- Wells Score (PE), Geneva Score (PE)
- HEART Score (ACS)
- Ottawa Ankle/Knee Rules (영상 필요성)
- Canadian C-spine Rule
- NEXUS Criteria (경추 CT)

### 15.3 주요 오더셋
- KTAS 1(소생): 기관삽관 + 중심정맥 + 동맥라인 + 수액 + 혈액검사(ABGA/CBC/Chem/응고/혈액형+교차) + Portable CXR + FAST + 모니터링
- ACS 의심: 심전도(10분 이내) + Troponin + DAPT(ASA+P2Y12) + 헤파린 + NTG + 심장내과 의뢰
- 뇌졸중 코드: 신경학적 검사 + CT(non-contrast, 25분 이내) + CTA + 혈액검사 + tPA 준비
- 패혈증 번들: 혈배양 2세트 + 광범위 항생제(1시간 이내) + 젖산 + 수액 30mL/kg + 소변량 모니터

```
icuDailyAssessment:
  ├── 신경계 (N): GCS, 진정수준(RASS), 섬망(CAM-ICU), 동공
  ├── 호흡기 (R): 인공호흡기 설정, P/F ratio, 이탈 준비(SBT)
  ├── 순환기 (C): 혈역학(MAP, CVP, CI), 승압제 용량, 수액 반응성
  ├── 위장관 (G): 경관영양/경구식이, 잔류량, 스트레스궤양 예방
  ├── 신장 (K): 소변량, Cr/BUN, 전해질, 투석 여부
  ├── 감염 (I): 체온, 배양결과, 항생제(일수/de-escalation), 감염표지자
  ├── 내분비 (E): 혈당 관리, 인슐린 프로토콜
  ├── 혈액 (H): Hb, PLT, PT/aPTT, DIC 선별, 수혈
  ├── 피부/창상: 욕창(Braden), 라인 삽입 부위, 드레싱
  ├── DVT 예방: 약물적/기계적
  ├── 재활: 조기 거동(early mobilization)
  ├── 가족 면담: 예후 설명, 의사결정
  └── 24시간 I/O 총계 + 체중
```

### 16.2 스코어링 도구
- APACHE II (0-71, ICU 입실 24시간)
- APACHE IV
- SOFA (Sequential Organ Failure Assessment, 0-24, 매일)
- qSOFA (Quick SOFA, 패혈증 선별)
- SAPS II / SAPS III
- RASS (Richmond Agitation-Sedation Scale, -5 ~ +4)
- CAM-ICU (Confusion Assessment Method for ICU, 섬망)
- GCS (3-15)
- CPIS (Clinical Pulmonary Infection Score)
- Murray Lung Injury Score
- ARDS Berlin Criteria (mild/moderate/severe)
- Braden Scale (욕창 위험)
- NUTRIC Score (영양 위험)

### 16.3 주요 오더셋
- ICU 입실: 모니터링(연속 심전도/SpO2/동맥라인/CVP) + 수액 + 진정(propofol/midazolam) + 진통(fentanyl/remifentanil) + 스트레스궤양 예방(PPI) + DVT 예방(enoxaparin) + 혈당 프로토콜
- 인공호흡기 이탈(Weaning): SBT 프로토콜 + 자발호흡시험 기준 + 발관 기준
- 패혈성 쇼크: 수액 30mL/kg → Norepinephrine(1st) → Vasopressin(2nd) + Hydrocortisone(불응성)

## 18. 영상의학과 (Radiology)

### 18.1 차트 형식/구조

영상의학과는 SOAP이 아닌 구조화 판독보고서(Structured Report)를 작성한다.

**표준 판독보고서 구조:**
```
radiologyReport:
  ├── 헤더:
  │    환자정보, 검사종류(modality), 검사부위, 검사일, 의뢰의
  ├── 임상정보 (Clinical Information):
  │    의뢰 사유, 관련 병력
  ├── 비교검사 (Comparison):
  │    이전 검사 일자/소견 (있을 경우)
  ├── 검사방법 (Technique):
  │    조영제 사용 유무, 프로토콜
  ├── 소견 (Findings):
  │    시스템별 또는 부위별 구조화 기술
  └── 결론/인상 (Impression):
       ├── 주요 소견 요약 (1-3줄)
       ├── 분류 등급 (해당 시)
       └── 권고 사항 (Recommendation)
```

**구조화 보고서 분류 체계:**

BI-RADS (유방 영상):
```
biRads:
  카테고리 0: 추가 영상 필요
  카테고리 1: 정상
  카테고리 2: 양성 소견
  카테고리 3: 양성 가능성 높음 (6개월 추적)
  카테고리 4: 악성 의심 (조직검사 권고)
    4A: 낮은 의심 (2-10%)
    4B: 중간 의심 (10-50%)
    4C: 높은 의심 (50-95%)
  카테고리 5: 악성 강력 의심 (≥95%)
  카테고리 6: 조직학적 확인된 악성
```

LI-RADS (간 영상):
```
liRads:
  LR-1: 확실히 양성
  LR-2: 양성 가능성 높음
  LR-3: 중간 확률 간세포암
  LR-4: 간세포암 가능성 높음
  LR-5: 확실한 간세포암
  LR-M: 간세포암 이외 악성 가능성
  LR-TIV: 종양혈관침범
  주요 소견: 동맥기 과강조, 배출(washout), 피막(capsule), 성장
```

PI-RADS (전립선 MRI):
```
piRads:
  PI-RADS 1: 매우 낮은 악성 가능성
  PI-RADS 2: 낮은 악성 가능성
  PI-RADS 3: 불확실
  PI-RADS 4: 높은 악성 가능성
  PI-RADS 5: 매우 높은 악성 가능성
  구역: 이행대(TZ) / 말초대(PZ)
  크기, 위치(Sector Map), 피막외확장, 정낭침범
```

TI-RADS (갑상선 초음파):
```
tiRads (K-TIRADS, 한국 갑상선학회 기준):
  K-TIRADS 1: 정상
  K-TIRADS 2: 양성 (낭종, 해면양)
  K-TIRADS 3: 낮은 의심
  K-TIRADS 4: 중간 의심
  K-TIRADS 5: 높은 의심
  크기, 에코, 모양, 경계, 석회화, 림프절
```

Lung-RADS (폐 CT 선별):
```
lungRads:
  1: 음성 (결절 없음 또는 양성 결절)
  2: 양성 (작은 결절, 연간 추적)
  3: 양성 가능성 높음 (6개월 추적 CT)
  4A: 의심 (3개월 CT 또는 PET)
  4B: 악성 의심 (조직검사/수술)
  4X: 추가 의심 소견
```

### 18.2 Critical Finding 알림
- 응급 소견 발견 시 의뢰의에게 즉시 전화/메시지 알림
- 알림 기록: 소견, 알림 시각, 수신자, 확인 시각

## 20. 진단검사의학과 (Laboratory Medicine)

### 20.1 차트 형식/구조

진단검사의학과는 결과 보고와 검증에 중점을 둔다.

**결과 보고 구조:**
```
labReport:
  ├── 검체 정보:
  │    검체 유형(혈액/소변/체액/조직), 채취 시각, 접수 시각,
  │    검체 상태(용혈/지질혈/황달/응고)
  ├── 검사 결과 (구조화):
  │    ┌────────────┬──────┬──────┬───────┬──────┐
  │    │ 검사항목    │ 결과  │ 단위  │ 참고범위 │ 플래그 │
  │    ├────────────┼──────┼──────┼───────┼──────┤
  │    │ WBC        │ 12.5 │ K/uL │ 4.0-10│ H    │
  │    │ Hb         │ 10.2 │ g/dL │12-16  │ L    │
  │    │ PLT        │ 250  │ K/uL │150-400│      │
  │    │ ...        │      │      │       │      │
  │    └────────────┴──────┴──────┴───────┴──────┘
  │    플래그: H(상한초과), L(하한미달), HH(위험높음), LL(위험낮음),
  │           C(Critical), A(비정상)
  │
  ├── Critical Value (위급값) 알림:
  │    ├── 위급값 목록:
  │    │    K >6.5 or <2.5 mEq/L
  │    │    Na >160 or <120 mEq/L
  │    │    Glucose >500 or <40 mg/dL
  │    │    Hb <7.0 g/dL
  │    │    PLT <20 K/uL
  │    │    INR >5.0
  │    │    Troponin I >99th percentile
  │    │    혈액배양 양성
  │    │    CSF 세포증가/배양양성
  │    ├── 알림 프로세스:
  │    │    결과 확인 → 담당의 전화 → 읽기확인(Read-back)
  │    │    기록: 알림 시각, 수신자명, 확인 시각
  │    └── 미확인 시 자동 에스컬레이션
  │
  ├── Delta Check (이전 결과 대비 변동):
  │    자동 비교, 급격한 변동 시 경고
  │
  └── 검증 (Validation):
       기기 결과 → 자동검증 규칙 → 통과 시 자동 보고
                                 → 불통과 시 수동 검증 필요
                                    (검사자 확인 + 재검사)
```

## 21. 핵의학과 (Nuclear Medicine)

### 21.1 차트 형식/구조

**핵의학 보고서:**
```
nuclearMedicineReport:
  ├── 검사 정보:
  │    방사성의약품 (radiopharmaceutical), 투여량(MBq/mCi),
  │    투여 경로, 촬영 시점(투여 후 시간)
  ├── PET/CT 보고서:
  │    ├── SUV (Standardized Uptake Value):
  │    │    SUVmax, SUVmean, SUVpeak
  │    │    각 병변별: 부위, 크기, SUVmax
  │    ├── 대사 반응 평가 (치료 후):
  │    │    PERCIST: CMR/PMR/SMD/PMD
  │    │    Deauville Score (림프종): 1-5
  │    ├── 부위별 소견:
  │    │    두경부, 흉부, 복부/골반, 근골격, 림프절
  │    └── 인상/결론 + 병기(해당 시)
  ├── 갑상선 스캔: I-131/Tc-99m, 섭취율, 결절 cold/hot/warm
  ├── 골스캔: Tc-99m MDP, 전이 의심 부위 기록
  ├── 심근관류스캔: 관류 결함 부위/정도/가역성(ischemia/scar)
  │    SRS (Summed Rest Score), SSS (Summed Stress Score),
  │    SDS (Summed Difference Score)
  └── 신장스캔: DTPA/DMSA, GFR, 각 신장 기능 비율
```

## 22. 가정의학과 (Family Medicine)

### 22.1 차트 형식/구조

**건강검진 차트 (Health Screening):**
```
healthScreeningRecord:
  ├── 국가건강검진 항목 (국민건강보험공단):
  │    ├── 일반건강검진 (2년 주기):
  │    │    신체계측(BMI, 허리둘레), 혈압,
  │    │    혈액검사(CBC, 공복혈당, AST/ALT, 총콜레스테롤, HDL, LDL, TG, Cr, eGFR),
  │    │    소변검사(단백뇨), 흉부X선, 구강검진
  │    ├── 암 검진:
  │    │    위암(40세+, 2년, 위내시경/위장조영)
  │    │    대장암(50세+, 1년 분변잠혈→양성 시 대장내시경)
  │    │    간암(40세+ 고위험, 6개월, 초음파+AFP)
  │    │    유방암(40세+ 여성, 2년, 유방촬영)
  │    │    자궁경부암(20세+ 여성, 2년, Pap smear)
  │    │    폐암(54-74세 30갑년 흡연, 2년, LDCT)
  │    ├── 영유아 건강검진 (4-72개월, 7회):
  │    │    성장발달 평가, K-DST, 시각/청각 선별
  │    └── 결과 판정: 정상A / 정상B(경계) / 질환의심 / 유질환자
  │
  ├── 생활습관 평가:
  │    ├── 음주: AUDIT-K (0-40)
  │    ├── 흡연: pack-year, 금연 상담/치료
  │    ├── 운동: 주당 빈도/강도/시간 (IPAQ)
  │    ├── 영양: 식습관 평가
  │    ├── 수면: 수면시간, PSQI (Pittsburgh Sleep Quality Index)
  │    ├── 스트레스: PHQ-9 (우울), GAD-7 (불안), PSS (인지된 스트레스)
  │    └── BMI/대사증후군 평가
  │
  ├── 만성질환 관리 (Chronic Disease Management):
  │    ├── 고혈압: 가정혈압 기록, 약물 순응도
  │    ├── 당뇨: HbA1c 추이, 자가혈당, 합병증 선별 일정
  │    ├── 이상지질혈증: 지질 추이, 10년 심혈관 위험(한국형)
  │    └── 골다공증: FRAX, DXA 추이
  │
  └── 상담/교육 기록:
       금연/절주 상담, 운동처방, 영양상담, 건강행동변화단계
       (무관심→관심→준비→실행→유지)
```

## 23. 치과 (Dentistry)

### 23.1 차트 형식/구조

치과는 SOAP과 완전히 다른 치아 차트(dental chart) 기반이다.

**치아 차트 (Dental Chart):**
```
dentalChart:
  ├── 치아 번호 (FDI Two-Digit Notation, 국제 표준):
  │    영구치: 11-18 (우상) / 21-28 (좌상) / 31-38 (좌하) / 41-48 (우하)
  │    유치: 51-55 / 61-65 / 71-75 / 81-85
  │
  ├── 각 치아별 상태 기록:
  │    ├── 현재 상태:
  │    │    건전(Sound) / 우식(Caries) / 충전(Filling) /
  │    │    크라운(Crown) / 브릿지(Bridge) / 임플란트(Implant) /
  │    │    결손(Missing) / 잔근(Root Remnant) / 동요(Mobile) /
  │    │    매복(Impacted) / 과잉(Supernumerary)
  │    ├── 우식 면 표기 (5면):
  │    │    M(근심) O(교합) D(원심) B(협측) L(설측)
  │    │    예: MOD cavity, BO filling
  │    ├── 치료 계획 마킹 (색상/기호 구분)
  │    └── 완료된 치료 마킹
  │
  ├── 치아 도식 (Tooth Diagram):
  │    32개 영구치 (또는 20개 유치) 그래픽 표시
  │    각 치아 클릭 → 상태 입력 팝업
  │    5면 표기 시각화
  │
  ├── 교합 기록: 교합 분류(Angle Class I/II/III), 개방교합, 과개교합
  │
  └── 구강 내 소견:
       잇몸 상태, 구강점막, 혀, 구개, 타액선, 턱관절(TMJ)
```

**치주 차트 (Periodontal Chart):**
```
periodontalChart:
  ├── 각 치아별 6점 측정 (근심협측/정중협측/원심협측/근심설측/정중설측/원심설측):
  │    ├── 치주낭 깊이 (PPD, Probing Pocket Depth): mm
  │    ├── 치은 퇴축 (Gingival Recession): mm
  │    ├── 임상부착수준 (CAL, Clinical Attachment Level): mm (자동 계산)
  │    └── 출혈 (BOP, Bleeding on Probing): 유/무
  │
  │    ┌──────┬───┬───┬───┬───┬───┬───┬───┬───┐
  │    │ 치아  │ 18│ 17│ 16│ 15│ 14│ 13│ 12│ 11│
  │    ├──────┼───┼───┼───┼───┼───┼───┼───┼───┤
  │    │ PPD B│3/2/3│3/3/3│4/3/5│...                 │
  │    │ PPD L│3/2/3│3/3/3│5/4/6│...                 │
  │    │ REC B│0/0/0│0/0/1│1/0/2│...                 │
  │    │ BOP  │-/-/-│-/-/-│+/-/+│...                 │
  │    │ 동요도│  0  │  0  │  I  │...                 │
  │    │ 분기부│  -- │  -- │  II │...                 │
  │    └──────┴───┴───┴───┴───┴───┴───┴───┴───┘
  │
  ├── 치아 동요도 (Mobility): 0 / I / II / III
  ├── 분기부 병변 (Furcation): I / II / III
  ├── 치주 분류: Stage I-IV, Grade A-C (2017 신분류)
  └── 방사선 소견: 골소실 유형(수평/수직), 정도(%)
```

### 23.2 스코어링
- DMFT (Decayed-Missing-Filled Teeth) Index
- PSR (Periodontal Screening and Recording)
- Periodontal Stage (I-IV) / Grade (A-C)
- Miller Classification (치은퇴축 I-IV)
- Endodontic PAI (Periapical Index)

## Hospital RUN 기존 모델과의 매핑 요약

현재 시스템에 이미 구현된 모델과 추가 필요한 부분:

| 진료과 | 기존 모델 활용 | 추가 필요 모델/필드 |
|--------|-------------|------------------|
| 내과 | Encounter(SOAP), Prescription, DiagnosisCode, FormSchema | ROS 체크리스트 템플릿, 스코어링 폼, POMR 연계 |
| 외과 | Surgery(확장 필요) | Op Note 15필드 구조화, 수술 전/후 체크리스트 |
| 정형외과 | Encounter | ROM 테이블 모델, MMT 테이블, 골절분류 코드 |
| 신경외과 | Encounter, EmergencyVisit | 신경학적 평가 구조화 모델, GCS 시리얼 기록 |
| 소아과 | Patient, FormSchema | GrowthRecord, VaccinationRecord, 발달선별 폼 |
| 산부인과 | - | PrenatalRecord(연속격자), LaborRecord, Partogram |
| 정신과 | EncounterTemplate(MSE) | MSE 구조화 모델, 척도검사 기록, 격리/강박 기록 |
| 안과 | Encounter | 안과 검사 구조화 (시력/안압/세극등/안저), OCT/시야 데이터 |
| 이비인후과 | Encounter | 청력검사표(PTA), 내시경 소견 구조화 |
| 피부과 | Encounter | 병변기술 구조화, 바디맵, PASI/SCORAD 계산기 |
| 비뇨의학과 | Encounter | IPSS 폼, 요류측정 데이터, PSA 추적 |
| 재활의학과 | Encounter | FIM/MBI 평가표, ROM 테이블, 치료처방 |
| 응급의학과 | EmergencyVisit(확장) | KTAS 172 주증상 마스터, 외상평가, CPR 기록 |
| ICU | Admission, IntakeOutput | FlowsheetEntry(시간축), 인공호흡기기록, SOFA 자동계산 |
| 마취과 | Surgery | PreAnestheticAssessment, AnesthesiaRecord(시간축) |
| 영상의학과 | ImagingResult(확장) | 구조화 판독(BI-RADS 등), 위급값 알림 |
| 병리과 | - | PathologyReport, SynopticReport(CAP) |
| 진단검사의학과 | LabResult, LabResultItem | CriticalValue 알림, DeltaCheck, 자동검증 |
| 핵의학과 | ImagingResult | SUV 보고서, PET 반응평가 |
| 가정의학과 | Encounter, FormSchema | 건강검진 스케줄/결과, 생활습관 평가 |
| 치과 | - | DentalChart(치아별 상태), PeriodontalChart(6점 측정) |

구현 우선순위는 기존 `docs/01-plan/의료차트_비교분석_기획서.md` 문서의 우선순위 매트릭스와 일치시키되, 각 진료과에서 FormEngine(FormSchema + FormSubmission)과 EncounterTemplate을 최대한 활용하여 점진적으로 구조화하는 전략이 권장된다. 범용 스코어링 도구(PHQ-9, GAD-7, IPSS, FIM 등)는 FormSchema로 정의하고, 진료과별 복합 차트(ICU 플로우시트, 마취기록, 산전기록, 치과차트)는 별도 모델이 필요하다.
