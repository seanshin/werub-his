# 경영성과 벤치마크(의료기관 회계정보공시 손익) — 기획·결과

> 2026-09-28 · 사용자 요청: "github.com/TAEJIN-AHN/Hospital-Profit-Visualization 통합상황판과 대시보드에 관련 내용들 학습해서 추가"

## 1. 학습한 것(외부 공개 프로젝트)

- 주제: 국내 (상급)종합병원 경영성과 태블로 대시보드. 자료는 한국보건산업진흥원 **의료기관 회계정보공시**(haspa.khidi.or.kr) 손익계산서 2019~2021(842 기관·연도).
- 분석 틀 4가지:
  1. 지역(시도·시군구) 내 병원 간 의료이익 비교(지도·원 크기/색)
  2. 의료수익경상이익률의 동급 평균 비교(연구 수익 등 의료외 손익 반영)
  3. 연도별 의료이익률 추이(0 기준 색·절댓값 두께)
  4. 의료수익 대비 인건비·재료비·관리운영비의 동급 평균 편차(높으면 적색)
- 정제 요령: 기관명·주소의 연도별 불일치를 최신 기준으로 통일 · 세목 제외 상위 계정 ~50개 · 지오코딩 실패(0,0) 주소 교정.
- 🔴 **데이터 파일은 복사하지 않았다** — 저장소에 라이선스 표기가 없다. 원자료는 공공 공시이므로 관리자가 내려받아 가져온다.

## 2. 실측(이 저장소)

- HIS 에는 손익계산서가 없다 — `executive` 는 수납 금액만, 원가(`cost-analysis`)는 배부 0행, 인건비·재료비는 ERP/회계 몫.
- 동급 비교는 전부 "미등재 → 표시 안 함"(QI·만족도·KONIS) · 병원 종별·병상 설정 키 없음.
- 원 데이터 검산(스크래치 · 로컬 DB 전용): 842행 전부 공시 항등식 성립(의료수익−의료비용=의료이익 · 비용 4항목 합 · 법인세차감전순이익) ·
  🔴 종합병원 2020 의료이익률 **평균 −15.0% · 중앙값 −3.7%**(극단값) → 평균만 보이면 동급 기준이 왜곡된다.

## 3. 만든 것

- 정본 `packages/shared/src/hospital-finance.ts` — 계정(`FINANCE_ACCOUNTS`)·공시 열 매핑·지표 6(분모=의료수익 · 없으면 null)·`peerStat`(평균·중앙값·사분위·n)·`peerDeviation`(**중앙값 기준** · 비용은 높을수록/이익은 낮을수록 나쁨)·항등식 검증·CSV 파서(의존성 없음).
- 수치 정책 `percentPoint`(%p)·`moneyEok`(억원 표시).
- 모델 `FinanceDisclosure`(기관·연도 unique)·`FinanceDisclosureImport`(이력·거절 사유) · 마이그레이션 `20260928000005_finance_disclosures`(추가만).
- API `api/v1/finance-benchmark` — `overview`·`institutions`·`trend`·`imports`(GET · ADMIN·EXECUTIVE) · `POST imports`(ADMIN · CSV UTF-8 · 항등식·숫자·중복·키 검증 후 upsert).
- 설정 `finance.benchmark.selfInstitution` — 공시 기관명으로 "우리 병원" 지정(미설정=NOT_SET · 미존재=NOT_FOUND · 비교하지 않고 그렇게 말한다).
- 화면 `/executive/finance-benchmark`(3002 · 경영진 메뉴) — 동급 분포표 · ① 지역 버블 지도+목록 · ② 경상이익률 분포 위치(사분위 띠·중앙값·평균) · ③ 추이(부호 색·두께·동급 중앙값 점선) · ④ 비용 구조 편차(적색=개선 검토 대상·판정 아님) · 가져오기(관리자).
- 요약 카드 — 대시보드 위젯 `finance-benchmark`(경영진 기본 배치) · 통합 상황판 하단(ADMIN·EXECUTIVE).
