## 1. 현재 접수 워크플로우 (문제점)

```
접수 직원이 수동으로:
1. 환자명/MRN 입력 → 검색 → 결과 확인
2. 신규 환자면 → 별도 환자 등록 페이지로 이동 → 입력 → 돌아와서 접수
3. 진료과 선택 → 의사 선택 → 접수 유형 선택 → 접수 사유 입력
→ 5~7단계, 신규 환자 시 10분+
```

## 2. AI 접수 어시스턴트 (목표)

```
접수 직원이 AI CLI에 자연어 입력:
"김영수 1958년생 고혈압 재진"

AI가 자동으로:
1. "김영수" 검색 → 기존 환자 매칭 (MRN: P2026-0001, 68세 남)
2. 고혈압 → 내과 자동 추천
3. "재진" → 접수 유형 자동 설정
4. 접수 폼 자동 채움 → 직원은 [확인] 클릭만

"홍지은 1995년 여자 두통 초진"

AI가 자동으로:
1. "홍지은" 검색 → 미등록 환자
2. "신규 등록이 필요합니다. 기본 정보를 입력해 주세요."
3. 이름: 홍지은, 생년: 1995, 성별: 여 → 자동 채움
4. 두통 → 내과/신경과 추천
5. "초진" → 접수 유형 자동 설정
→ 1단계, 30초
```

## 3. AI CLI 명령어

### 3.1 접수 전용 슬래시 커맨드

| 명령어 | 기능 | 예시 |
|--------|------|------|
| `/접수` | 통합 접수 (검색+등록+접수) | `/접수 김영수 고혈압 재진` |
| `/검색` | 환자 검색 | `/검색 김영수` 또는 `/검색 P2026-0001` |
| `/등록` | 신규 환자 등록 | `/등록 홍지은 1995-03-15 여 010-1234-5678` |
| `/추천` | 증상 → 진료과 추천 | `/추천 두통 어지러움 구토` |
| `/대기` | 현재 대기 현황 | `/대기` 또는 `/대기 내과` |

### 3.2 자연어 입력 (슬래시 없이)

```
직원: "김영수 고혈압 재진"
AI: 🔍 환자 검색: 김영수
    ✅ 기존 환자 발견
    ├── MRN: P2026-0001
    ├── 68세 남 | 국민건강보험 | 혈액형 A+
    ├── 알레르기: 페니실린, 땅콩
    ├── 문제목록: 고혈압(만성), 당뇨(만성)
    └── 마지막 진료: 2026-05-07 김내과 선생님

    📋 접수 자동 설정:
    ├── 진료과: 내과 (순환기) ← 고혈압 기반
    ├── 담당의: 김내과 ← 이전 담당의
    ├── 접수 유형: 재진
    └── 접수 사유: 고혈압 재진

    [접수 완료] [수정 후 접수] [취소]
```

```
직원: "홍지은 1995년 여자 두통"
AI: 🔍 환자 검색: 홍지은
    ❌ 등록된 환자가 없습니다.

    📝 신규 환자 등록:
    ├── 성: 홍 | 이름: 지은
    ├── 생년월일: 1995-__-__ (월/일을 입력해주세요)
    ├── 성별: 여

    └── 전화: ___

    🏥 진료과 추천 (증상: 두통):
    ├── 1순위: 내과 (일반 두통)
    ├── 2순위: 신경과 (만성/편두통)
    └── 3순위: 이비인후과 (부비동 두통)

```

