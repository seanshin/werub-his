## 1. 설계서를 어떻게 읽었는가

설계서의 중심 주장은 반직관적이고, 근거가 강하다.

> **환자안전에서 AI 가 기여할 지점은 "새 경보를 만드는 것"이 아니라
> "이미 발생한 정보가 사람에게 도달하고 조치되었는지를 끝까지 추적하는 것"이다.**

DDI 경보 override 율 90%, 8개 연구 메타분석에서 환자 결과 개선 없음, hard stop RCT 는 **IRB 가 조기 중단**.
반면 효과가 입증된 것은 전부 **"프로세스를 구조화하고 누락을 막는" 개입**이다(CPOE pADE RR 0.47 ·
바코드 투약 41.4%↓ · 추적 자동화로 폐암 조기진단 72% vs 55%).

이 방향은 이 저장소가 축적한 판정 규칙과 정확히 같은 것을 말한다 —
**"표본 부재의 정답은 폴백이 아니다"**, **"거짓 경보는 진짜 경보를 죽인다"**, **"전송을 흉내내지 않는다"**.
그래서 설계서를 **외부 방법론이 아니라 이 저장소 규약의 확장**으로 받는다.

### 1.1 그대로 받지 않는 지점 3가지

설계서는 훌륭하지만 **이 저장소가 이미 배운 것 하나가 빠져 있다.**

| # | 설계서의 전제 | 이 저장소의 실측 |
|---|---|---|
| **A** | §11 의 지표(루프 완결률·override율·NNE)는 **기능이 작동 중임을 전제**한다 | 🔴 이 저장소에서 **개통 이래 한 번도 작동한 적 없던 기능이 6종** 나왔고, 그중 일부는 단위 테스트가 초록이었다(목이라서). **루프 완결률의 분모가 0이면 완결률은 100%가 된다.** → **§11.5 로 "작동 여부 자체를 재는 층"을 추가한다**(아래 §6.1) |
| **B** | §5.4 경보 예산제는 **현행 경보 실태를 baseline 으로** 삼는다 | 🔴 이 저장소의 `GateViolationLog` 는 **전체 1행**이다. 탐지기가 죽어 있으면 위반이 기록될 수 없다 — **baseline 자체가 없다.** 예산을 정하기 전에 **탐지기가 살아 있는지부터** 재야 한다 |
| **C** | §5.3.6 I-PASS 의 **I(중증도)·S(수신자 복창)는 사람 전용** | 🔴 이 저장소의 죽은 인계 패널이 **AI 로 I 와 Synthesis 까지 생성**하려 한다(`workstation/nursing`). 설계서와 정면 충돌하며, 그 패널은 저장 버튼조차 없다 |

**결론**: 설계서의 지표 체계 위에 **"이 탐지기는 살아 있는가"를 먼저 묻는 층**을 얹는다.
이 저장소의 규약으로 옮기면 — **안전 화면의 초록은 분모를 묻는다** · **가드는 결함을 재주입해 실패해야 가드다**.

## 2. 🔴 최상위 분기 — 적법성 논리가 두 개다

설계서의 4대 제약 1번은 **폐쇄망(외부 반출 금지)** 이고, §2.3 은 1단계에서 외부 게이트웨이를
**아예 만들지 않을 것**을 권한다("없으면 외부 반출 0%를 구조적으로 증명할 수 있다").

그런데 이 저장소는 **다른 논리로 적법성을 확보해 두었다**:

| 논리 | 근거 문서 | 현 상태 |
|---|---|---|
| **A. 폐쇄망**(설계서) | `docs/05-reference/ARCHITECTURE-INVARIANTS.md` **INV-PHI-03(BLOCKER)** — "임상 콘텐츠는 경계를 벗어나지 않는다" | 🔴 **FAIL**(`architecture-invariants-audit-20260715.analysis.md`). 2026-07-15 판정이 오늘도 유효 |
| **B. 위탁 + 비저장 확인**(현행) | `docs/01-plan/references/ai-processor-phi-nonstorage.md`(2026-06-10) — WeRU.B PHI 비저장 확인서 수령·RAG 테넌트 격리·기존 저장분 파기 | 운영 중 |

🔴 **두 논리는 양립하지 않는다.** A 를 택하면 원내 GPU 도입과 전면 이관이고, B 를 택하면
INV-PHI-03 을 **개정**해야 한다(규범을 위반한 채로 두는 것이 가장 나쁘다).

**이 결정이 §5·§8·§9 전부의 선행 조건이다.** 결정 전까지는 아래만 진행한다:
- 외부로 나가는 것을 **줄이고 정직하게 기록**(2026-08-18 일부 회수 — §9)
- **목적지 변경 봉쇄**(`ai.server.url` 보호 — 회수 완료)
- 어느 쪽을 택하든 필요한 것(스코프 등급·자율성 등급·감사·루프 추적)

### 2.1 결정에 필요한 사실

- 이 저장소는 **오픈웨이트 전용**이다(OpenAI/Anthropic/Gemini 호출 **0건**). 모델 라이선스 장벽이 없다
- 원내 GPU **0장**(운영서버 `lspci`=QEMU VGA), `pgvector` **미설치**, 벡터 컬럼 0
- `ai.server.url` 소비자가 **9곳** — 목적지를 한 번 바꾸면 9개 경로가 따라간다
- 선행 문서 `docs/01-plan/features/tier-split-appliance.plan.md` 의 **사람 결정 #2("GPU 원내 포함 vs 수탁 유지")가 2026-07-15부터 미결**이다. 🔴 **이 계획서는 그 결정을 다시 묻는 문서가 아니라, 그 결정이 무엇을 막고 있는지 보이는 문서다**

## 3. 🔴 규제 포지션 — S4 가 이미 25개 가동 중이다

설계서 §3.2 는 기능을 S1~S4 로 나누고 **S4(EMR 을 분석해 새 위험도·진단·치료계획·예후를 산출)는
의료기기 해당**으로 본다. 그리고 §1.2(R18)이 결정적이다:

> 미국 Cures Act 의 CDS 면제 조항이 **한국에는 없다.**
> **"의사가 최종 판단하니까 의료기기가 아니다"는 통하지 않는다.** 판단은 표방된 사용목적(intended use)으로 한다.
> 뷰노 딥카스는 의사가 최종 판단함에도 **2등급 의료기기로 허가**받았다.

## 4. 격차표 — 설계서 요구 vs 현행

판정: **있음 / 부분 / 없음 / 🔴있는데 죽어 있음**.
🔴 **"있는데 죽어 있음"이 가장 중요하다** — 있다고 착각하면 계획이 그 자리를 비워 둔다.
`✅2026-08-18` = 오늘 회수 완료(§9).

### 4.1 §5.3.1 검사결과 클로즈드루프

| 요구 | 현행 | 판정 |
|---|---|---|
| 5단계 상태기계(DETECTED→NOTIFIED→ACK→ACTED→CLOSED) | `status` 가 **`PENDING`/`ACKNOWLEDGED` 2상태뿐**. ESCALATED·CLOSED 없음 | 없음 |
| 통보 = 책임 개인 | 맞다(주치의 폴백) | 있음 |
| 담당의 부재 시 승계 | 없음. `doctorId` 미상이면 `warn` 후 return 하는데 레코드는 `doctor_id=NULL` 로 남고 미확인 목록은 `where{doctorId:userId}` → **누구에게도 안 보이는 고아 경보** | 없음 |
| 통보 시각의 진실성 | `notified_at @default(now())` = **탐지 시각을 통보 시각으로 원장에 박는다.** 실제 발송은 fire-and-forget | 🔴있는데 죽어 있음 |
| **read-back 복창** | BE `readBack ?? true` · FE 배너가 체크박스 없이 `{readBack:true}` 하드코딩 → 지표 `readBackMissing` 이 **구조적으로 영원히 0** | 🔴있는데 죽어 있음 |

| ESCALATED 크론 | 저장소 크론 전체에 참조 **0** | 없음 |
| 워크리스트에서 루프를 닫을 수 있나 | 🔴 **불가.** 표에 확인 버튼이 없고 확인은 배너에서 담당의 본인만 — **감시자는 보되 못 고치고, 담당의 부재면 아무도 못 본다** | 🔴있는데 죽어 있음 |
| 지표 3종(완결률·확인소요·에스컬레이션율) | 전부 미산출 | 없음 |

시드가 탐지 경로를 우회해 INSERT 했고, 화면은 그 6건에 대해 **"미보고 위험값 없음 ✓" 초록**으로 거짓말한다.

### 6.1 §11.5 — "이 탐지기는 살아 있는가" 층 (신설)

설계서 §11 의 모든 지표 위에 **선행 질문**을 둔다.

| 검사 | 방법 |
|---|---|
| **쓰기 경로가 열려 있는가** | 화면 페이로드를 **실제 ValidationPipe 에 태워** 확인. 목(mock) 테스트는 증거가 아니다 |
| **탐지 모집단이 0이 아닌가** | 게이트·경보·지표마다 **분모를 함께 낸다**. 0이면 "위반 없음"이 아니라 **"평가된 적 없음"**(안전 게이트 승격 가이드가 이미 이 방식이다 — 확장한다) |
| **가드가 결함을 재주입하면 실패하는가** | 🔴 이 저장소에서 **가드가 다른 이유로 통과한 사례가 누적 15건 이상**이다. 재주입 역검증이 유일한 증거 |
| **시점이 갈라지지 않았는가** | `scripts/data-freshness.mjs`(2026-08-18 신설) — 축별 지연·인과쌍·미래·역전. 설계서 다음 액션 #5(루프 완결률 baseline)의 도구 기반이 된다 |

### 6.2 판정 규칙의 이식

설계서 §5.6(AI 자체가 환자안전 위험)은 이 저장소의 **P1·P15·P16·P17** 과 같은 것을 말한다.
