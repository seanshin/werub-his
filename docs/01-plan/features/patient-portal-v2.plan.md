## 1. 현재 구현 상태

### 1.1 환자 포털 (/portal)

**인증:**
- MRN + 생년월일 로그인
- SMS 인증 + 회원가입 + PIN 로그인
- JWT 세션

**탭 10개 (1,664줄):**
| 탭 | 기능 | 상태 |
|---|------|------|
| 홈 | 알림/공지 요약 | ✅ |
| 예약 | 예약 목록/취소/변경 | ✅ |
| 진료이력 | SOAP 기록 조회 | ✅ |
| 문진/동의 | 문진표 제출 + 동의서 서명 | ✅ |
| 서류 | 문서 요청/발급 | ✅ |
| 투약/알레르기 | 복용 약물 + 알레르기 | ✅ |
| 검사결과 | CBC/LFT 등 결과 | ✅ |
| 영상검사 | Study 목록 + PACS 뷰어 링크 | ✅ |
| 진료비 | 수납 이력 + 미수납 | ✅ |
| 내 정보 | 프로필/연락처/주소 | ✅ |

**인터넷 예약 (/booking):** AI 대화형 예약 (673줄)

### 1.2 블록체인 인증서 시스템

**백엔드:**
| 기능 | API | 상태 |
|------|-----|------|
| 인증서 발급 | POST /blockchain-cert/issue | ✅ |
| 내 인증서 조회 | GET /blockchain-cert/my | ✅ |
| 인증서 승인/거부 | POST /:id/approve, /:id/reject | ✅ |
| 인증서 갱신/정지/해지 | POST /:id/renew, /suspend, /revoke | ✅ |
| CRL 목록 | GET /crl | ✅ |
| 감사 로그 | GET /audit-log | ✅ |
| 만료 예정 | GET /expiring | ✅ |
| 핑거프린트 검증 | GET /verify/:fingerprint | ✅ |

**프론트엔드:**
| 페이지 | 기능 | 상태 |
|--------|------|------|
| /admin/blockchain-cert | 관리자 인증서 관리 | ✅ |
| /settings/my-certificate | 내 인증서 조회 | ✅ |
| /verify | 외부 검증 페이지 | ✅ |
| SignatureModal | 전자서명 모달 | ✅ |
| SmartSignButton | 서명 버튼 (차트/동의서) | ✅ |

**모델:**
- BlockchainCertificate — 인증서 (STAFF/PATIENT, 공개키, 상태, 만료)
- SignedDocument — 서명된 문서 (차트, 동의서)

- BlockchainAnchor — 블록체인 앵커링

| P-10 | **수술/시술 동의서 전자서명** | 동의서 서명 있음 | 블록체인 인증서 기반 법적 서명 강화 |

| # | 기능 | 현재 | 개선 |
|---|------|------|------|
| B-1 | **환자 인증서 발급** | STAFF 중심 | 환자 포털에서 인증서 발급 요청 가능 |

## 3. 구현 계획

### Phase 1: 실시간 대기 + 건강 대시보드 (P-1, P-2)

**3.1 실시간 대기 현황:**
```
┌─ 대기 현황 ──────────────────────────────────┐
│                                                │
│  현재 대기 순번: #3                            │
│  예상 대기 시간: 약 15분                       │
│                                                │
│  ──●──────●──────○──────○──                   │
│  접수    대기중   진료    수납                   │
│                                                │
│  진료과: 내과 | 담당의: 김내과                   │
│  접수시간: 09:42                                │
│                                                │
│  🔔 호출 시 알림이 전송됩니다                   │
└────────────────────────────────────────────────┘
```

API: 기존 `GET /api/v1/portal/waiting-status` 활용 + SSE 스트림 연동

### Phase 2: 처방약 복용 관리 + 문진표 알림 (P-3, P-4)

**3.3 복용 체크:**
- 활성 처방 → 복용 시간대 자동 계산 (아침/점심/저녁)
- 체크박스로 복용 확인
- 미복용 시 알림 (포털 접속 시)

**3.4 문진표 알림:**
- 예약 전날 포털 홈에 배너 표시
- "문진표를 작성하면 진료 대기 시간이 단축됩니다"

### Phase 3: 영수증 + 가족 계정 (P-5, P-6)

**3.5 의료비 영수증:**
- 기존 `/print/receipt/[billingId]` 활용
- 포털에서 PDF 다운로드 (window.print → PDF 저장)
- 연말정산 의료비 증빙 (기간별 합산)

**3.6 가족 계정:**
```prisma
// 기존 PatientFamily 모델 활용
model PatientFamily {
  patientId    String   // 보호자 환자 ID
  linkedPatientId String // 피보호 환자 ID
  relationship String   // PARENT, CHILD, SPOUSE, GUARDIAN
  canViewRecords Boolean // 기록 열람 권한
}
```
- 포털 로그인 후 가족 환자 전환 기능
- 소아/고령 환자 대신 예약/문진표/결제 가능

### Phase 4: 양방향 메시지 + 건강검진 (P-7, P-8)

**3.7 양방향 메시지:**
```
┌─ 담당의 문의 ───────────────────────────────┐

│  └── 답변: 네 알겠습니다                     │
│                                              │
│  [새 문의 작성]                              │
│  ┌────────────────────────────────────────┐  │
│  │ 약 복용 후 어지러움이 있는데 괜찮은가요? │  │
│  └────────────────────────────────────────┘  │
│  [전송]                                      │
└──────────────────────────────────────────────┘
```

### Phase 5: 블록체인 인증서 환자 연동 (B-1~B-4)

**3.8 환자 인증서:**
- 포털에서 인증서 발급 요청 (본인 확인 후)
- 브라우저 로컬 키 생성 (Web Crypto API) → 공개키 서버 전송
- 개인키 PIN 보호 (IndexedDB 암호화 저장)
- 동의서 서명 시 블록체인 서명 옵션

**3.9 서명 검증 강화:**
- QR 코드 생성 (서명된 문서 → /verify?fp=xxx)
- 검증 결과: 서명자 이름, 서명 시간, 문서 해시, 블록체인 앵커 상태

### Phase 6: 진료기록 열람 이력 + 예방접종 (B-6, P-9)

**3.10 열람 이력:**
```
┌─ 내 기록 열람 이력 ─────────────────────────┐

│  05/18 14:30  조간호 (간호부) — 바이탈 기록  │
│  05/15 11:00  이외과 (외과)  — 수술 기록     │
│                                              │
│  ⚠ 긴급 열람 (Break The Glass)              │
│  05/10 03:20  응급의학과 — 응급 진료 (사유 기록됨) │
└──────────────────────────────────────────────┘
```

기존 audit 로그 + Break The Glass 로그를 환자 포털에서 조회
