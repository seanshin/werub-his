## 3. 구현 항목

### 3.1 환자 정보 헤더 확장

| 현재 | 추가 |
|------|------|
| 환자명, MRN, 보험종류 | + 나이/성별, 진료과, 담당의, 진료일, 진단명 |

### 3.2 법정 10개 항목 분류

처방(Prescription) 데이터를 10개 항목으로 분류:

| 번호 | 항목 | 처방 타입 매핑 |
|:----:|------|--------------|
| ① | 진찰료 | 자동 (외래 기본) |
| ② | 입원료 | 입원 시 자동 |
| ③ | 투약·조제료 | MEDICATION |
| ④ | 주사료 | MEDICATION (route=IV/IM) |
| ⑤ | 마취료 | AnesthesiaRecord |
| ⑥ | 처치·수술료 | THERAPY, SURGERY |
| ⑦ | 검사료 | LAB |
| ⑧ | 영상진단료 | IMAGING |
| ⑨ | 치료재료대 | MATERIAL |
| ⑩ | 식대 | DIET |

### 3.3 급여/비급여 구분

각 항목에 `[급여]` `[비급여]` 배지 표시.
비급여 항목은 별도 소계에 합산.

### 3.4 부담금 자동 계산

보험종류별 자동 계산:
```
건강보험 (의원급): 본인 30%
건강보험 (병원급): 본인 40%
건강보험 (종합병원): 본인 50%
건강보험 (상급종합): 본인 60%
의료급여 1종: 면제 (급식비만)
의료급여 2종: 본인 10~15%
산재/자동차: 전액 보험
비급여: 전액 본인
```

### 3.5 할인/감면

| 종류 | 감면율 | 대상 |
|------|:------:|------|
| 경로우대 | 10% | 만 65세 이상 |
| 차상위계층 | 본인부담 경감 | 차상위 확인서 |
| 직원/가족 | 50% | 병원 직원 및 직계가족 |
| 의료급여 | 면제~15% | 의료급여 수급자 |

### 3.6 결제수단 상세

- **카드**: 카드사 선택 + 승인번호 + 할부개월
- **현금**: 현금영수증 (소득공제/지출증빙/미발급) + 번호
- **계좌이체**: 은행 + 입금자명
- **복합결제**: 카드+현금 금액 분리 입력

### 3.7 영수증 즉시 발급

수납 완료 후:
- [계산서·영수증 인쇄] → `/print/receipt/{billingId}`
- [세부산정 인쇄] → `/print/receipt/{billingId}?tab=detail`
- [비급여 내역서] → `/print/receipt/{billingId}?tab=noncovered`

```

billing.copay.nhi.inpatient: 20      // 건강보험 입원 %

billing.copay.ma1.outpatient: 0      // 의료급여 1종 외래
billing.copay.ma2.outpatient: 15     // 의료급여 2종 외래

billing.fee.consultation.initial: 15890  // 초진 진찰료
billing.fee.consultation.followup: 11690 // 재진 진찰료
billing.fee.admission.general: 52000     // 일반병실
billing.fee.meal.general: 5200           // 일반식
billing.fee.dispensing.internal: 4500    // 원내조제료
billing.fee.dispensing.external: 8000    // 원외처방료
```
