## 1. 현재 상태

### 1.1 구현 현황

| 기능 | FE | BE | 시드 | 상태 |
|------|:--:|:--:|:----:|:----:|
| 입원 목록 + AI 위험도 | ✅ | ✅ | 5건 | 완성 |
| 입원 상세 (경과기록) | ✅ | ✅ | 6건 | 완성 |
| 퇴원 요약 | ✅ | ✅ | - | 구조만 |
| 간호 사정 | ✅ | ✅ | - | 구조만, 데이터 없음 |
| 간호 기록 (SOAP) | ✅ | ✅ | - | 구조만, 데이터 없음 |
| 섭취/배출 (I/O) | ✅ | ✅ | - | 구조만, 데이터 없음 |
| MAR (투약 기록) | ✅ | ✅ | - | 구조만, 데이터 없음 |
| 바이탈 기록 | ✅ | ✅ | - | 외래만, 입원 연동 부족 |
| 회진 기록 | - | ✅ | - | BE만, FE 없음 |
| 인수인계 | - | ✅ | - | BE만, FE 없음 |

### 1.2 문제점

| # | 문제 | 영향 |
|---|------|------|
| I-1 | **테스트 데이터 없음** | 간호사정/간호기록/I&O/MAR/바이탈 모두 빈 화면 — 기능 검증 불가 |
| I-2 | **역할 분리 없음** | 의사/간호사 구분 없이 모든 기능이 동일하게 노출 |
| I-3 | **입원 차트 통합 뷰 없음** | 의사가 입원 환자 차트를 한눈에 보는 대시보드가 없음 |
| I-4 | **회진/인수인계 FE 없음** | BE에 API는 있지만 화면이 없음 |
| I-5 | **바이탈 트렌드** | 입원 기간 바이탈 추이 차트 없음 (외래 1회만) |
| I-6 | **식이/영양 관리** | dietType만 있고 식사 기록/칼로리 추적 없음 |

## 3. 테스트 데이터 시드

### 3.1 필요 데이터

| 모델 | 데이터 수 | 대상 환자 |
|------|:--------:|---------|
| **NursingAssessment** | 8건 | 입원 환자 전원 (입원 시 1회) |
| **PreVisitVitals** (입원 바이탈) | 40건+ | 환자당 5~7일 × shift 3회 |
| **NursingNote** | 24건+ | 환자당 3~5건 (Focus/DAR) |
| **IntakeOutput** | 48건+ | 환자당 하루 6~8건 |
| **MedicationAdministration** | 30건+ | 활성 처방 기반 |
| **ProgressNote** | 16건+ | 환자당 2~3건 (의사 경과기록) |

### 3.2 샘플 데이터 상세

**바이탈 (김영수 환자, 입원 3일차):**
```
5/9  06:00  BP 148/92  HR 82  BT 36.8  SpO2 96%  통증 0
5/9  14:00  BP 142/88  HR 78  BT 36.9  SpO2 97%  통증 0
5/9  22:00  BP 138/85  HR 76  BT 36.7  SpO2 97%  통증 0
5/10 06:00  BP 136/84  HR 74  BT 36.6  SpO2 98%  통증 0
5/10 14:00  BP 132/80  HR 72  BT 36.5  SpO2 98%  통증 0
```

**I/O (오대한 환자, 수술 후):**
```
섭취: IV N/S 1000mL, IV 항생제 200mL, 경구 500mL, 식사 400mL
배출: 소변 1400mL, 드레인 150mL, 기타 50mL
균형: +500mL (수술 후 정상)
```

**간호 기록 (Focus/DAR):**
```
Focus: 수술 부위 통증
Data: NRS 5/10, 찡그린 표정, 체위 변경 시 악화
Action: 케토롤락 30mg IV 투여, 체위 변경 보조
Response: 30분 후 NRS 3/10으로 감소, 표정 편안
```

**MAR:**
```
세프트리악손 1g IV q12h — 06:00 ✅ 투여, 18:00 ✅ 투여
케토롤락 30mg IV PRN — 08:00 ✅ 투여 (통증 시), 14:00 ⏳ 예정
오메프라졸 20mg PO QD — 07:00 ✅ 투여
```

## 5. 구현 계획

### Phase 1: 테스트 데이터 시드 (기반)

| # | 작업 | 예상 |
|---|------|:----:|
| 1-1 | NursingAssessment 8건 (환자별 1건) | 0.5h |
| 1-2 | 바이탈 40건+ (3일×3shift×환자) | 1h |
| 1-3 | NursingNote 24건+ (Focus/DAR) | 0.5h |
| 1-4 | IntakeOutput 48건+ (일별 I/O) | 0.5h |
| 1-5 | MedicationAdministration 30건+ | 0.5h |
| 1-6 | ProgressNote 16건+ (의사 경과기록) | 0.5h |

**Phase 1 합계: 3.5h**

### Phase 2: 입원 차트 통합 뷰 (의사용)

| # | 작업 | 예상 |
|---|------|:----:|
| 2-1 | 입원 상세 페이지 리디자인 (대시보드형) | 2h |
| 2-2 | 바이탈 트렌드 차트 (입원 기간 전체) | 1h |
| 2-3 | 경과기록 타임라인 뷰 | 1h |
| 2-4 | 오더 현황 인라인 표시 | 1h |

**Phase 2 합계: 5h**

### Phase 3: 간호 워크시트 (간호사용)

| # | 작업 | 예상 |
|---|------|:----:|
