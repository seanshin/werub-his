# 환자 차트 — 타블렛 보기 모드(독립 셸) UX 기획

> **상태(2026-09-14 코드 대조)**: 구현됨(일부) — apps/web/src/app/tablet/patients/[id]/page.tsx · apps/web/src/app/tablet/patients/[id]/encounter/page.tsx · apps/web/src/app/tablet/nursing/[admissionId]/note/ · 잔여: (참고) tablet i18n 23화면(사람)

> 작성: 2026-06-23 / 상태: Plan v1.2 (보강: 스타일러스 입력 명세·노트형(필기) 진료 작성 배경)
> 한 줄: 데스크탑 차트의 반응형 축소가 아니라, **독립적으로 동작하는 별도 타블렛 전용 셸**(전용 라우트·레이아웃·터치 네비게이션)에서 실제 의료차트를 조회·작성·관리한다.

---

## 1. 배경·문제

- 현재 환자 차트(`/patients/[id]`)·진료 작성(`/patients/[id]/encounter/new`)은 **데스크탑 전제**: 좌측 사이드바(고정)·상단 통합검색/화면번호·핫키(`g` ScreenJump, `F2/F8` 액션)에 의존(`apps/web/src/app/(main)/layout.tsx`, `components/layout/ScreenJump.tsx`, `HotkeyProvider.tsx`).
- 반응형은 **부분적**(grid `md:`/`lg:`, 사이드바 `lg:static` 드로어)이라 타블렛에서 그대로 쓰면 정보 밀도·터치 타깃·키보드 의존 문제가 남는다.
- 회진(라운딩)·병상 옆 진료·간호 기록은 **타블렛 단독 기기**(손에 들고, 장갑/스타일러스, 키보드 없음)로 운영되어야 한다.

**결정(요구사항)**: 타블렛 모드는 **별도 동작 형태** — 데스크탑 `(main)` 레이아웃과 분리된 **독립 셸**로 구축한다. (반응형 리플로우 아님)

## 2. 목표·비목표

**목표**
- 타블렛(가로 우선, 세로 지원) 단독 기기에서 **환자 차트 조회 + 진료/간호 기록 작성**까지 완결.
- 키보드·마우스·핫키 없이 **터치 퍼스트**로 모든 핵심 동작 수행.
- 데스크탑과 **데이터·도메인 로직 공유**(중복 구현 금지), UX 셸만 별도.

**비목표**
- 네이티브 앱(`apps/mobile` Expo)과 통합/대체 아님 — 웹 타블렛 셸.
- 데스크탑 차트 UI 변경 아님(진입 버튼만 추가).
- 오프라인 동기화(FR-08 Out of Scope) 미포함.

## 3. 대상 기기·사용 맥락

| 구분 | 값 |
|------|----|
| 기기 | iPad / Android 태블릿 (10~13"), 가로 1024~1366px 우선 · 세로 768~834px 지원 |
| 포인터 | coarse(터치) 기본, 스타일러스 보조 |
| 맥락 | ① 회진 — 병상 옆 차트 리뷰·구두처방 메모 ② 진료 — 책상 위 거치형 작성 ③ 간호 — 병동 라운드 기록 |
| 제약 | 키보드 없음, 장갑/소독, 화면 반사, 한 손 파지(엄지 도달 영역) |

## 4. 독립 셸 아키텍처

기존 독립 셸 선례 재사용: `app/consent-device`(태블릿 키오스크)·`app/display`(보드) — **실제 세그먼트 + 자체 layout** 패턴(라우트 그룹 `()`은 URL 접두어가 없고 `(main)`과 경로 충돌하므로 사용 안 함). 동일 패턴으로 신설.

```
apps/web/src/app/tablet/                   ← 신규 실제 세그먼트(/tablet/*) · 독립
├── layout.tsx                             ← 타블렛 전용 셸(데스크탑 Sidebar/TopBar 미사용)
├── _components/                           ← 타블렛 전용 컴포넌트(언더스코어=비라우트)
├── page.tsx                               ← /tablet 홈: 오늘 환자·회진 목록·검색
├── patients/[id]/page.tsx                 ← /tablet/patients/[id] 차트 조회(타블렛 IA)
└── patients/[id]/encounter/page.tsx       ← 진료/기록 작성(타블렛 작성기, P1)
```

- **독립 레이아웃**: 좌측 데스크탑 사이드바 제거 → 상단 슬림 바(환자 컨텍스트·모드 표시) + **오프캔버스 네비 드로어**(큰 터치 행) + **하단 액션 바**(엄지 도달, 핫키 대체).
- **데이터 재사용**: TanStack Query 훅·API 클라이언트·도메인 표시 컴포넌트(탭 콘텐츠)는 그대로 import, 타블렛 컨테이너로 래핑.
- **진입/전환**:
  - 데스크탑 차트 헤더(`PatientHeader.tsx`)에 **「타블렛 모드」** 버튼 추가 → 동일 환자 `/tablet/patients/[id]`로 이동(컨텍스트 유지).
  - 타블렛 기기 북마크/키오스크로 `/tablet` 직접 진입 가능(데스크탑 거치지 않음).
  - 모드 상태는 라우트로 자명(별도 셸) — 토글 플래그 불필요. localStorage `tabletMode=1`로 재진입 시 `/tablet` 우선(선택).
- **인증·잠금**: 기존 단말 인증 재사용 — Tier1 PIN 화면잠금 / Tier2 처방 시 생체 step-up(이미 config 게이트 존재). 키오스크 모드 시 자동 화면잠금.

## 5. 정보구조(IA) — 타블렛 재구성

데스크탑 탭(개요·검사결과·바이탈·투약·오더·진료이력·전문과 칩)을 타블렛에선 **2계층 + 스와이프**로 단순화.

```
[환자 컨텍스트 바]  강미래 5/여 A+ NKDA · P2026-0008          [≡ 네비] [환자전환]
─────────────────────────────────────────────────────────────────────
세그먼트(큰 탭, 스와이프):  [요약] [바이탈] [검사] [투약] [기록]  ⋯ 더보기
```

- 6개 데스크탑 탭 → **5개 핵심 세그먼트**(요약/바이탈/검사/투약/기록) + 「더보기」 시트(전문과·문제목록·알레르기·수술·입퇴원).
- 세그먼트 간 **좌우 스와이프** 전환(터치) + 탭(누름) 동시 지원.
- 「요약」 = 데스크탑 OverviewTab 재구성(핵심정보·바이탈·알레르기·활성처방·문제목록을 타블렛 카드 스택으로).

## 6. 레이아웃 — 가로/세로

### 6.1 가로(Landscape, 우선) — 2-pane

```
┌─ 컨텍스트 바 ─────────────────────────────────────────────────────────┐
│ 강미래 5/여 A+  NKDA   P2026-0008            [≡] [환자전환] [잠금]      │
├──────────────────────────┬────────────────────────────────────────────┤
│  좌: 차트 컨텍스트(고정)   │  우: 작업 영역                              │
│  - 최근 바이탈            │   세그먼트: [요약][바이탈][검사][투약][기록]│
│  - 활성 문제/처방 요약    │   ┌──────────────────────────────────────┐ │
│  - 알레르기/위급 경고     │   │  선택 세그먼트 콘텐츠                 │ │
│  (PatientChartDrawer       │   │  (조회) 또는 (작성: SOAP/오더)       │ │
│   패턴 재사용·상시 표시)   │   └──────────────────────────────────────┘ │
├──────────────────────────┴────────────────────────────────────────────┤
│ 하단 액션 바:  [＋오더] [＋처방] [💾 저장] [✓ 서명] [🎙 음성] [⌨ 빠른문구]│
└────────────────────────────────────────────────────────────────────────┘
```

- 좌측 컨텍스트 패널 = `PatientChartDrawer`(이미 `fixed right-0 sm:w-[440px]`)를 **좌측 상시 패널**로 재배치 재사용.
- 우측 작업 영역 = 조회 세그먼트 또는 진료 작성기. 진료 작성 시 좌측 컨텍스트를 보며 우측에 SOAP/오더 입력(데스크탑 `encounter/new`의 2-pane을 타블렛 비율로).
- 하단 액션 바 = **핫키(F2 저장·F8 취소 등) 전면 대체** — 엄지 도달 영역 고정.

## 8. 터치·입력 에르고노믹스

- **터치 타깃 최소 44×44px**(현재 일부 `w-4 h-4` 아이콘 → 타블렛 셸은 `w-6 h-6`+패딩). 행 높이 ≥ 48px.
- **엄지 도달**: 1차 동작(저장·오더·처방·서명)은 하단 고정 바.
- **SOAP 빠른 입력**: 진료과·증상별 **빠른문구 칩**(템플릿 → textarea 삽입), 문진표 자동채움(기존 `applyQuestionnaireToSOAP` 재사용).
- **바이탈 입력**: 전용 **숫자 키패드** + 정상범위 가이드(오타·키보드 회피).
- **스타일러스**: textarea 필기 입력 OS IME 허용(별도 구현 없이), 서명 패드 재사용(동의서 서명 컴포넌트).
- **음성 입력(P3)**: S/O 받아쓰기(브라우저 SpeechRecognition 또는 기존 AI 받아쓰기 연계).
- **제스처**: 세그먼트 좌우 스와이프, 컨텍스트 바텀시트 드래그업, 길게 눌러 맥락 메뉴.

## 9. 키보드·핫키 대체 매핑

| 데스크탑(키보드) | 타블렛(터치) |
|------------------|--------------|
| `g` ScreenJump 화면이동 | 네비 드로어 런처(즐겨찾기·최근·역할별 큰 버튼) |
| `F2` 저장 / `F8` 취소 | 하단 액션 바 [💾 저장]/[✕ 취소] |
| 통합검색(상단) | 컨텍스트 바 [🔍] → 전면 검색 시트(환자/약품/코드) |
| 탭 클릭 | 세그먼트 탭/스와이프 |
| 화면번호 입력 | 미노출(터치 런처가 대체) |

## 10. 단계(P0~P3)

- **P0 — 독립 셸 + 차트 조회(읽기)**: `(tablet)/layout.tsx`·`/tablet` 홈(오늘환자/회진/검색)·`/tablet/patients/[id]` 요약/바이탈/검사/투약 세그먼트(조회), 컨텍스트 패널(가로)/바텀시트(세로), 네비 드로어, 데스크탑 진입 버튼. **회진 리뷰 사용 가능.**
- **P1 — 진료/기록 작성**: `/tablet/patients/[id]/encounter` SOAP·오더·처방 작성기(빠른문구·숫자키패드), 하단 액션 바(저장·서명), Tier2 생체 step-up 연계.
- **P2 — 간호·전문과**: 간호기록(5형식)·NANDA-NIC-NOC·전문과 레이아웃 타블렛화, 더보기 시트.
- **P3 — 고급 입력**: 음성 받아쓰기·스타일러스 서명·키오스크 잠금·환자전환 빠른 스위처.

### 14.3 차트 — 「바이탈/검사/투약」 조회 세그먼트
- **바이탈**: 큰 추세 그래프(BP/HR/SpO2/BT·체중) + 측정 카드. [＋바이탈] → 숫자 키패드 입력 시트.

## 15. 임상 워크플로우(단계별)

### 15.1 회진 리뷰(읽기, P0)
1. `/tablet` → 「회진 병동」 → 병동 선택 → 환자 리스트(상태 플래그).
2. 환자 탭 → 「요약」 2-pane. 좌측 컨텍스트 상시·우측 세그먼트 스와이프로 바이탈/검사/투약 훑기.
3. 메모 필요 시 [＋오더]/[＋처방]은 **구두처방 플로우**(15.2)로.
4. 다음 환자 → 컨텍스트 바 [환자전환] 빠른 스위처(같은 병동 좌우 스와이프).

### 15.2 구두처방 + Read-back(P1)
1. 진료 작성기 또는 회진 중 [＋처방] → 약물 검색 → 용법 입력.
2. **구두처방 표식**(orderSource=VERBAL) 선택 시 **Read-back 확인 단계** 삽입(기존 patient-safety `read-back/:prescriptionId` 재사용) — 간호사가 복창 확인 토글.
3. [✓ 서명] → Tier2 step-up(처방=`PRESCRIPTION_CREATE`) → 서버 assertion 검증 → 발행.

### 15.3 진료 작성·서명(P1)
1. 차트 [📝 진료시작] → `encounter` 진입 시 **DRAFT encounter 자동 생성**(서버, encounterId 단일 소스).
2. SOAP(빠른문구/음성) + 처방/오더 입력 → [💾 임시저장](autosave) → [✓ 서명·완료](status SIGNED, step-up·블록체인 서명 연계).

### 15.4 간호 인계·기록(P2)
1. 「기록」 세그먼트 → 간호노트(5형식)·NANDA-NIC-NOC·낙상 재사정.
2. 교대 인계: 미서명/미확인 항목 배지 → 서명(SignatureModal). I-PASS 핸드오프 양식 연계.

### 15.5 환자 전환·잠금
- [환자전환]: 검색 시트 또는 같은 컨텍스트(병동/큐) 좌우 스와이프. 전환 시 미저장 DRAFT 경고.
- 자리 비움: [🔒] 또는 idle 타임아웃 → Tier1 PIN 잠금(키오스크).

## 17. 단말 인증·키오스크·동시편집

### 17.1 기기 등록·로그인
- 타블렛은 **등록 단말**(기존 단말 보안 — `admin/terminal-security` 페이지·terminal config). 최초 1회 기기 등록 → 단말 신뢰.
- 로그인: 직원 SSO/패스키(기존). 공용 단말은 **빠른 사용자 전환**(PIN/생체) 지원.

### 17.2 2-Tier 인증(재사용)
- **Tier1 — 화면 잠금(PIN)**: idle 타임아웃·[🔒] → PIN 재입력(자리 비움 보호). config 게이트 기존.
- **Tier2 — 생체 step-up(스마트폰 푸시)**: 민감 액션(`terminal.stepUpActions`: `PRESCRIPTION_CREATE`·`ENCOUNTER_SIGN`)에서 `StepUpApprovalPrompt` → FCM 푸시 → 폰 생체 → 서버 assertion 검증. `terminal.stepUpPilotUserIds`로 점진 적용. **기본 OFF**(go-live 시 플립).

### 17.3 키오스크 모드
- `/tablet`을 거치형 키오스크로: 자동 화면잠금(idle), 외부 링크/주소창 숨김(PWA standalone), 데스크탑 사이드바·ERP 런처 등 비노출.
- 세션: 사용자 전환 시 차트 컨텍스트·DRAFT 격리(직전 사용자 데이터 잔존 금지).

### 17.4 데스크탑 ↔ 타블렛 동시편집 안전
- **단일 소스**: 같은 진료는 동일 `encounterId`(서버) — 타블렛/데스크탑이 같은 레코드를 본다.
- **DRAFT 자동생성 중복 방지**: 작성기 진입 시 해당 환자의 **열린 DRAFT가 있으면 재사용**(신규 생성 금지) — 두 기기가 각각 DRAFT를 만들지 않도록 서버 가드.
- **저장 충돌**: 마지막 저장 우선 + `updatedAt` 기준 stale 경고(상대가 먼저 저장 시 알림·머지 안내). 서명(SIGNED) 후에는 편집 잠금(수정=AMEND 경로).
- **표시**: 컨텍스트 바에 "다른 기기에서 편집 중" 인디케이터(동일 encounter 활성 세션 감지, 경량 폴링/SSE).

# 보강(v1.2) — 스타일러스 입력·노트형 진료 작성

## 18. 스타일러스(펜) 입력 명세

타블렛 진료 작성은 **펜이 1차 입력기**가 되도록 설계한다(종이 차트 경험). 두 경로를 제공:

### 18.1 경로 A — 필기→텍스트(Scribble, EMR 정합·기본)
- 노트형 SOAP 필드에 **펜으로 직접 필기 → OS 손글씨 인식(iPad Scribble / Android 필기)** 으로 텍스트 변환. 변환 결과는 일반 텍스트라 **기존 `updateEncounter`로 그대로 저장**(구조화 유지·BE 무변경).
- 필드는 **노트(괘선) 배경**·넓은 행간(line-height ≈ 괘선 간격 36px)·손글씨 친화 폰트·충분한 높이로 "종이에 쓰는" 느낌.
- 제스처: 펜으로 단어 위 **긁기=삭제**, 줄 사이 **세로획=공백 삽입**(OS 기본). 빠른문구 칩 병행.

### 18.2 경로 B — 필기 스케치(그림·도해)
- 자유 필기/도해(피부병변 위치, 골절 도식, 다이어그램)용 **펜 캔버스**(`PenNoteCanvas`). 텍스트로 환원 불가한 시각 정보.
- 영속화: 임상 첨부 엔드포인트(인코딩 PNG/SVG를 encounter에 첨부)는 **P3.1 선결**(BE: `POST /encounters/:id/attachments`). 그 전까지는 작업 스케치(세션 내)+PNG 내보내기/인쇄.

### 18.3 펜 동작 명세(공통)
| 항목 | 명세 |
|------|------|
| 포인터 구분 | `pointerType==='pen'`만 필기(기본). 손가락(touch)은 **스크롤/제스처**(팜 리젝션). 토글로 손가락 필기 허용 |
| 팜 리젝션 | 펜 호버/접촉 시 touch 입력 무시(`touch-action:none` on canvas, pen 우선). 손바닥 거치 오작동 방지 |
| 필압 | `PointerEvent.pressure`(0~1)로 선 굵기 가변(0.3~1.0→1.2~4px). 미지원(0) 시 속도 기반 가변 |
| 기울기 | `tiltX/tiltY`(지원 시) 형광펜 폭 보정(선택) |
| 도구 | 펜(검정·파랑·빨강)·형광펜(반투명·굵게)·지우개(스트로크 단위)·실행취소(스트로크 스택)·전체지우기 |
| 렌더 | devicePixelRatio 스케일(레티나 선명), 스트로크=점 배열 모델→undo 시 전체 재드로우 |
| 지연 | pointermove 직접 그리기(rAF 코얼레싱), 입력 지연 최소화 |
| 저장 | `toDataURL('image/png')` 내보내기. (P3.1: 첨부 업로드) |

### 18.4 노트(괘선) 배경 명세
- CSS 괘선: `repeating-linear-gradient(#fff, #fff 35px, #e6effa 36px)`(36px 행) — SOAP 필드·스케치 캔버스 공통.
- 좌측 여백선(빨강 세로선) 선택. 모서리 둥근 카드·종이 질감 그림자로 노트 느낌.
- 다크/글레어 대비: 배경 #fcfdff(미세 블루톤)·괘선 저채도.

## 19. 노트형 진료 작성기 구조(펜 모드)
- 작성기 상단 **입력 모드 토글 [키보드 | 펜]**. 펜 모드:
  - SOAP 4필드 = **노트형 필드**(괘선 배경·넓은 행간·Scribble 친화). 펜으로 바로 필기→텍스트.
  - 하단 **「✎ 스케치」** = `PenNoteCanvas`(괘선 배경, 18.3 도구) 패널/오버레이. 도해 작성.
- 가로 2-pane 유지(좌 차트 참조·우 노트 작성). 펜은 우측 노트 영역에서 1차 사용.
