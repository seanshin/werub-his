## 0. 현황 / 문제
- 현재 `InstrumentSetTemplate.items = [{ name, qty }]` — **자유 텍스트**. 품목이 관리 단위가 아님.
- 결과: ① 동일 기구의 표준화/코드화 불가 ② 세트 간 **품목 공유·연계** 추적 불가 ③ 재포장 시 **재고 소모** 미반영 ④ **공급(입고)·안전재고·발주** 관리 부재.

## 1. 목표
- **기구 품목 마스터**로 모든 기구를 코드·재고·공급업체와 함께 관리.
- 트레이 세트를 **품목 선택형 빌더**로 조합 → 세트↔품목 연계(어느 세트가 어떤 품목을 쓰는지).
- 재포장 시 품목 **재고 자동 소모**, 반납/폐기 시 환원.
- **공급/재고**: 입고·소모·조정·반품 트랜잭션 + **안전재고 미달 알림·발주 제안**.

## 2. 범위
- **포함**: 품목 마스터(CRUD), 세트 조합 빌더(품목 연계), 재고 소모 연계, 공급 트랜잭션, 안전재고 알림, 공급업체.
- ~~**제외(차기)**~~ → **✅ 완료(2026-06-09 구현됨, 제외 해제)**:
  - **정식 구매발주(PO) 워크플로우·승인** — `cssd-po.service.ts`(발주생성→승인→입고수령, `CssdPurchaseOrder/CssdPoLine`, 재주문 제안), `/cssd` 발주 탭. (P3 → 완료)
  - **바코드/QR 입출고 스캔** — `items/by-code/:code` 조회 + ItemsTab 스캔/QR 라벨. (P3 → 완료)
  - **외부 ERP 연동** — `erpItemCode` 매핑 + outbox `stock.changed` → [[erp-integration-master]]로 흡수 구현.
- **남은 제외**: 멸균 횟수/수명 관리(기구 개체 단위)만 차기.

## 3. 도메인 모델 (제안)
```
InstrumentItem (기구 품목 마스터)
  - code(고유), name, category(절단/지혈/견인/봉합/세척/기타)
  - spec(규격), unit(개/세트)
  - stock(현재고), safetyStock(안전재고), location
  - supplierId?, unitPrice?
  - isActive
  - timestamps

InstrumentSetTemplate.items 변경
  - 기존: [{ name, qty }]  →  [{ itemId, name(스냅샷), qty }]
  - itemId로 InstrumentItem 연계(명칭/코드/단가 조회), 자유항목도 허용(itemId null)

Supplier (공급업체)
  - id, name, contact, phone, email, isActive

SupplyTransaction (공급/재고 거래)
  - id, itemId, type(IN 입고 / OUT 소모 / ADJUST 조정 / RETURN 반품)
  - qty(+/-), balanceAfter(거래후 재고)
  - reason/ref(재포장 LOT·PO번호 등), performedBy, createdAt
```
> 재고 = `InstrumentItem.stock`(캐시) + `SupplyTransaction` 원장(감사·이력). 트랜잭션 시 stock 갱신.

## 4. 기능 요구사항 (FR)
| ID | 기능 | 우선 |
|----|------|------|
| FR-01 | 품목 마스터 CRUD(코드·분류·규격·안전재고·공급업체·단가·위치) | High |
| FR-02 | **세트 조합 빌더** — 품목 검색·선택·수량 → 트레이 구성(품목 연계) | High |
| FR-03 | 세트↔품목 **사용처(역참조)** — 특정 품목이 포함된 세트 목록 | Medium |
| FR-04 | 재포장 시 **품목 재고 소모(OUT)** 자동 차감 + 트랜잭션 기록 | High |
| FR-05 | 반납/폐기 시 재고 환원(RETURN/조정) | Medium |
| FR-06 | **공급(입고 IN)·조정(ADJUST)** 등록 → 재고 반영·이력 | High |
| FR-07 | **안전재고 미달 알림** + 발주 제안 목록 | High |
| FR-08 | 공급업체 관리 + 업체별 품목/단가 | Medium |
| FR-09 | 품목별 입출고 이력(원장) 조회 | Medium |
| FR-10 | 재고 부족 시 재포장 경고(품목 부족 세트 표시) | Medium |

## 5. 사용자 플로우
```
[품목 마스터 등록/입고] → InstrumentItem + SupplyTransaction(IN)
[세트 조합] 빌더에서 품목 선택·수량 → 트레이 템플릿(품목 연계 FR-02)
[재포장] 트레이 선택·카운트 → LOT 생성 + 구성 품목 재고 OUT 차감(FR-04)
   └ 재고 부족 품목 → 경고(FR-10)
[반납/폐기] → 환원/조정(FR-05)
[안전재고 미달] → 알림 + 발주 제안(FR-07) → 입고(IN)로 보충
```

## 6. 화면 (UX) — `/cssd` 탭 확장
- **품목 마스터**: 목록(재고·안전재고·부족배지)·검색·CRUD·입고/조정 버튼·이력.
- **세트 조합(빌더)**: 좌 품목 검색/선택 → 우 구성 바스켓(수량·총단가·총수량) → 저장(트레이 템플릿).
- **공급/재고**: 안전재고 미달·발주 제안 패널 + 입출고 원장.
- (기존 재포장 탭) 품목 연계·재고 소모 반영.

## 9. 리스크
- 기존 템플릿(자유텍스트) 다수 → 품목 매핑 부담(D-1 혼용으로 완화, 점진 매핑).
- 재고 차감 정확성: 반납/회수/폐기 경로 누락 시 재고 오차 → 트랜잭션 원장으로 정합성 확보.
- 재포장과 재고의 **시점 정의**(D-3) 명확화 필요.
