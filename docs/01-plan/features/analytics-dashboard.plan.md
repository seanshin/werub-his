## 3. API 매핑 수정 사항

### 3.1 현재 문제: 중첩 data 파싱

```typescript
// 현재 (깨짐):
const eo = execOverview?.data ?? {};
// → API 반환: { data: { todayRevenue: 1250000, ... } }
// → apiClient.get 반환: { data: { todayRevenue: 1250000, ... } }
// → execOverview = { data: { todayRevenue: ... } }
// → execOverview?.data = { todayRevenue: ... }  ← 맞지만 중첩 여부 불확실

// 수정 (안정적):
const eo = (() => {
  const raw = execOverview?.data;
  if (!raw) return {};
  if ('todayRevenue' in raw) return raw;  // 직접 접근
  return (raw as any).data ?? raw;        // 중첩 처리
})();
```

### 3.2 Chart.js 데이터 연동

모든 차트에 실제 API 데이터를 연결:
- 주간 매출 Bar: `weekly.map(d => d.revenue)`
- 월별 Line: `monthly.map(m => m.revenue)` + `monthly.map(m => m.encounters)`
- 진료과별 Bar: `depts.map(d => d.revenue)`
- 보험유형 Doughnut: billing 데이터에서 insuranceType 집계

## 4. 추가 API 필요

### 4.1 시간대별 진료 분포 (신규)

```
GET /api/v1/executive/hourly-distribution?date=2026-05-20
→ [{ hour: 9, count: 5 }, { hour: 10, count: 8 }, ...]
```

### 4.2 진단코드 Top N (신규)

```
GET /api/v1/executive/top-diagnoses?limit=10&from=2026-05-01&to=2026-05-20
→ [{ code: 'J18', name: '폐렴', count: 15 }, { code: 'I10', name: '고혈압', count: 12 }, ...]
```

### 4.3 보험유형별 금액 (신규)

```
GET /api/v1/executive/insurance-breakdown
→ [{ type: 'NHI', amount: 5000000, count: 30 }, { type: 'SELF_PAY', amount: 800000, count: 5 }, ...]
```
