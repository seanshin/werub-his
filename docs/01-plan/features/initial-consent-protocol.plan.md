# 초진 동의서 프로토콜 (Initial Consent Protocol) 기획서 v1.0

> **작성일**: 2026-06-02
> **수준**: Enterprise
> **우선순위**: P0 (법적 필수, 접수 차단)
> **관련 법률**: 개인정보보호법 제15·17·23·24조, 의료법 제24조의2, 정보통신망법 제50조

---

## 1. 개요

### 1.1 목적

환자가 병원에 처음 접수할 때 **법정 필수 동의서 5종 + 선택 동의서 2종**을 체계적으로 수집하고, 동의 내용을 출력·보관·추적하는 **초진 동의서 프로토콜**을 구축한다.

### 1.2 현황 vs TO-BE

| 항목 | 현재 | TO-BE |
|------|------|-------|
| **동의 항목** | 3종 (체크박스) | 7종 (법정 전문 포함) |
| **동의 방식** | HIS 체크박스만 | HIS + 포털 + 모바일 3채널 |
| **동의서 출력** | 없음 | 동의서 전문 PDF 출력 (서명란 포함) |
| **전자서명** | 없음 | 포털/모바일에서 서명 패드 서명 |
| **동의 이력** | consents JSON 필드 | RegistrationConsent 모델 (개별 추적) |
| **원무과 워크플로우** | 없음 | "포털 동의 요청" 버튼 → 알림 → 확인 |
| **미동의 차단** | 없음 | 필수 동의 미완료 시 접수 차단 |
| **동의 철회** | 없음 | 포털에서 선택 동의 철회 가능 |

### 1.3 핵심 시나리오

```
시나리오 1: 대면 접수 (종이 동의서)
  환자 내원 → 원무과 접수
  → 원무과: HIS에서 "동의서 출력" 클릭
  → 프린터: 법정 7종 동의서 전문 출력 (서명란 포함)
  → 환자: 읽고 서명 (종이)
  → 원무과: HIS에서 동의 항목 체크 + 접수 완료
  → DB: RegistrationConsent 7건 생성

시나리오 2: 포털 전자 동의 (대면 유도)
  환자 내원 → 원무과 접수
  → 원무과: "포털 동의 요청" 클릭
  → 환자 폰: Push 알림 "동의서 서명이 필요합니다"
  → 환자: 포털 앱 → 동의서 전문 확인 → 서명 패드 서명
  → HIS: 실시간 반영 (SSE) "전자 동의 완료"
  → 원무과: 확인 → 접수 완료

시나리오 3: 사전 동의 (예약 시)
  환자: 온라인 예약 완료
  → 시스템: 자동 Push "방문 전 동의서를 미리 작성해주세요"
  → 환자: 포털에서 7종 동의서 사전 서명
  → 내원 당일: 원무과에서 "사전 동의 완료" 확인 → 즉시 접수

시나리오 4: 재진 환자
  환자 내원 → 원무과 접수
  → 시스템: 기존 동의 이력 확인 → "동의 완료 (2026-06-02)"
  → 원무과: 추가 동의 불필요 → 바로 접수
  → 1년 경과 시: "동의 갱신이 필요합니다" 알림
```

## 2. 법정 동의서 10종

> **검토 근거**: 개인정보보호법, 의료법, 의료법 시행규칙, 의료법 시행령 제42조의2, 
> 정보통신망법, 생명윤리법, 보건의료기본법 제6조·제12조·제13조
> **참고**: [대한병원협회 개인정보 처리 FAQ](https://www.kha.or.kr), [국가법령정보센터 의료법](https://www.law.go.kr/LSW/lsInfoP.do?lsId=001788)

| # | 동의서 | 법적 근거 | 수집 항목 | 목적 | 보유 기간 |
|---|--------|---------|----------|------|----------|
| 1 | **개인정보 수집·이용** | 개인정보보호법 제15조 | 성명, 생년월일, 성별, 연락처, 주소, 이메일 | 진료, 수납, 처방, 증명서 발급 | 10년 (의료법 시행규칙 제15조) |
| 2 | **민감정보(건강정보) 처리** | 개인정보보호법 제23조, 의료법 시행령 제42조의2 | 병력, 진단명(KCD), 검사결과, 처방, 영상자료, 유전정보 | 질병 진단·치료·예방, 건강관리 | 10년 |

| 4 | **제3자 제공** | 개인정보보호법 제17조 | 진료정보, 수납정보, 보험 자격 정보 | 국민건강보험공단, 건강보험심사평가원, 보험사(환자 요청 시), 국세청, 질병관리청(감염병) | 제공 목적 달성 시 파기 |
| 5 | **진료 동의** | 의료법 제24조의2(의료행위에 관한 설명) | — | 의료행위(진찰, 검사, 치료) 수행에 대한 포괄적 동의. 수술·시술은 별도 동의서 필요 | 10년 |
| 6 | **진료정보교류(HIE) 동의** | 의료법 제21조의2(진료기록의 송부), 의료법 시행규칙 별지 제9호의5 | 진료기록, 검사결과, 처방정보 | 의료기관 간 전자적 진료정보 공유 (타병원 전원·의뢰 시) | 동의 철회 시까지 |

### 2.2 필수 고지 (동의 아님, 게시·안내 의무)

| # | 고지 사항 | 법적 근거 | 내용 |
|---|----------|---------|------|
| A | **환자의 권리와 의무** | 의료법 제4조제3항, 보건의료기본법 제6조·제12조·제13조 | 진료받을 권리, 알 권리 및 자기결정권, 비밀 보장권, 피해 구제권 / 의료인 신뢰·존중 의무 |
| B | **비급여 진료비용 고지** | 의료법 제45조(비급여 진료비용 등의 고지) | 비급여 항목 및 금액을 접수창구 또는 대기실에 게시 |

> **참고**: 환자의 권리와 의무는 "동의서"가 아닌 "게시 의무"이므로 접수 시 별도 서명을 받지 않되, 초진 안내문에 포함하여 교부합니다.

### 2.3 선택 동의 (4종 — 미동의 시에도 진료 가능)

| # | 동의서 | 법적 근거 | 비고 |

| 8 | **임상연구 정보 활용** | 생명윤리법 제18조 | 비식별 처리된 진료정보의 학술 연구 활용 |

### 2.4 특수 상황별 추가 동의

| 상황 | 추가 동의 | 법적 근거 |
|------|----------|---------|
| **미성년자 (만 14세 미만)** | 법정대리인(부모) 동의 필수 | 개인정보보호법 제22조제6항 |
| **피성년후견인** | 법정대리인(후견인) 동의 필수 | 민법 제9조 |
| **외국인** | 여권번호 수집 동의, 통역 안내 | 개인정보보호법 제24조 |
| **응급환자** | 의식 불명 시 동의 면제 → 사후 추인 | 의료법 제24조의2 단서, 응급의료법 제9조 |
| **수술/시술** | 별도 서면 동의서 (수술동의서, 마취동의서) | 의료법 제24조의2 |

| **감염병 환자** | 감염병 신고 동의 (의무, 동의 불필요) | 감염병예방법 제11조 |

### 2.5 동의서 전문 필수 기재사항 (개인정보보호법 제15조·제17조·제22조)

동의서에는 반드시 아래 4가지 항목을 **명확히** 기재해야 합니다:
1. **수집·이용 목적** (어디에 쓸 것인지)
2. **수집하려는 개인정보의 항목** (무엇을 모을 것인지)
3. **보유 및 이용 기간** (언제까지 갖고 있을 것인지)
4. **동의 거부 권리 + 거부 시 불이익** (거부해도 되며, 거부하면 어떻게 되는지)

각 동의서 전문은 다음 형식을 따릅니다:

```
┌─────────────────────────────────────────────────┐
│           [병원명] 개인정보 수집·이용 동의서        │
│                                                   │
│ 1. 수집 항목                                       │
│    성명, 생년월일, 성별, 연락처, 주소, 이메일        │
│                                                   │
│ 2. 수집·이용 목적                                   │
│    진료(진찰, 검사, 치료), 처방, 수납, 증명서 발급    │
│                                                   │
│ 3. 보유·이용 기간                                   │
│    진료일로부터 10년 (의료법 시행규칙 제15조)         │
│                                                   │
│ 4. 동의 거부 권리                                   │
│    동의를 거부할 권리가 있으며, 필수 항목 거부 시     │
│    진료가 제한될 수 있습니다.                        │
│                                                   │
│ 환자명: ________________  서명: ________________   │
│ 일  자: 2026년  월  일                              │
│                                                   │
│ 법정대리인(해당 시): ___________  관계: __________  │
└─────────────────────────────────────────────────┘
```

## 3. 데이터 모델

### 3.1 RegistrationConsent (초진 동의서 이력)

```prisma
model RegistrationConsent {
  id            String    @id @default(uuid()) @db.Uuid
  patientId     String    @map("patient_id") @db.Uuid
  type          String    @db.VarChar(30)  // PRIVACY, SENSITIVE, UNIQUE_ID, THIRD_PARTY, TREATMENT, MARKETING, RESEARCH
  version       String    @default("1.0") @db.VarChar(10)
  agreed        Boolean
  
  // 서명
  signedAt      DateTime? @map("signed_at") @db.Timestamptz()
  signedBy      String?   @map("signed_by") @db.VarChar(100)  // 서명자 이름
  signatureData String?   @map("signature_data") @db.Text      // Base64 서명 이미지
  signMethod    String?   @map("sign_method") @db.VarChar(20)  // PAPER, PORTAL, MOBILE, HIS
  
  // 법정대리인 (미성년자/피후견인)
  guardianName  String?   @map("guardian_name") @db.VarChar(100)
  guardianRelation String? @map("guardian_relation") @db.VarChar(20) // PARENT, SPOUSE, CHILD, LEGAL_GUARDIAN
  
  // 철회
  revokedAt     DateTime? @map("revoked_at") @db.Timestamptz()
  revokedReason String?   @map("revoked_reason") @db.VarChar(200)
  
  // 갱신 (1년 주기)
  expiresAt     DateTime? @map("expires_at") @db.Timestamptz()
  renewedFromId String?   @map("renewed_from_id") @db.Uuid
  
  // 추적
  collectedBy   String?   @map("collected_by") @db.Uuid  // 접수 직원 ID
  ipAddress     String?   @map("ip_address") @db.VarChar(50)
  createdAt     DateTime  @default(now()) @map("created_at") @db.Timestamptz()

  patient       Patient   @relation(fields: [patientId], references: [id])

  @@unique([patientId, type, version])
  @@index([patientId, type])
  @@map("registration_consents")
}
```

## 4. 원무과 워크플로우

### 4.1 접수 화면 동의서 패널

```
┌─ 환자 접수 ───────────────────────────────────────────────┐
│                                                           │
│ 환자: 김영수 (P2026-0001) | 초진                           │
│                                                           │
│ ┌─ 동의서 현황 ──────────────────────────────────────────┐ │
│ │                                                        │ │
│ │ ✅ 개인정보 수집·이용    (필수)  2026-06-02 서명완료     │ │
│ │ ✅ 민감정보 처리         (필수)  2026-06-02 서명완료     │ │
│ │ ✅ 고유식별정보 처리     (필수)  2026-06-02 서명완료     │ │
│ │ ⬜ 제3자 제공            (필수)  미동의                  │ │
│ │ ⬜ 진료 동의             (필수)  미동의                  │ │
│ │ ── 선택 ──────────────────────────────────────────     │ │
│ │ ⬜ 마케팅 수신           (선택)  미동의                  │ │
│ │ ⬜ 임상연구 활용         (선택)  미동의                  │ │
│ │                                                        │ │
│ │ ⚠️ 필수 동의 2건 미완료 — 접수 불가                      │ │
│ │                                                        │ │
│ │ [동의서 출력]  [포털 동의 요청]  [전체 동의 체크]        │ │
│ └────────────────────────────────────────────────────────┘ │
│                                                           │
│ [접수 완료]  ← 필수 동의 미완료 시 비활성화                  │
└───────────────────────────────────────────────────────────┘
```

### 4.2 동의서 출력

"동의서 출력" 클릭 시:
- 미동의 항목만 출력 (이미 동의된 항목은 제외)
- A4 1~2장, 법정 전문 + 서명란 + 병원 로고
- 종이 서명 후 원무과가 HIS에서 체크

### 4.3 포털 동의 요청

"포털 동의 요청" 클릭 시:
1. 환자에게 Push 알림 전송: "접수 동의서 서명이 필요합니다"
2. 포털/모바일 앱에서 동의서 전문 표시
3. 각 동의서별 서명 패드 서명
4. 서명 완료 시 HIS 실시간 반영 (SSE)
5. 전체 필수 동의 완료 시 "접수 완료" 버튼 활성화

## 7. 이벤트 흐름

```
① 원무과 → POST /patients/:id/registration-consents
   (type: PRIVACY, agreed: true, signMethod: PAPER)
   → DB: RegistrationConsent 생성
   → JourneyEvent: REGISTRATION_CONSENT_COLLECTED

② 원무과 → POST /patients/:id/registration-consents/send-portal
   → Push 알림: "접수 동의서 서명이 필요합니다"
   → PatientNotification 생성
   → SSE: HIS에 "알림 전송 완료" 표시

③ 환자 → PUT /portal/registration-consents/:type/sign
   (signatureData: Base64, signMethod: PORTAL)
   → DB: RegistrationConsent 업데이트
   → emit('registration.consent.signed')
   → SSE → HIS 실시간 반영
   → JourneyEvent: REGISTRATION_CONSENT_SIGNED

④ 전체 필수 동의 완료
   → emit('registration.consent.complete')
   → HIS: "접수 완료" 버튼 활성화
```

## 8. 동의서 PDF 출력

### 8.1 출력 규격

- A4 세로, 1~2페이지
- 병원 로고 + 병원명 상단
- 각 동의서 전문 (법률 근거 포함)
- 환자 서명란 (가로 10cm 실선)
- 법정대리인 서명란 (미성년자용)
- 접수일자, 병원 직인

### 8.2 출력 시나리오

| 상황 | 출력 범위 |
|------|----------|
| 초진 (전체 미동의) | 7종 전체 출력 |
| 초진 (일부 포털 서명 완료) | 미서명 항목만 출력 |
| 재진 (갱신 필요) | 만료된 항목만 출력 |
| 포털 비가입 환자 | 7종 전체 출력 (종이 필수) |
