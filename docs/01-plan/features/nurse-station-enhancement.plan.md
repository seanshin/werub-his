## 1. 현황 분석

### 현재 상태
- 환자 대기열 (10초 자동 새로고침)
- 환자 선택 → 우측 상세 (기본)
- Stats 카드 4개 (담당의사, 예약, 완료, 진행중) — 모두 0

### 부족한 기능

| 간호사 핵심 업무 | 현재 | 필요 |
|---------------|:---:|:---:|
| **활력징후(VS) 측정·기록** | ❌ | 체온/혈압/맥박/호흡/SpO2 + 통증 + BMI |
| **투약 관리 (MAR)** | ❌ | 예정 투약 목록 + 투약 확인 + 시간 기록 |
| **I/O (섭취/배설) 기록** | ❌ | 수액/경구/배뇨/배변/드레인 |
| **낙상/욕창 위험도** | ❌ | Morse/Braden 점수 + 색상 배지 |
| **간호 기록 (NNote)** | ❌ | SBAR 형식 기록 + 인수인계 |
| **처치/드레싱 기록** | ❌ | 상처관리, IV 교체, 카테터 관리 |
| **환자 라운딩 체크** | ❌ | 시간별 라운딩 체크리스트 |
| **알림/알람** | ❌ | 투약 시간, 검사결과 도착, 의사 오더 |
| **병동 보드** | ❌ | 병실별 환자 현황 한눈에 |
| **인수인계 (Handoff)** | ❌ | 교대 시 SBAR 요약 자동 생성 |

## 3. 핵심 기능 상세

### 3.1 활력징후 기록

- 일괄 기록 모드: 병실 순회 시 여러 환자 VS를 한 화면에서 입력
- 자동 이상치 감지: BP>140/90, HR>100, BT>38.0, SpO2<95 → 빨간 배지 + 알림
- VS 추이 차트 (환자별 시계열)
- 측정 간격: 일반 4h, 수술후 1h, 중환자 15min

### 3.2 투약 관리 (MAR)

- 시간별 투약 스케줄 (간트 차트 형태)
- 투약 확인 버튼 → 시간 + 간호사 ID 자동 기록
- 미투약 알림 (예정 시간 경과 시 빨간 표시)
- PRN(필요시) 투약 기록
- 마약류 이중 확인 연동 (ControlledSubstanceLog)

### 3.3 I/O 기록

- 섭취: IV수액, 경구, 혈액, 영양(TPN)
- 배설: 소변, 배변, 구토, 드레인, 출혈
- 시간별 누적 + 24시간 총합
- 불균형 알림 (양성 >500mL 또는 음성 >500mL)

### 3.4 병동 보드

- 병실 그리드 (카드 형태)
- 각 환자: 이름, 상태(색상), 주진단, 입원일수, 다음 VS/투약, 낙상/욕창 위험도
- 빈 병상 표시
- 실시간 업데이트 (SSE/polling)

### 3.5 인수인계

- SBAR 형식 자동 생성 (환자별)
- 교대 시간별 요약 (Day→Evening→Night)
- 주의 환자 하이라이트 (고위험, 수술후, 새 입원)
- 인수인계 서명 (전자서명 연동)

## 4. 데이터 모델 활용

### 이미 있는 모델
- `MedicationAdministration` — 투약 기록 (MAR)
- `FallRiskAssessment` — 낙상 위험 평가
- `RiskReassessmentSchedule` — 재평가 스케줄
- `NursingAssessment` — 간호 사정
- `ClinicalHandoff` — 인수인계
- `Admission` + `Bed` — 입원/병상

### 추가 필요
- VS 일괄 기록 API
- I/O 기록 모델 (또는 기존 NursingNote 확장)
- 병동 보드 집계 API

## 5. 구현 단계

| Phase | 내용 | 예상 |
|-------|------|------|
| **Phase 1** | 내 환자 탭 보강 (VS 요약, 투약 대기, 낙상 배지) | 중 |
| **Phase 2** | 투약 관리(MAR) 탭 | 대 |
| **Phase 3** | 활력징후 탭 (일괄 기록 + 이상치 알림) | 중 |
| **Phase 4** | I/O 기록 탭 | 중 |
| **Phase 5** | 간호 기록 (SBAR) 탭 | 중 |
| **Phase 6** | 병동 보드 탭 | 대 |
| **Phase 7** | 인수인계 + 알림 | 중 |
