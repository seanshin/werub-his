## §2 설계

### 2.1 로케일 정본 (shared 신설)

```
packages/shared/src/i18n/
  locale.ts        — UI_LOCALES = ['ko','en','ja','ar'] · UiLocale · UI_LOCALE_LABEL(자국어 표기: 한국어/English/日本語/العربية)
                     · LOCALE_DIR: {ar:'rtl', 그 외 'ltr'} · UI_LOCALE_UNVERIFIED_TAG(미검수 티 어휘)
  messages/
    common.ts      — 공통(버튼·빈상태·에러문구)
    nav.ts         — NAV_SECTIONS 283
    status.ts      — shared 라벨 71 Record 443항목의 en/ja/ar 층
    <area>.ts      — P2 영역별 파일(병렬 에이전트 소유권 단위 — 충돌 회피)
  t.ts             — t(key, locale): 미등록 키는 **한국어 원문 반환 + missing 플래그**(조용한 폴백 금지 — 포털 CATALOG 함정 반복 안 함)
```

- **키 = 한국어 원문**(portal-i18n 선례): 추출 자동화가 쉽고, ko 는 카탈로그 자체가 필요 없다(원문=정본). 중복 원문은 자동 병합.
- **동음이의 충돌**: 같은 원문이 문맥별로 다른 번역이 필요하면 `원문@문맥` 키(예: `접수@원무`·`접수@신고`) — t() 는 `@` 뒤를 표시에서 제거. 기본은 무문맥 키(충돌 시에만).
- **경계**: BE 응답 메시지(에러·토스트 원문)는 이번 스코프 **밖**(한국어 유지·P3+ 등재만) — FE 크롬이 대상이다. AI 초안 생성은 런타임이 아니라 **스크립트**(`scripts/i18n-draft.mjs` — 엔진 호출→카탈로그 파일 생성→사람이 커밋).
- 기존 `X_LABEL` Record 71개는 **시그니처 불변**(ko 정본 유지) — `status.ts` 가 같은 값 문자열을 키로 en/ja/ar 층을 든다. 소비처가 깨지지 않고, 라벨을 고치면 카탈로그 키가 어긋나 **가드가 잡는다**(§5).

### 2.2 3상태 정직성 — 지어낸 번역 금지

| 상태 | 표기 | 생산 경로 |
|---|---|---|
| `VERIFIED` | 그대로 표시 | 사람 검수 완료 |
| `AI_DRAFT` | 표시 + 미검수 티(툴팁: AI 초안·`AI_ORIGIN_TEXT` 병기 — AI기본법 §31) | 온프레미스 번역 엔진 일괄 초안 |
| (미등록) | **한국어 원문 그대로** + `JA×`/`AR×`/`EN×` 티(term-display EN× 패턴 준용) | — |

- 임상 안전 문구(경보·게이트 차단·복약)는 `safetyCritical: true` 로 분류 — **검수 전(AI_DRAFT)에는 한국어 원문을 병기**한다(오역이 안전사고가 되는 자리).
- 검수 상태는 카탈로그 메타(`verified: Set<key>`)로 코드에 든다 — 검수는 커밋으로 남는 사람 행위.

### 2.3 저장 2층 (기존 구조 재사용)

- 직원 개인: `UserUiPreference.uiLocale VarChar(8)?`(명시 컬럼 규약 — JSON 슬롯 금지) + `ui-preferences` EP 확장 + `ui-locale-store`(term-lang-store 미러: localStorage `ui.locale` + 서버 우선·실패 시 "이 기기에만 저장됨" 토스트).
- 기관 기본: `hospital.defaultUiLocale`(신설·기본 `'ko'`) — 개인 미설정 시 이것. `hospital.country` 에서 **파생 제안만**(KR→ko·AE→en 제안 — 🔴 AE 기관 공용어는 단정하지 않는다·기관이 확정). **`emr.locale` 은 키 폐기**(소비처 0·중복 정본 — R9 ⑤⑥ 선례·unwired 기준선 42→41).
- 전환 UI: TopBar 에 언어 셀렉트(🌐 + 자국어 표기) — 용어 토글과 시각 구분(용어="의료코드"·언어="화면 언어" 힌트).

### 2.4 lang·dir·폰트

- `<html lang>` 동적화 대신 **본문 래퍼 `<div lang dir>`**(zh/layout 우회 선례 — 전역 동적 렌더 비용 회피). `(main)` layout 에서 locale 반영.
- 폰트: Pretendard 유지 + `lang` 별 폴백 스택 추가(`Noto Sans JP`·`Noto Sans Arabic` — self-host 또는 jsdelivr, OFL). P1.
- 🔴 **아랍어는 표기만 — 레이아웃 LTR 유지**(2026-09-07 사람 결정). 화면이 그 사실을 고지한다(언어 선택 UI) — 물리 유틸 3,970 을 감춘 채 완성인 척하지 않는다.
- 🔴 **표기만 해도 문자열 안 방향은 필요하다**: 아랍어 번역 2,404건 중 **179건이 라틴 약어·숫자 혼합**(PACU·CPOE·QR…)이라 LTR 컨테이너에 그대로 두면 괄호·약어가 뒤집혀 보인다. `<T>`·`StatusBadge` 가 `dir="auto"` 를 부여해 **그 문자열의 base direction 만** 정한다(주변 레이아웃 불변 — RTL 웨이브와 무관하게 안전). ko 는 DOM 동일성 규약이라 미부여.
- 향후 RTL 을 켤 때 필요한 것(등재만): 물리→논리 유틸 codemod(일괄 치환 위험 — 좌측 고정 사이드바·차트 축은 의도적 물리)·절대위치/아이콘/transform 수동 검토·임상 수치 BiDi 격리(`<Num>`·`KDate`·코드 배지에 `<bdi>`).

### 2.5 날짜·숫자·통화

- `ui-settings.tsx` 의 `ko-KR` 4줄 → locale 인자화(`localeTag(): 'ko-KR'|'en-US'|'ja-JP'|'ar-AE'` — 숫자는 **서구 아라비아 숫자 유지**·`nu-latn`, 임상 수치 오독 방지). `<KDate>` 42파일·`<Money>` 30파일이 자동 승계.
- 통화 표기·절사는 **불변**(locked 정책 — ₩/10원 절사는 건보법). AED 등 타국 통화는 §6 사람 결정.
- 원시 `toLocale*` 565곳은 P2 롱테일에서 부품 수렴(기존 display 부품 채택 확대 — 별도 기준선).

### 2.6 검수 관제 — `/admin/ui-locale`

미검수/미번역은 **줄어드는 워크리스트**: 언어별 미등록 키 수·AI_DRAFT 수·VERIFIED 수(분모 병기), safetyCritical 미검수 상단 고정, AI 초안 일괄 생성 버튼(온프레미스 엔진 — `{attempted, translated, failed(reason)}` 정직 결과), 검수 반영은 **카탈로그 파일 수정 커밋**(화면은 export/다운로드 보조 — 화면에서 코드 정본을 직접 쓰지 않는다).

**파일 끝까지 문자열로 간주**한다 → 그 파일의 `ko`(한글 조각)·`t`(배선 수) 집계가 통째로 무의미해진다.

실측: `apps/web/src/app/(main)/pharmacist-activity/page.tsx:187` 이 그 자리였다. 담당 갈래가 코드모드로
배선했을 때 **3건만 잡혔고**(실제로는 112건 이상), 초기 `ko` 314 도 과대 계상이었다.

🔴 **영향**: 이 스캐너는 여러 가드의 계측 정본이다(`i18n-exclusion-vs-gap`·각 라운드의 화면별 잔여 기준선).
같은 패턴이 있는 다른 파일의 기준선도 허수일 수 있다 — **"기준선이 초록"이 "그 화면이 배선됐다"를 뜻하지 않는다.**

미수정 이유: 고치면 전 화면의 `ko` 수치가 바뀌어 이번 라운드에 갈래 8기가 각자 정확 동결한 기준선이
한꺼번에 깨진다. **라운드 합류 후 한 번에** 고치고 기준선을 재동결한다(그때 `--json` 전후 비교를 남긴다).

고칠 방법: `stripComments` 에 `regex` 모드를 추가한다. 직전 유의미 문자가 `( , = : [ ! & | ? { } ; return`
등이면 `/` 를 정규식 시작으로 보고, 문자 클래스 `[...]` 안의 `/` 를 무시하며 이스케이프를 건너뛴다.

### 수정 결과 (2026-09-09 · 라운드 합류)

🔴 **`regex` 모드만 추가한 첫 수정본이 오히려 더 틀렸다** — 그 상태로 트리에 남아 있었고, 기준선 5개가 빨간
채였다. TSX 는 `/` 가 네 가지로 쓰인다: 나눗셈·정규식·JSX 닫는 태그 `</div>`·JSX 자기닫기 `/>`.
직전 문자만 보고 판정하면 뒤 셋이 전부 정규식이 된다.

| 교정 | 무엇을 막나 | 실제로 깨져 있던 자리 |
|---|---|---|
| `REGEX_ALLOWED_PREV` 에서 `<` 제거 | `</span>` 의 `/` 를 정규식으로 읽음 | `orders/page.tsx:511` `<span>⚠️</span> <T k="DUR/CDSS만" />` → 그 뒤 300줄의 주석이 코드로 남음 |
| `/>` 예외 | `<T k={label} />` 의 `}` 뒤 `/` | `safety`·`billing/[id]`·`blockchain-cert` |
| 정규식 모드가 백틱을 만나면 **템플릿으로** 복귀 | 코드로만 되돌리면 닫는 백틱이 템플릿을 '여는' 것이 됨 | `crm/campaigns/[id]:109` `{a} / {b} {c ? \`/ ${d}\` : ''}` |
| 템플릿 `${...}` 안을 코드로 추적(스택) | 보간 안의 주석이 코드로 남음 | `admin/rbac:219` |
| 문자열(`'`·`"`)은 줄을 넘지 못한다 | 오탐 하나가 파일 끝까지 삼키는 것을 **한 줄로 가둠** | 전역 |

**`--json` 전후 비교**(전 784파일): `ko` 합계 **17,118 → 17,087**. 수치가 달라진 파일은 **4개뿐**이고
전부 계측 교정이다 — `pharmacist-activity` 106→72(§11 의 원 사례)·`admin/controlled-substance` 99→80·
`admin/rbac` 5→3·`workstation/consent` 55→**56**(늘었다).

🔴 **첫 수정본으로 잰 값은 17개 파일이 달랐다**(그중 13개가 위 결함이 만든 허수). "고쳤다"를 믿고 기준선을
재동결했다면 허수를 정본으로 굳힐 뻔했다.

기준선 재동결 2건(둘 다 **하향** — 화면이 아니라 계측이 고쳐졌다): `quality2` pharmacist-activity 106→72,

**남은 것**: 주석 누수 5파일(`break-glass`·`controlled-substance`·`emergency`·`patients/[id]/encounter/new`·

## §10 🔴 배선이 가드를 죽인다 (2026-09-09 실측 · P3 라운드)

이 저장소의 여러 정직성 가드가 **화면 소스의 한국어 문구를 직접 읽어** 판정한다
(예: `apps/api/test/architecture/self-gated-screen-fit.spec.ts` 가 `apps/web/src/app/(main)/orders/page.tsx` 를 읽는다).
i18n 배선이 그 문구를 `<T k="원문" />`·`tOf('원문')` 로 바꾸면:

| 단언 형태 | 배선 후 | 위험 |
|---|---|---|
| `expect(s).toMatch(/처방 서명 완료 · \$\{billingMsg\}/)` | **실패** | 눈에 띈다(그나마 낫다) |
| `expect(s).not.toContain("toast.success('처방 완료 (서명+수납)')")` | 🔴 **조용히 통과** | 가드가 죽었는데 초록이다 |

규약(이 라운드부터):
1. 화면을 배선하면 **web 가드만이 아니라 `apps/api` 의 `test/architecture` 도 돌린다** — api 쪽 가드가 web 소스를 읽는 경우가 있다.
2. 깨진 가드는 기준선을 낮추거나 단언을 지우지 않는다. `<T k="원문">`·`tOf('원문')` 형태도 찾도록 **패턴을 넓힌다**(원문이 키로 그대로 남아 있으므로 검색 가능하다).
3. 부정 단언은 "그 문구가 **어떤 형태로도** 없다"를 유지하도록 고친다.
4. 판단이 서지 않으면 그 화면을 배선하지 않고 남긴다 — **가드를 죽이는 배선보다 미배선이 낫다**(미배선은 목록에 남아 보이지만, 죽은 가드는 보이지 않는다).

관련: `docs/01-plan/features/screen-walkthrough-audit.plan.md` P1 · CLAUDE.md §3(통과가 보증이 아니다).

## §9 언어 팩 구조 — 새 언어를 파일 하나로 (2026-09-07 사람 지시)

### 9.1 문제

종전 구조에서 언어를 하나 늘리려면 **영역 카탈로그 11개 파일**(`messages/*.ts`)을 전부 열어
각 파일의 `en/ja/ar` 옆에 새 언어를 끼워야 했다. 언어가 늘수록 파일이 넓어지고, **한 파일만
빠뜨리면 그 영역만 조용히 미번역**이 된다(P2 에서 실제로 겪은 함정).

### 9.2 구조

```
i18n/pack.ts          LocalePack{code,label,dir,tag,status,messages,verified,note}
                      registerLocalePack / activeLocalePacks / packLookup / packCoverage
i18n/packs/<code>.ts  ← **새 언어는 여기 파일 하나**
i18n/packs/index.ts   ← 등재 한 줄
i18n/messages/*.ts    기존 영역 카탈로그 → **빌트인 팩으로 자동 조립**(데이터·우선순위 불변)
```

- `t()` 조회: ① 팩 → ② 빌트인 카탈로그 → ③ 원문+티. 새 언어는 ①로 즉시 붙는다.
- **부분 번역이 정상**이다 — 없는 키는 한국어 원문 + 미번역 티(§2.2 그대로).
- 같은 코드 재등록은 **병합**(확장 팩·부분 보정을 따로 둘 수 있다).
- 🔴 **팩을 넣는다고 선택지에 뜨지 않는다** — `status: 'ACTIVE'` 여야 한다. 번역만 있고
  레이아웃(RTL)·검수자가 없는 언어를 고르게 두면 "쓸 수 있는 것"으로 읽힌다(§8 아랍어 사례).

### 9.3 조립 실측·회수

**`common` 65키 누락**을 실측으로 잡았다 — 화면은 빌트인 카탈로그 경로로 여전히 찾아내 **증상이

## §8 아랍어권 — **별도 에디션 트랙** (2026-09-07 사람 결정 2건 · 전용 정본 `arabic-rtl-track.plan.md`)

### 8.1 결정과 이유

🔴 **2026-09-07 사람 결정: 아랍어는 이 축에서 분리해 별도 진행한다.**

2. **부채가 남는다** — 뒤집어도 신규 화면이 다시 `ml-`을 쓰면 원위치다.
3. **아랍어 기관은 화면 요구가 다르다** — 관할(DHA·DoH·MOHAP)·서식·동선이 KR 과 달라(개원 축 실측)

| `1,918만원` | `만원@단위` **미등재** → 원문 폴백 | 등재(`×10k KRW`). 🔴 값·자릿수는 불변 — money 는 잠금 도메인이라 **단위 낱말만** 다뤘다. 🧑 표시 정책이라 사람 검수 대상 |
| `4개월 전` | `개월 전@단위` 미등재 | 등재(`months ago`) — 숫자에 붙는 꼬리라 단위 어휘로 다룬다 |
| 행 액션 툴팁·`aria-label`(전 화면) | 공용 부품 `RowAction` 이 `label`·`hint` 를 **생문자열로** 그림 | `<T>`·`tAttr` 배선 — 공용이라 전 화면에 걸린다 |

🔴 **이 축에서 가드가 세 번 나를 잡았다**(전부 재주입으로 확인):
1. `갱신` 을 새로 등재했더니 앞 카탈로그가 이미 가져 **죽은 키**였다.
2. `{초}초 전` 류가 **고아 키**로 잡혔다 — 이제 키를 만드는 곳이 **shared** 인데 가드는 web 만 훑었다.
   범위를 넓히되 **카탈로그 파일 자신은 제외**했다(카탈로그에 있다는 사실로 "쓰인다"고 하면 검사가 무의미해진다).
3. 🔴 그 뒤 재주입이 **통과**했다 — 원인은 주입이 아니라 **가드의 기존 허점**이었다:
   `@` 로 **시작하는** 키는 `bare` 가 빈 문자열이 되어 `includes('')` 가 늘 참이라,
   **어떤 고아 키든 앞에 `@` 만 붙이면 검사를 빠져나갔다.** 고치고 두 형태 모두 물리는 것을 확인했다.
4. `<Unit>명</Unit>` 을 대시보드 가드가 **생한글로** 셌다 — 배선한 형태인데 실패한다. 기준선을 올리지 않고
   패턴을 넓혔고, **진짜 생한글을 주입하면 여전히 잡히는 것**을 확인했다(넓힌 것이 완화가 아님).

### G. 🔴 서버가 조립한 표시 문장은 로케일을 모른다 (전수 조사 완료 · 1건 회수 · 기준선 동결)

`safety-quality-board.service.ts` 가 QI 캡션을 **한국어 문장으로 만들어** 내려준다:
`지표별 최신 측정(기간 무관) 기준 · 최신 측정 시점 2026-05 — 이번 달(2026-09) 측정 아님, 4개월 전`.
화면은 그 문자열을 그대로 그리므로 **어떤 언어를 골라도 한국어로 남는다.**

🔴 카탈로그로는 못 고친다 — 서버가 값(기간·경과 개월)을 문장에 녹여 보내기 때문이다.
고치려면 **서버가 조각(period·isCurrent·staleMonths)을 주고 화면이 조립**해야 한다(그 값들은 이미 응답에 있다).
같은 형태가 다른 서비스에도 있을 수 있어 **전수 조사가 필요하다** — 이 항목은 열어 둔다.

#### 전수 조사 결과 (2026-09-10)

`apps/api/src` 1,314파일에서 **한글 + 보간이 함께 든 템플릿 리터럴**을 셌다(주석 제거 후).

| 구분 | 수 | 뜻 |
|---|---:|---|
| 전체 | 2,337 | 한글+`${}` 템플릿 |
| 로그(`logger.`·`console.`) | 562 | 화면에 나가지 않는다 — 이 축 대상 아님 |
| **나머지(가드 대상)** | **1,774** | 예외 메시지·내부 계산·표시 문장이 섞여 있다 |

🔴 **이 수는 상한이지 "결함 1,774건"이 아니다.** 화면에 실제로 닿는지는 한 건씩 봐야 안다 —
그래서 "N건이 결함"이라 말하지 않고, **늘지 않는다** 하나만 가드로 지킨다
(`apps/api/test/architecture/server-composed-display-text.spec.ts` · 재주입 역검증 완료).

🔴 **내 분류기도 틀렸다** — 처음엔 필드명(`note:`·`label:` 등)으로 갈라 `display 506` 이라 셌는데,
정작 **아는 사례(QI 각주)가 그 분류에 안 들어왔다**(변수에 담았다가 응답에 넣는 형태였다).
대조군으로 확인하지 않았으면 506 을 정답처럼 보고할 뻔했다.

#### 회수한 1건

`safety-quality-board.service.ts` 의 `qiBasis` — 서버가 만들던 문장을 **없앴다**. 조각
(`qiLatestPeriod`·`qiIsCurrentPeriod`·`qiStaleMonths`)은 원래 응답에 있었고, 조립은 화면이 한다
(`command-center-view.ts` `boardNote` → 키+파라미터 → `<Tf>`). 경과 개월을 모르면 그 조각을
빼고 말한다(지어내지 않는다). api 스펙도 **문장이 아니라 조각**을 못박도록 바꿨고,
"서버가 다시 문장을 만들면 실패"하는 단언을 넣었다.

이전 라운드가 `dashboard.ts` 주석에 이 문장을 **"서버 생성 — 의도적 제외"**로 적어 두었다.
제외 목록은 그때는 맞았지만 **고칠 수 있게 되면 목록에서 내려야 한다** — 그 메모도 함께 갱신했다.
