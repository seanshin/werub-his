## 1. 역할 설계

### 1-1. 새 역할 정의

현재 UserRole: `ADMIN | DOCTOR | NURSE | PHARMACIST | LAB_TECH`

추가 필요:

| 역할 | 코드 | 대상 | 권한 |
|------|------|------|------|
| **CEO** | EXECUTIVE | 이사장/원장 | 경영 전체 현황 (읽기), 설정 없음 |
| **CMO** | CMO | 의료원장/진료부원장 | 진료 통계 + 의료 품질 + 인력 |

> 초기 구현은 **기존 ADMIN 역할 + 별도 대시보드 라우트**로 처리 (UserRole 변경 최소화)
> 경영진 계정에 `executiveRole` 플래그를 Staff 모델에 추가

## 3. 전용 사이드바

경영진 대시보드는 **별도 레이아웃** 또는 **별도 메뉴 그룹**으로 구성.

### 3-1. 경영진 사이드바 메뉴

```
경영 대시보드
├── 경영 현황          /executive
├── 의료 품질          /executive/clinical
├── 재무/수납          /executive/finance
├── 인력 현황          /executive/staff
├── KPI 관리          /executive/kpi
└── 리포트            /executive/reports
```

### 3-2. 접근 방식

기존 사이드바에 **경영진** 섹션 추가 (ADMIN 역할 중 executive 플래그):

```
관리자
  ...
  경영 대시보드         ← 신규 (경영진만)
  의료 품질 대시보드     ← 신규 (경영진만)
```

## 4. 데이터 소스

### 경영 대시보드

| 위젯 | API | 비고 |
|------|-----|------|
| 오늘 매출 | `/api/v1/billings?status=PAID` sum | 기존 |
| 미수납 | `/api/v1/billings?status=PENDING` sum | 기존 |
| 주간 매출 추이 | `/api/v1/billings` 집계 | 신규 집계 API 필요 |
| 월간 진료 추이 | `/api/v1/encounters` 월별 집계 | 신규 집계 API 필요 |
| 부서별 실적 | `/api/v1/encounters` + `/api/v1/billings` 부서별 | 신규 집계 API |
| 인력 현황 | `/api/v1/hr/staff` | 기존 |
| 병상 가동률 | `/api/v1/beds/status` | 기존 |
| 보험 청구 | `/api/v1/claims/summary` | 기존 |
| 재고 부족 | `/api/v1/inventory` | 기존 |
| KPI | 신규 KPI 모델 or 집계 | 신규 |

### 의료 품질 대시보드

| 위젯 | API | 비고 |
|------|-----|------|
| 오늘 진료 현황 | `/api/v1/dashboard/overview` | 기존 |
| 의료진별 실적 | 신규 집계 API | 의사별 진료건수/대기/미완료 |
| 안전사고 | `/api/v1/safety/incidents` | 기존 |
| 감염관리 | `/api/v1/infection/stats` | 기존 |
| QI 지표 | `/api/v1/quality/dashboard` | 기존 |
| 교육 현황 | `/api/v1/education/expiring` | 기존 |

## 5. 구현 순서

### Phase 1: 계정 + 경영 대시보드 (바로 가능)
1. 경영진 계정 3개 시드 (홍원장/김이사장/박의료원장)
2. 로그인 퀵 선택에 추가
3. `/executive` 경영 대시보드 페이지 (기존 API 활용)
4. 사이드바에 경영 대시보드 메뉴 추가

### Phase 2: 의료 품질 대시보드
5. `/executive/clinical` 의료 품질 대시보드
6. 의료진별 실적 집계 API

### Phase 3: 집계 API + KPI
7. 주간/월간 매출 집계 API
8. 부서별 실적 집계 API
9. KPI 모델 + 대시보드

## 6. 기대 효과

| 대상 | 현재 | 개선 후 |
|------|------|---------|
| 병원장 | HIS에 경영 뷰 없음 | 매출/환자/KPI 한눈에 |
