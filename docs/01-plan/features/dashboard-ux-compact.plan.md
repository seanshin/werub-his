## 1. 현황 분석

### 1.1 스크린샷 기반 문제점

| 영역 | 현재 상태 | 문제 |
|------|----------|------|
| **환자 센서스 카드** | 카드당 세로 ~80px, p-3 + space-y-2 | 5명만 표시해도 400px 차지. 3줄(이름/진단/하단정보)로 세로 낭비 |
| **오늘 진료표** | 오전/오후 2줄 + 빈 공간 | 데이터 2줄인데 카드 높이 ~200px. 공간 60% 낭비 |
| **미완료 차트** | 리스트 항목당 ~44px | 환자명+날짜만 표시하는데 amber-50 배경 + p-2.5로 과도한 여백 |
| **담당 입원환자** | 항목당 ~44px, indigo-50 배경 | 병동+이름+진단을 한 줄에 표시하지만 패딩 과다 |
| **오늘 수술 일정** | 데이터 없을 때도 카드 높이 유지 | "없습니다" 텍스트에 ~150px 공간 낭비 |
| **카드 공통** | rounded-2xl(16px), p-6(24px), gap-4 | HIS는 정보 밀도가 중요. 16px 라운딩과 24px 패딩은 소비자 앱 수준 |
| **MiniStat 상단바** | 5칸 grid, 각 px-3 py-2.5 | 적절하나 숫자(text-xl)가 크고 레이블(text-[10px])이 작아 불균형 |

| 항목 | 현재 | 이상적 |

| 환자 행 높이 | ~72px (3줄) | ~36px (1줄 핵심정보) |

## 2. 개선 방안

### 2.1 환자 센서스 카드 (MyCensusPanel) — 최우선

**현재**: 카드형 레이아웃, 환자당 3줄 (이름/진단+바이탈/하단메타)

**개선**: 테이블형 컴팩트 행

```
Before (80px/환자):
┌─────────────────────────────────────────────────────┐
│ ● 안정  김영수  (M/7일)              3층 내과병동 301-A │
│ 고혈압 급성 악화 + 심부전 관리                         │
│ 미확인 검사 1건  처방 6건                              │
└─────────────────────────────────────────────────────┘

After (36px/환자):
┌──┬──────┬─────┬───────────────┬─────────────┬────────┬──────────┐
│안정│김영수│M/7일│고혈압+심부전   │BP130/85 HR78│검사1 Rx6│3층301-A  │
└──┴──────┴─────┴───────────────┴─────────────┴────────┴──────────┘
```

**구체 변경사항**:
- `space-y-2` → `divide-y divide-gray-100`
- 카드 내부 3줄 → 1줄 flex (배지 | 이름 | 성별/재원일 | 진단 truncate | 바이탈 축약 | 미확인+처방 | 병실)
- `p-3 rounded-xl` → `px-3 py-2 hover:bg-gray-50`
- 바이탈: 모든 항목 → BP + HR만 (SpO2는 <95%일 때만)
- 하단 메타정보(회진시간, 간호기록) → 호버 툴팁 또는 제거
- 상태 배지: `text-[10px] px-2 py-0.5` → `text-[9px] px-1.5 py-px` 최소화
- border-l-4 제거 → 배지 색상으로 충분

**예상 절감**: 환자 5명 기준 400px → 200px (**50% 감소**)

### 2.2 오늘 진료표 + 미완료 차트 (2-column 영역)

**현재**: 각각 독립 카드, p-6, 내부 여백 과다

**개선**:
- `p-6` → `p-4`
- 진료표: 오전/오후를 한 줄로 합침
  - `오전 09:00~12:30 | 오후 없음` (현재 2줄 → 1줄)
  - 진료실 배지를 헤더 옆으로 이동
- 미완료 차트:
  - `p-2.5 rounded-xl bg-amber-50` → `py-1.5 px-2 border-b border-gray-50`
  - 환자명과 날짜를 같은 줄에 더 컴팩트하게
  - 이유(chiefComplaint)는 제거하거나 truncate 짧게

**예상 절감**: 카드당 ~40px 절감

### 2.3 담당 입원환자 + 오늘 수술 일정 (2-column 영역)

**개선**:
- `p-6` → `p-4`
- 입원환자 행: `p-2.5 rounded-xl bg-indigo-50` → `py-1.5 px-2`
  - 배경색 제거, 밑줄(border-b)로 구분
  - 병동+이름을 더 촘촘하게
- 수술: 동일 패턴 적용
- "데이터 없음" 상태: `py-4` → `py-2` 최소화
- "회진 시작 →" 링크: 하단 별도 줄 → 헤더 우측으로 이동 (이미 "전체 보기 →" 있으므로 통합)

### 2.4 검사결과 도착 (전폭 카드)

**개선**:
- 전폭이 아닌 2-column 중 하나로 편입 (대기환자와 같은 행)
- 행 높이: `p-2.5 rounded-xl` → `py-1.5 px-2 border-b`
- 검사/영상 배지 + 환자명 + 검사명을 더 컴팩트하게

### 2.5 MiniStat 상단바

**개선**:
- 숫자 `text-xl` → `text-lg`로 약간 축소
- `py-2.5` → `py-2`
- 전체 mb-6 → mb-4

### 2.6 카드 공통 스타일 통일

| 속성 | 현재 | 개선 |
|------|------|------|
| border-radius | rounded-2xl (16px) | rounded-xl (12px) |
| padding | p-6 (24px) | p-4 (16px) |
| 카드 간 gap | gap-4 (16px) | gap-3 (12px) |
| 섹션 간 margin | space-y-4, mt-6 | space-y-3, mt-4 |
| 헤더 margin-bottom | mb-4 | mb-2 |
| 제목 아이콘 | w-5 h-5 | w-4 h-4 |
| shadow | shadow-sm | 제거 (border만 유지) |

### 2.7 차트 영역 (DashboardCharts)

**개선**:
- `height={200}` → `height={160}` 차트 높이 축소
- 4개 차트 중 의사에게 불필요한 "부서별 환자 분포" 도넛차트 → 의사 역할에서 숨기거나 축소
- 차트 카드도 `p-5` → `p-4`, `rounded-2xl` → `rounded-xl`

### 2.8 레이아웃 재배치 (선택)

현재 순서: stat바 → 센서스 → 진료표+미완료차트 → 입원+수술 → 검사결과 → 차트 → 바로가기+접속정보

**제안 순서** (임상 워크플로우 기반):
1. stat바 (현행 유지)
2. 센서스 (컴팩트화)
3. **3-column**: 진료표(1) + 미완료차트(1) + 대기환자(1)
4. **2-column**: 입원환자 + 수술/검사결과
5. 차트 (축소)
6. 바로가기 + 접속정보 (현행)

→ 진료표가 데이터 적으므로 1/3 폭이면 충분, 미완료차트와 대기환자를 같은 행에 배치

## 5. 디자인 원칙

1. **HIS는 정보 도구**: 소비자 앱의 넉넉한 여백이 아닌, 데이터 밀도 우선
2. **한 화면에 더 많이**: Above-the-fold에 센서스 전체 + 진료표 + 미완료차트
3. **색상은 의미 전달용**: 배경색 남발 대신 텍스트 색상/배지로 구분
4. **호버로 상세 정보**: 기본 뷰는 핵심만, 상세는 마우스오버
5. **기존 기능 100% 보존**: 정보 제거 없이 표현 방식만 변경
