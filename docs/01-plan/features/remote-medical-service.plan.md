## 1. 기획 배경

### 1.1 왜 "소통"이 아닌 "비대면 진료"인가

현재 포털의 "소통" 탭은 단순 메시지함이지만, 실제로 환자가 의사에게 증상을 묻고 답변을 받는 행위는 **의료법상 원격의료**에 해당합니다.

```
[기존] 소통 탭 = 단순 메시지 (법적 모호)
                    ↓
[변경] 비대면 진료 = 원격의료 행위 (의료법 제34조)
       ├── 텍스트 상담   (비동기 메시지)
       ├── 화상 진료     (실시간 영상통화)
       ├── 결과 전달     (검사결과 설명 + 판독소견)
       └── 처방/지시     (복용 안내 + 생활 지도)
```

### 1.3 기존 "화상진료"와 "비대면진료"의 관계

기존 HIS의 "화상진료"(`/telehealth`)는 **Jitsi 기반 실시간 영상통화만** 제공합니다.
"비대면진료"는 이를 포함하는 **상위 개념**으로, 별도 카테고리로 운영합니다.

```
┌─────────────────────────────────────────────────────────────┐
│  HIS 메뉴 구조                                               │
│                                                              │
│  기존:                                                       │
│  ├── 화상진료 (/telehealth)          ← Jitsi 영상통화만      │
│  └── (소통 기능 없음)                                        │
│                                                              │
│  변경:                                                       │
│  ├── 화상진료 (/telehealth)          ← 기존 유지 (Jitsi)     │
│  │    └── 실시간 영상 진료 전용                               │
│  │                                                           │
│  └── 비대면진료 (/remote-consult)    ← 신규 카테고리          │
│       ├── 텍스트 상담 (비동기)                                │
│       ├── 결과 전달/설명                                     │
│       ├── 화상 상담 (비대면진료 내 화상 전환)                  │
│       └── 수납 + 진료기록 연동                                │
│                                                              │
│  * 화상진료: 예약 기반 실시간 대면 대체 (기존 워크플로우)       │
│  * 비대면진료: 일상적 의료 소통 + 필요 시 화상 전환            │
└─────────────────────────────────────────────────────────────┘
```

### 1.4 포털 / HIS / 모바일 탭 매핑

| 기능 | 포털 (환자) | HIS (의사) | 모바일 (환자) |
|------|-----------|-----------|-------------|
| **비대면진료** | 진료 > 비대면진료 (기존 "소통" 대체) | 차트 > 비대면 탭 + `/remote-consult` 대시보드 | 비대면진료 탭 |
| **화상진료** | 서비스 > 원격진료 (기존 유지) | `/telehealth` (기존 유지) | 원격진료 탭 |

**차이점 요약:**

| 항목 | 화상진료 (기존) | 비대면진료 (신규) |
|------|---------------|-----------------|
| 채널 | 영상통화만 | 텍스트 + 결과전달 + 화상(선택) |
| 시작 | 예약 필수 | 즉시 질문 가능 |
| 시간 | 실시간 15~30분 | 비동기 (24h 내 답변) |
| 처방 | 진료 중 즉시 | 답변 후 필요 시 |
| 수가 | 40,000~60,000원 | 20,000~30,000원 |
| 수납 | 진료 후 즉시 | 답변 완료 시 자동 |
| 위치 | HIS `/telehealth` | HIS `/remote-consult` (신규) |
| 포털 | 서비스 > 원격진료 | **진료 > 비대면진료** |
| 진료기록 | Encounter 자동 생성 | 의사 선택 시 연동 |

### 1.5 비대면진료에서 화상 전환

텍스트 상담 중 의사 또는 환자가 **화상 전환**을 요청할 수 있습니다.
이때 기존 `/telehealth`의 Jitsi 세션을 생성하되, `RemoteConsultation`에 연결됩니다.

```
텍스트 상담 진행 중
     │
     ├── 의사: [화상 전환 제안] → 환자에게 알림
     │   또는
     ├── 환자: [📹 화상 전환 요청] → 의사에게 알림
     │
     ▼
상대방 수락 → Jitsi 세션 생성 (즉시 or 예약)
     │
     ▼
화상 진료 완료 → 텍스트 스레드에 기록
     │
     ▼
수가 자동 업그레이드 (텍스트 20K → 화상 40K)
```

### 1.6.3 Ottehr 텔레헬스 워크플로우 상세

**환자 플로우 (intake/telemed):**

```

      │
④ WaitingRoom — 가상 대기실
      │   ├── 장비 테스트 (카메라/마이크 미리보기)
      │   ├── 대기 상태 표시 ("의사가 곧 입장합니다")

      │   └── 대기 중 채팅 가능
      │

      │   ├── 양방향 영상/음성
      │   ├── 화면 공유 (검사결과 함께 보기)
      │   ├── 채팅 (텍스트 보조)
      │   ├── 통화 제어 (마이크/카메라/종료)
      │   └── 사이드 패널 (환자 정보 + 문진 내용)
      │
⑥ CallEndedPage — 진료 종료
      ├── 진료 요약 표시
      ├── 처방전 안내
      ├── 다음 예약 안내

      └── 수납 안내

## 2. 법적 근거

### 2.1 의료법 제34조 (원격의료)

```
제34조(원격의료)
① 의료인(의료업에 종사하는 의사·치과의사·한의사만 해당한다)은
   제33조 제1항에도 불구하고 컴퓨터·화상통신 등

   의료지식이나 기술을 지원하는 원격의료(이하 "원격의료"라 한다)를
   할 수 있다.

② 원격의료를 행하거나 받으려는 자는
   보건복지부령으로 정하는 시설과 장비를 갖추어야 한다.

③ 원격의료를 하는 자(이하 "원격지의사"라 한다)는
   환자를 직접 대면하여 진료하는 경우와 같은 책임을 진다.

## 12. PM 검토 — 보완 사항

### 12.1 초진/재진 구분 로직

비대면 진료 시범사업에서 **초진과 재진의 허용 범위가 다릅니다**.

| 구분 | 조건 | 허용 채널 | 제약 |
|------|------|----------|------|
| **재진** | 최근 1년 이내 해당 의사 대면 진료 이력 | 텍스트 + 화상 + 결과설명 | 없음 |
| **초진** | 대면 진료 이력 없음 | 화상만 (텍스트 불가) | 감염병 유행 시 한시적 허용, 만성질환 재진 전환 필요 |
| **경과 관찰** | 동일 질환 추적 중 | 텍스트 + 화상 | 3개월 내 대면 진료 필요 |

**구현 방안:**
```
상담 요청 시:
  1. encounters 테이블에서 해당 의사 최근 진료 조회
  2. 1년 이내 진료 있음 → 재진: 모든 채널 허용
  3. 진료 없음 → 초진: 화상만 허용 + "초진 비대면은 화상만 가능합니다" 안내
  4. systemConfig에서 감염병 유행 모드 ON 시 → 초진 텍스트도 허용
```

### 12.2 진료과별 비대면 적합성

모든 진료과가 비대면에 적합하지는 않습니다.

| 적합도 | 진료과 | 사유 |
|:------:|-------|------|
| **높음** | 내과, 가정의학과, 정신건강의학과, 피부과 | 문진 기반, 경과 관찰 위주 |
| **중간** | 정형외과, 재활의학과, 이비인후과 | 사진/영상 보조 시 가능 |
| **낮음** | 외과, 산부인과, 안과, 치과 | 직접 진찰/시술 필요 |
| **불가** | 응급의학과 | 즉시 대면 필요 |

**구현 방안:** 진료과별 비대면 가능 여부를 `systemConfig`에 설정하여, 해당 진료과 의사만 비대면 진료에 참여 가능.

### 12.3 처방전 발행 워크플로우

비대면 진료에서 처방이 필요한 경우:

```
의사: 비대면 진료 중 처방 필요 판단
     │
     ▼
채널 확인:
  ● 화상 진료 중 → 즉시 전자처방전 발행 가능
  ● 텍스트 상담 → "처방은 화상 진료에서만 가능합니다" 안내
                    또는 "대면 진료를 예약해주세요" 안내
     │
     ▼ (화상 진료 시)
처방전 발행 → DUR 점검 → 처방전 확정
     │
     ▼
약국 전송:
  ● 환자 선택 약국으로 팩스/전송
  ● 포털에 처방전 PDF 제공
  ● "가까운 약국 찾기" 링크
```

**텍스트 상담에서 처방이 필요한 경우:**
- 기존 처방 동일 약 연장 → 화상 전환 없이 가능 (의사 판단)
- 신규 처방 → 화상 전환 또는 대면 예약 권고

### 12.4 진료 시간 제한 및 자동 종료

| 항목 | 정책 |
|------|------|
| 텍스트 상담 유효기간 | 최초 요청 후 **7일** (이후 자동 종료) |
| 텍스트 메시지 횟수 | 환자 10회 + 의사 10회 = 최대 20회 (초과 시 새 상담) |

| 화상 대기 시간 | 예약 시간 후 **10분** 미입장 시 자동 취소 |
| 의사 미답변 에스컬레이션 | 24h → 과장 알림, 48h → 자동 환불 |
