## 3. 세련화 원칙 (이 저장소 판정 규칙의 포털 적용)

1. **세션이 가진 능력을 화면이 먼저 안다** — 실패를 보고 추측하지 않는다(§1.3).
2. **같은 사실은 한 정본** — 금액·상태·판정 어휘는 shared 정본 하나(R1·R2·R4).
3. **숫자에는 시각·기준·출처** — 환자는 숫자만 보면 놀라거나 안심한다(R5).
4. **모르면 모른다고, 꺼졌으면 없다고** — 실패·꺼짐·권한 밖·없음은 다른 문장(v4.93 교훈 유지).
5. **최신·중요한 것 먼저, 나머지는 접는다** — 긴 세로 목록 대신 요약 → 펼침(R6).
6. **환자 화면에는 코드가 없다** — `CHECKED_IN`·`NORMAL`·`NHI` 를 그대로 보이지 않는다(R2·R3 · 머리 카드의 `NHI` 포함).

## 4. 세련화 묶음 (A)

### A1. 세션 능력 정본 (`portal session capabilities`) — 최우선
- 서버가 로그인 응답·`GET portal/session` 에 **이 세션으로 쓸 수 있는 기능 목록**을 준다: `{ kind: 'ACCOUNT'|'MRN'|'GUARDIAN', features: { notifications, nationalId, family, familyAccounts, upload, ... }, expiresAt }`.
- 정본은 shared 하나(기능 키 → 필요한 세션 종류). 가드(`PatientAccountAuthGuard`·`PortalOrPatientGuard`·보호자 범위)와 **기계 대조**한다 — 가드가 막는 기능을 화면이 "가능"이라 말하면 실패.
- 화면은 능력이 없는 기능을 **부르지 않고** 처음부터 안내 카드로 그린다(종전: 부르고 403 → 안내). 남은 시간 표시(만료 5분 전 "연장" 대신 다시 로그인 안내 — 갱신 토큰 결정 전).
- 효과: §1.3 사고 3건의 기전 제거 · 불필요한 401/403 호출 0.

### A2. 상태·판정 어휘 정본
- 예약·진료·수납·서류 상태 → `StatusBadge domain` 로 수렴(R2) · 지난 예약은 "지난 방문"으로 분리.
- 검사 판정 어휘를 shared 하나로(정상·높음·낮음·위급 · 아이콘 하나)(R4) · 진단검사 카드는 **검사명·날짜·판독 요약**을 그리고 이름 없는 행은 그리지 않는다(R3 — 원장에 이름이 없으면 "검사명 미기록"이라 말한다).
- 머리 카드 `NHI` → "건강보험" 등 환자 언어.

### A3. 건강 탭 재구성 (R5·R6)
- 맨 위: **최근 변화 요약** — 최신 결과 중 기준 밖 항목만, 직전 값 대비 화살표(같은 검사 코드끼리만 · 재반올림 금지 · 기준은 결과 행의 참고치).
- 결과는 **날짜 → 패널** 접힘 목록(최신 1개만 펼침) · 항목을 누르면 그 항목 추이(기존 `lab-trends`).
- 활력은 공용 표준 부품(측정 시각·출처·단위) · 기준 밖이면 "다음 진료 때 의료진과 상의하세요" 고정 문구(진단·권고하지 않음 · `policy.portal.disclaimerAndAccessibility` 범위).
- "이 결과를 쉽게 설명해 주세요"(AI) 버튼은 패널마다가 아니라 펼친 패널에 하나 · AI 표기 병기 유지.

### A4. 홈 "오늘 할 일" 한 줄 목록
- 생애주기 홈 위에 **행동이 필요한 것만** 모은다: 미작성 문진표 · 서명할 동의서 · 미수납 · 오늘 예약(시간·장소) · 새 결과 · 서류 준비 완료.
- 각 줄은 출처 EP 의 실제 건수(실패면 그 줄만 "확인 불가") · 0건이면 줄을 그리지 않고, 전부 0이면 "지금 하실 일은 없습니다" 한 줄.

### A5. 모바일 크롬 정리 (R7)
- 플로팅 버튼 하나로 합친다(상담·AI·전화 메뉴) · 하단 탭 위로 띄우고 본문 하단 여백 확보.
- 온보딩은 **계정 단위로 1회**(서버 기록) · 등록번호 세션은 짧은 한 줄 안내로. ✅ v4.99.0 — 계정 세션은 `PatientAccount.onboardingCompletedAt`(보호자 위임은 보는 사람 계정) · 등록번호 세션은 기기 단위(능력표 `onboarding.scope = DEVICE`)
- 터치 대상 44px · 하단 탭 활성 표시.

### A6. 빈 상태·로딩·실패 일관
- 공용 `EmptyState`·`QueryErrorFallback`·스켈레톤만 쓴다(포털 전용 문구 카탈로그) · 섹션 높이 고정 스켈레톤으로 화면 튐 제거.

### A7. 접근성·언어
- 글자 크기·고대비는 있다 → **화면 전체 반영 점검**(고정 px 글자 잔존 전수) · 스크린리더 라벨(탭·차트 대체 텍스트) · 포털 언어(ko/en/zh/ja) 미번역 키 0 유지.

## 7. 검증 방식 (이번 주 교훈)

- 🔴 **세션 종류 3가지 × 전 탭·하위 메뉴**를 헤드리스 브라우저로 순회해 4xx/5xx·"세션"·"실패"·영문 코드 문구를 센다 — 단계마다(v4.93 은 홈만 봐서 두 번 더 신고받았다).
- 데스크톱 1400 · 모바일 390 캡처를 단계 전후로 남긴다.
- A1 은 가드 ↔ 능력표 기계 대조 + 재주입(가드가 막는 기능을 능력표에 "가능"으로 넣으면 실패).
- 금액(R1)은 원장 줄 합과 화면 두 카드가 **같은 값**인지 시드 환자 전수로 대조.
