# 진료비 영수증 의료법 세밀화 기획서 v1.0

> **요약**: 진료비 계산서·영수증을 **의료법 시행규칙 별지 제11호의2** 기준으로 세밀·정밀화한다. 방금 구축한 **수진자 자격조회**(본인부담 구분=의료급여 1/2종·차상위·산정특례·자격상실)를 영수증/세부산정내역에 정확 반영하고, **급여 내 일부본인부담/전액본인부담 분리**, **하드코딩된 요양기관 정보 제거**(설정 연동), 의료기관장 서명·현금영수증·감면·세액공제까지 법정 요건을 충족한다.
>
> **작성일**: 2026-06-12 / **상태**: Draft
> **근거**: 의료법 시행규칙 제42조·별지 제11호의2, 국민건강보험법 시행규칙 §9의2, 의료급여법 시행규칙, 의료법 §45(비급여 고지)

## 1. 현황 (실측)

`apps/web/src/app/(main)/print/receipt/[billingId]/page.tsx` — 4개 탭 보유:
| 탭 | 컴포넌트 | 현황 | 세밀화 갭 |
|----|----------|------|----------|
| 계산서·영수증 | ReceiptMain | 13항목·급여/비급여/선택진료 열·급여소계/합계. 보험구분·본인부담구분 행(자격조회) 추가됨 | **급여 일부/전액본인부담 미분리**, 요양기관정보 하드코딩, 야간/공휴일·종별·면허·서명·현금영수증·감면 부재 |
| 세부산정내역 | DetailStatement | 항목/코드/명칭/단가/횟수/총액/급여비급여 | **본인부담 구분 열 부재**, EDI 보험코드 미표시, 산정특례·정액 미반영 |
| 납입확인서 | AnnualStatement | 연도별 외래/입원 월별 | 세액공제 안내·발급기관정보 보강 |
| 비급여 내역서 | NonCoveredStatement | 비급여 항목 | §45 고지정합·비급여 분류·동의 표시 |

**핵심 하드코딩**: 요양기관번호 `12345678`, 사업자번호 `123-45-67890`, 병원명 등 → **설정 연동 필요**.

## 2. 법정 요건 ↔ 세밀화 항목

### 2.1 계산서·영수증(별지 제11호의2) — 컬럼 정밀화
법정 컬럼 구조(급여를 일부/전액으로 분리):
```
구분 | 금액 | [급여] 일부본인부담{본인부담금|공단부담금} | [급여] 전액본인부담 | [비급여] 선택진료 | [비급여] 선택진료외
```
- **급여 일부본인부담**: 본인부담금(자격 copayCategory 기반) + 공단부담금.
- **급여 전액본인부담**: 100분의100 본인부담 항목(법정).
- **비급여**: 선택진료(2018 폐지·0 표기) / 선택진료외.
- 합계: 진료비총액 · 환자부담총액(본인일부+전액+비급여) · 이미납부 · 납부할금액 · **감면액**.

### 2.2 자격조회 반영 (본인부담 구분 정밀)
| copayCategory | 영수증 표기 | 본인부담 산정 |
|---------------|------------|--------------|
| NHI | 건강보험 · 일부부담 | 외래30/입원20% |
| MA_TYPE1 | 의료급여 1종 · 일부부담 | **정액**(외래 1·2·3차 1,000~2,000원, 입원 0) — ※정액 모델 신설 |
| MA_TYPE2 | 의료급여 2종 · 일부부담 | 외래 1,000원+15%/입원 10% |
| NEAR_POOR | 차상위 · 일부부담 | 14% |
| SPECIAL_EXEMPTION | 산정특례(V코드) · 일부부담 | 암5·희귀10·중증0~10% |
| EXPIRED/NOT_FOUND | **자격상실 · 전액부담** | 100% + 경고 |
| SELF_PAY | 자비 · 전액부담 | 100% |
- `Billing` 자격 스냅샷(copayCategory·eligibilityStatus·specialExemption — 이미 저장) 사용. **의료급여 1종 정액**은 율(%) 모델 한계 → 정액 플래그/금액 신설(§5).

### 2.3 세부산정내역서(별지 제11호의2 후면) — 열 보강
`항목구분 | EDI코드 | 명칭 | 단가 | 횟수/일 | 금액 | 급여/비급여 | 본인부담구분(일부/전액/비급여) | 산정특례`
- EDI 보험코드(`MedicationCode.insuranceCode`·`ProcedureCode.code`) 표시.
- 항목별 `copayRate`(BillingItem 보유) 노출, 산정특례 적용 라인 표식.

### 2.4 머리말·꼬리말 법정 항목
- 요양기관: **명칭·기호·종별·사업자등록번호·대표자·주소·전화·면허** → **설정 연동**(config-runtime `hospital.*` 또는 `HospitalInfoContent`).
- 환자: 성명·등록번호·**진료기간·야간(공휴일)진료 여부·입원/외래/퇴원 구분**.
- 수납: 납부액·미수납·**수납방법(현금/카드 승인번호/현금영수증)**·발행일.
- **의료기관의 장 서명/날인**(이미지·전자), 의료비 세액공제 안내, 세부내역 별도제공 안내.
- **진위확인 QR**(기존 IssuedDocument 발급/진위 연계 검토).

## 5. 데이터 보강 (신규)
- **config-runtime `hospital.*`**: `hospital.name·code(요양기관기호)·grade(종별)·bizNo·ceo·license·addr·tel`. (HospitalInfoContent 재사용 검토)
- **`Billing.discountAmount·discountReason`**(감면) — 추가 컬럼.
- **의료급여 1종 정액**: config `billing.copay.ma1.flat.{primary,secondary,tertiary}`(외래 차수별 정액) + 산정 로직(율 대신 정액 우선).
- **공휴일 판정**: 기존 `holiday` 모듈 활용 야간/공휴일 가산·표기.

## 6. 구현 순서 (Phase) — 별도 /pdca do 시
1. **P0**: 요양기관정보 설정 연동(하드코딩 제거) + 계산서·영수증 급여 일부/전액 분리 + 자격 본인부담 정밀표기.
2. **P0**: 세부산정내역 본인부담구분·EDI코드·산정특례 열.
3. **P1**: 야간/공휴일·입원외래·현금영수증·감면·서명·세액공제·QR.
4. **P1**: 의료급여 1종 정액 모델.
5. **P2**: 비급여 내역서 §45 정합·납입확인서 보강.

## 7. 검증
- 케이스별 영수증: 건보 외래·입원, 의료급여 1/2종, 차상위, 산정특례, 자격상실(전액), 자비 — 본인부담 표기·합계 정합.
- 법정 서식 대조(별지 제11호의2 컬럼·항목 13종·머리/꼬리말).
- 세액공제 증빙(연간), 비급여 §45 고지 정합.

## 8. 미해소 / 확인
- 약품 EDI 보험코드(ERP 매핑 진행중) — 세부내역 코드열은 채워지는 대로.
- 의료급여 1종 정액 산식(차수·약국·입원 차등) — 원무/임상 검토.
- 요양기관 종별·면허·대표자 실값 — 운영 설정.
- 진위확인 QR을 IssuedDocument로 발급할지(법적 보존·재발급).
- 선택진료료(2018 폐지) 컬럼 유지/제거 — 잔존 기관 정책.
