## 1. 현재 UX 진단

### 1.1 정량 현황

| 지표 | 수치 |
|------|-----:|
| 탭 수 | 13개 |
| 셀프서비스 기능 | 24개 |
| 포털 API | 38개 |
| 메인 파일 줄 수 | 2,919줄 |
| 서브 컴포넌트 | 25개 (단일 파일 내) |
| 하단 네비 (모바일) | 5개 탭 |

### 1.2 UX 문제점 분석

| # | 카테고리 | 문제 | 심각도 | 근거 |
|---|---------|------|:------:|------|
| UX-1 | **정보 과부하** | 13개 탭이 평면 나열 — 환자가 원하는 정보까지 4~5회 탐색 필요 | 높음 | 탭이 기능 중심이지 태스크 중심이 아님 |
| UX-2 | **인지 부하** | 홈 화면에 대기현황 + 건강대시보드 + AI요약 + 빠른메뉴 + 알림 + 문진표 + 공지 등 7개 섹션 동시 노출 | 높음 | 스크롤 3~4회 필요, 우선순위 불명확 |
| UX-3 | **모바일 네비 불일치** | 하단 5개 탭(홈/예약/문진/검사/진료비)과 상단 스크롤 12개 탭 이중 구조 | 중간 | 나머지 8개 탭 접근 경로 혼란 |
| UX-4 | **컨텍스트 단절** | 예약→대기→진료→수납 여정이 각 탭에 분산, 환자의 "지금 해야 할 일" 불명확 | 높음 | 진료 여정 기반 UX 부재 |
| UX-5 | **로그인 UX** | 휴대폰/MRN 2모드 토글 — 모드 전환 인지 어려움, 회원가입 모달 오버레이 | 중간 | 고령 환자 혼란 가능성 |
| UX-6 | **빈 상태 처리** | 데이터 없을 때 "데이터 없음" 텍스트만 — 다음 행동 유도 없음 | 중간 | Empty state UX 부재 |
| UX-7 | **시각적 위계 부족** | 모든 카드가 동일한 rounded-xl + border 스타일 — 긴급/중요 정보 구분 안 됨 | 중간 | 시각적 차별화 없음 |
| UX-8 | **단일 파일 구조** | 2,919줄 단일 파일 — 성능/유지보수/코드스플리팅 불리 | 낮음 | 기술 부채 (UX 간접 영향) |

## 2. 리디자인 전략

### 2.1 디자인 원칙

| 원칙 | 설명 |
|------|------|
| **여정 중심 (Journey-First)** | 기능 나열이 아닌 "지금 해야 할 일" 중심으로 정보 배치 |
| **점진적 노출 (Progressive Disclosure)** | 핵심 정보만 먼저, 상세는 탭/펼침으로 |
| **컨텍스트 인지 (Context-Aware)** | 예약 당일 → 대기 UI 강조, 검사 결과 나온 날 → 결과 카드 상단 |
| **고령자 포용 (Senior-Friendly)** | 최소 16px 본문, 44px 터치 타겟, 고대비 모드 |
| **제로 데드엔드 (Zero Dead-End)** | 모든 빈 상태에 다음 행동 CTA 제공 |

### 2.2 정보 아키텍처 재구성

**AS-IS: 기능 중심 13탭 평면 구조**
```
홈 | 예약 | 진료이력 | 문진/동의 | 서류 | 투약/알레르기 | 검사결과 | 영상검사 | 건강검진 | 원격진료 | 진료비 | 병원안내 | 내 정보
```

**TO-BE: 여정 중심 5+카테고리 계층 구조**
```
홈(투데이) | 진료 | 건강 | 서비스 | 내 정보
              │       │        │
              ├─ 예약  ├─ 검사결과  ├─ 서류발급
              ├─ 대기  ├─ 영상검사  ├─ 진료비/수납
              ├─ 진료이력 ├─ 투약관리 ├─ 원격진료
              ├─ 문진/동의 ├─ 건강검진 ├─ 병원안내
              └─ 담당의소통 └─ 건강대시보드 └─ 인증서
```

| 카테고리 | 포함 기능 | 사용자 멘탈모델 |
|---------|----------|--------------|
| **홈 (투데이)** | 오늘의 할 일, 실시간 알림, 여정 타임라인 | "지금 뭐 해야 해?" |
| **진료** | 예약, 대기현황, 진료이력, 문진/동의, 담당의 메시지 | "진료 받으러 왔어요" |
| **건강** | 검사결과, 영상검사, 투약/알레르기, 건강검진, 건강대시보드 | "내 건강 상태가 궁금해요" |
| **서비스** | 서류발급, 진료비/수납, 원격진료, 병원안내 | "병원 업무를 처리하고 싶어요" |
| **내 정보** | 프로필, 가족계정, 인증서, 동의관리 | "내 정보를 관리하고 싶어요" |

## 4. 인터랙션 상세

### 4.1 마이크로 인터랙션

| 인터랙션 | 현재 | 개선 |
|---------|------|------|
| 탭 전환 | 즉시 전환 (깜빡임) | 슬라이드 트랜지션 (200ms ease-out) |
| 카드 로딩 | "로딩 중..." 텍스트 | 스켈레톤 UI (pulse 애니메이션) |
| 데이터 새로고침 | 없음 | Pull-to-refresh (모바일) + 30초 자동 갱신 |
| 대기 순번 변경 | 폴링 후 숫자 변경 | 숫자 카운트다운 애니메이션 + 진동(모바일) |
| 버튼 피드백 | hover 색상 변경만 | haptic feedback + scale(0.98) press 효과 |
| 빈 상태 | 텍스트만 | 일러스트 + CTA 버튼 |

| 색상 대비 | AA 수준 | AAA 고대비 모드 토글 |
| 네비게이션 | 텍스트+아이콘 | 아이콘 + 한글 레이블 항상 표시 |

| 음성 안내 | 없음 | 주요 화면에 aria-live="polite" 상태 변경 알림 |

| 4-6 | WCAG AAA 감사 | axe-core 기반 접근성 테스트 + 수정 | 2h |

**Phase 4 합계: 10h**
