## 1. 현재 상태

### 1.1 보험 청구 (`/claims`)

| 기능 | 상태 | 비고 |
|------|:----:|------|
| 청구 목록 조회 | ✅ | 환자/청구액/상태/청구일 |
| 청구 생성 (generate) | ✅ | 미수납 billing에서 자동 생성 |
| 청구 제출 (submit) | ✅ | DRAFT → SUBMITTED |
| 일괄 제출 | ✅ | 체크박스 선택 후 일괄 |
| XML 다운로드 | ✅ | HIRA 청구 XML |
| 요약 통계 | ✅ | 클라이언트 계산 폴백 (5/27 수정) |
| 심사 결과 반영 | ❌ | 인정/부분인정/반려 처리 없음 |
| 청구 상세 | ❌ | 행목별 상세 내역 없음 |
| 이의신청 | ❌ | 반려 시 이의신청 프로세스 없음 |
| 청구 이력/통계 | ❌ | 월별/과별 청구 현황 없음 |

### 1.2 수납 (`/billing`)

| 기능 | 상태 | 비고 |
|------|:----:|------|
| 수납 목록 | ✅ | 전체/미수납/완료 필터 |
| 수납 처리 | ✅ | 결제 방법 선택 + 금액 입력 |
| 영수증 | ✅ | 기본 영수증 보기/인쇄 |
| 보험부담/본인부담 계산 | ⚠ | 고정 비율만 (보험종류별 미반영) |
| 부분수납 | ⚠ | 기본 구현, UX 미흡 |
| 환불 | ⚠ | 상태만 (실제 환불 처리 없음) |
| 미수납 알림 | ❌ | 기간 경과 미수납 알림 없음 |
| 선수금/예치금 | ❌ | deposit 관리 없음 |
| 카드/현금 영수증 | ⚠ | 필드만 있음, 실제 PG 없음 |
| 법정 영수증 4종 | ❌ | 계산서·영수증/세부산정/납입확인/비급여 |
| 중간 정산 | ❌ | 입원 중간 수납 없음 |

## 3. 진료비 계산 로직

### 3.1 보험종류별 본인부담률

| 보험종류 | 외래 | 입원 | 약국 | 비고 |
|---------|:----:|:----:|:----:|------|
| 건강보험 (상급종합) | 60% | 20% | 30% | 본인부담상한제 적용 |
| 건강보험 (종합병원) | 40% | 20% | 30% | |
| 건강보험 (병원) | 30% | 20% | 30% | |
| 의료급여 1종 | 면제 | 면제 | 500원 | 급식비 본인부담 |
| 의료급여 2종 | 15% | 10% | 500원 | |
| 산재보험 | 0% | 0% | 0% | 전액 산재 |
| 자동차보험 | 0% | 0% | 0% | 전액 자보 |
| 비급여 | 100% | 100% | 100% | |

### 3.2 입원 진료비 특이 항목

| 항목 | 계산 | 비급여 여부 |
|------|------|:----------:|
| 식대 | 1식 기준 × 일수 × 3끼 | 급여 (일부 본인부담) |
| 상급병실차액 | (상급 - 일반) × 일수 | 비급여 |
| 간병비 | 일당 × 일수 | 비급여 |
| 제증명료 | 건당 | 비급여 |
| 선택진료비 | 해당 항목 × 추가율 | 비급여 (2024 폐지) |

### 3.3 본인부담상한제

```
연간 본인부담금이 상한액 초과 시 초과분 환급:
- 소득 1분위: 80만원
- 소득 2~3분위: 100만원
- 소득 4~5분위: 150만원
- 소득 6~7분위: 200만원
- 소득 8분위: 300만원
- 소득 9분위: 400만원
- 소득 10분위: 580만원
```

## 5. 환불 프로세스

```
환불 사유:
├─ 과납: 수납액 > 실제 진료비 → 차액 환불
├─ 진료 취소: 예약 취소/미진료 → 전액 환불
├─ 보험 정정: 보험 적용 변경 → 차액 환불
└─ 기타: 오류 정정 등

환불 처리:
1. 환불 사유 선택 + 금액 입력
2. 승인권자 확인 (10만원 이상 원장 승인)
3. 환불 수단: 원결제 수단 우선 (카드→카드, 현금→현금)
4. 환불 영수증 발급
5. 감사 로그 기록
```

## 6. 카드/현금영수증

### 6.1 카드 결제 (PG 미연동 — 수동 입력)

```
현재: 카드사/승인번호 수동 입력
향후: PG 연동 (토스페이먼츠/이니시스)

수동 입력 필드:
- 결제수단: 카드/현금/계좌이체/복합

- 승인번호: 8자리
- 할부개월: 0(일시불)/2/3/6/12
```

## 8. 비급여 동의서 연동

