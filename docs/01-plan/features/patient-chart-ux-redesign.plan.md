### 1.2 UX 문제점 분석

| # | 카테고리 | 문제 | 심각도 | 근거 |
|---|---------|------|:------:|------|
| C-1 | **활성 처방 정보 부족** | 처방 7건이 숫자만 표시 — 약물명/용량 미노출 | 높음 | 의사가 진료 시작 전 현재 복용약을 즉시 확인해야 함 |

| C-4 | **최근 진료 내용 부실** | 날짜+상태+의사명만 — SOAP 요약/진단명 미표시 | 중간 | 진료 연속성을 위해 이전 진료 핵심 내용이 필요 |

## 2. 개선 전략

### 2.1 디자인 원칙

| 원칙 | 설명 |
|------|------|
| **5초 룰 (5-Second Rule)** | 차트 진입 후 5초 이내에 환자의 핵심 상태를 파악할 수 있어야 함 |
| **위험 우선 (Risk-First)** | 위급값/알레르기/약물경고를 최상단에 고정 |
| **임상 밀도 (Clinical Density)** | 스크롤 없이 최대 임상 정보를 시각적으로 압축 |
| **원클릭 액션 (One-Click Action)** | 진료 시작/처방/검사 오더를 개요에서 직접 실행 |

## 3. 상세 개선 명세

### 3.1 긴급 알림 배너 (신규)

```
위치: 개요 탭 최상단 (스크롤 시에도 sticky)
조건: 위급값 또는 CDSS/DUR 경고가 있을 때만 표시
```

| 알림 유형 | 색상 | 소스 |
|----------|------|------|
| **위급값 (Critical)** | 빨강 배경 + 깜빡임 | `/api/v1/lab/patients/{id}/critical-values` (신규) |
| **DUR 경고** | 주황 배경 | `/api/v1/ai/drug-interactions` (기존) |
| **알레르기 미확인** | 노랑 배경 | 알레르기 데이터 없을 때 |

```
API (신규):
GET /api/v1/lab/patients/:id/critical-values
→ 최근 72시간 이내 위급값 목록 (flag='C' 또는 flag='Critical')
→ { data: [{ testName, value, unit, flag, orderedAt }] }
```

### 3.2 환자 스냅샷 카드 (개선)

**현재** → 3칸 분리 (핵심정보 / 바이탈 / 알레르기)
**개선** → 1개 통합 카드, 정보 밀도 높임

| 항목 | 현재 | 개선 |
|------|------|------|
| 알레르기 | 별도 카드, "없음" 텍스트 | 환자 이름 옆에 인라인 배지, NKDA(확인됨) vs ⚠ 미확인 구분 |
| 바이탈 | 숫자만 | 숫자 + 비정상 ⬆⬇ 표시 + 미니 7일 트렌드 바 |
| 활성 처방 | 숫자(7건)만 | **약물명 TOP 5** 직접 표시 |

**바이탈 미니 트렌드:**
```
API (기존):
GET /api/v1/nurse-station/vitals/patient/:id?days=7
→ 7일간 BP 데이터를 미니 스파크라인으로 표시
```

**활성 처방 TOP 5:**
```
API (기존):
GET /api/v1/prescriptions/patient/:id?status=ACTIVE&limit=5
→ 약물명, 용량, 빈도 직접 표시
```

### 3.3 최근 진료 카드 (개선)

| 현재 | 개선 |
|------|------|
| 상태 배지 + 날짜 + 의사명 | + **진단 코드명** + **Assessment 한 줄 요약** + **Plan 핵심** |

```
현재: [작성중] 2026-05-22  관리자
개선: 5/22 내과 김내과
      Dx: I10 본태성 고혈압
      A: 약물 조정 필요
      P: 아모디핀 5mg→10mg 증량
```

### 3.4 최근 검사 이상수치 (신규)

```
위치: 활성 문제 옆 (기존 수납 요약 자리 교체)
데이터: 최근 7일 검사 중 flag가 H/L/C인 항목만 표시
색상:
  🔴 Critical (C) — 빨강
  🟡 High/Low (H/L) — 노랑
  🟢 경계 — 초록
```

```
API (기존):
GET /api/v1/lab/patients/:id/results?days=7
→ flag !== 'N' 필터링하여 이상수치만 추출
```

### 3.5 탭 구조 개선

**현재: 2줄 35탭 평면 나열**
```
[개요][문제목록][알레르기][검사결과][영상][바이탈][투약이력][수술이력][오더추적][입퇴원][의뢰/회신][진료이력]
[문진표][처방/수납][동의서][검진이력][여정][간호기록][환자정보][내과]
```

**개선: 카테고리 그룹 + 더보기**
```
주요:  [개요] [진료이력] [처방/투약] [검사/영상] [바이탈] [오더]
더보기: [문제목록] [알레르기] [수술] [입퇴원] [의뢰] [문진표] [동의서] [검진] [여정] [간호] [수납] [환자정보]
전문과: [내과] (부서 기반 자동 표시)
```

| 그룹 | 탭 | 표시 조건 |
|------|---|----------|
| **주요** (항상 표시) | 개요, 진료이력, 처방/투약, 검사/영상, 바이탈, 오더 | 항상 |
| **더보기** (펼침) | 나머지 13개 | 더보기 버튼 클릭 시 |
| **전문과** | 16개 | 해당 부서 의사만 |

### 3.6 퀵 액션 바 (신규)

```
위치: 개요 탭 하단 (sticky bottom 또는 인라인)
버튼: [진료 시작] [처방 입력] [검사 오더] [영상 오더] [메모]
```

| 액션 | 대상 | 비고 |
|------|------|------|
| 진료 시작 | `/patients/{id}/encounter/new` | 기존 버튼 |
| 처방 입력 | CPOE 모달 열기 | 기존 처방 탭 내 기능을 개요에서 직접 접근 |
| 검사 오더 | 검사 오더 모달 | 자주 쓰는 검사 세트 선택 |
| 영상 오더 | 영상 오더 모달 | CT/MR/X-ray 빠른 오더 |
| 메모 | 포스트잇 메모 | 환자별 의사 개인 메모 (임시) |

## 5. 성공 지표

| 지표 | 현재 (추정) | 목표 | 측정 방법 |
|------|:----------:|:----:|----------|
| 차트 진입→핵심 파악 시간 | ~10초 | ≤ 5초 | 의사 사용성 테스트 |
| 위급값 인지율 | 수동 확인 | 100% 자동 | 위급값 배너 노출 로그 |
| 개요→처방 클릭 수 | 3회 (탭→투약→처방) | 1회 (퀵 액션) | 이벤트 트래킹 |
| 스크롤 없이 보이는 정보 | 6항목 | 12항목+ | 화면 정보 밀도 분석 |
| 탭 평균 접근 시간 | 2~3클릭 | 1클릭 | 탭 그룹화 효과 |
