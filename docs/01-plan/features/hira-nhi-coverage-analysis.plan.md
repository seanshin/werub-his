## 1. 급여/비급여 구분 체계

### 1.1 법적 근거

| 법령 | 조항 | 내용 |
|------|------|------|
| 국민건강보험법 | 제41조 | 요양급여의 범위 (급여 대상 행위/약제/치료재료) |
| 국민건강보험법 | 제41조의4 | 비급여 대상의 범위 |
| 국민건강보험법 시행규칙 | 제9조 별표2 | 비급여 대상 목록 (양성식 제외) |
| 의료법 | 제45조 | 비급여 진료비용 등의 고지 의무 |
| 의료법 | 제45조의2 | 비급여 진료비용 등의 현황 조사 및 공개 |
| 의료법 시행규칙 | 제42조의2 | 비급여 진료비용 고지 방법 |

### 1.2 급여/비급여 구분 원칙

```
건강보험 적용 판단 흐름:

의료행위 발생
    │
    ├─ 급여 대상인가? (국민건강보험법 제41조)
    │   ├─ YES → 급여 처리
    │   │   ├─ 본인일부부담: 본인부담률 적용
    │   │   └─ 전액급여: 본인부담 면제 (법정 본인부담 면제 항목)
    │   │
    │   └─ NO → 비급여 대상인가?
    │       ├─ 법정 비급여 (시행규칙 별표2) → 비급여 처리 (전액 본인부담)
    │       ├─ 선택 비급여 (환자가 선택) → 비급여 처리 + 동의서
    │       └─ 임의 비급여 (의료기관 자체) → 불법 (금지)
    │
    └─ 급여 + 비급여 복합?
        └─ 급여 부분과 비급여 부분 분리 계산
```

## 3. 급여 항목 분류 (건강보험 수가)

### 3.1 행위별 수가 체계

| 분류 | 코드 체계 | 설명 |
|------|----------|------|
| 진찰료 | AA*** | 초진/재진, 기관등급별 |
| 입원료 | AB*** | 일반/중환자/격리 |
| 투약·조제료 | AC*** | 원내/원외, 약품비 별도 |
| 주사료 | AD*** | 피하/근육/정맥 |
| 마취료 | AE*** | 전신/부분/척추 |
| 이학요법 | AH*** | 물리치료, 재활 |
| 처치료 | J**** | 단순~복잡 |
| 수술료 | K**** / O**** | 부위별, 난이도별 |
| 검사료 | B**** / C**** | 혈액/뇨/미생물/병리 |
| 영상진단료 | D**** | X-ray/CT/MRI/초음파 |
| 방사선치료 | H**** | 외부/강내조사 |
| 정신과치료 | I**** | 개인/집단 정신치료 |
| 치과 | U**** | 치과 고유 행위 |

### 3.2 약품비 (약제급여 목록)

```
약품비 계산:
  약품비 = 약가 × 투약일수 × 1일 투여횟수 × 1회 투여량

  약가 결정:
  - 급여 약제: 건강보험 약제급여 목록 등재 약가
  - 비급여 약제: 의료기관 자체 가격 (고시 의무)
  
  조제료:
  - 원내조제: 약사 조제료 (건수당)
  - 원외처방: 처방전 발급료 (건수당)
```

### 3.3 재료대

```
치료재료:
  - 급여재료: 건강보험 요양급여비용 등재 재료
  - 비급여재료: 인체조직, 특수재료, 미등재 재료
  
  본인부담:
  - 급여재료: 보험자부담률 적용
  - 비급여재료: 전액 본인부담
```

## 5. 비급여 관리를 위한 시스템 적용 방안

### 5.1 HIS에서의 급여/비급여 처리

```
처방 입력 시:
  1. 의사가 처방 입력 (약물/검사/시술)
  2. 시스템이 급여 목록 자동 조회
     ├─ 급여 목록에 있음 → 급여 처리 (자동)
     ├─ 비급여 목록에 있음 → 비급여 처리
     │   └─ 환자 동의서 필요 여부 확인
     └─ 목록에 없음 → 관리자 확인 필요
  3. 비급여 항목인 경우:
     ├─ 예상 비용 안내 (사전 고지 의무)
     ├─ 환자 동의서 서명 (전자서명)
     └─ 처방 확정
```

### 5.2 비급여 가격 공시 의무

```
의료법 제45조의2에 따라:
  - 비급여 진료비 목록 + 가격을 원내 게시
  - 홈페이지 공개 (인터넷 공시)
  - HIRA 비급여 진료비 공개 시스템 보고 (연 1회)
  
HIS 시스템에서:
  - /admin/non-covered 에서 비급여 항목 관리 (구현됨)
  - 홈페이지 자동 공시 연동 필요
  - HIRA 보고 데이터 생성 기능 필요
```

### 5.3 급여/비급여 판정 기준 DB

```
시스템에 필요한 참조 데이터:

1. 건강보험 행위 급여 목록
   - EDI 코드 + 수가 + 상대가치점수
   - 출처: 건강보험 요양급여비용 (고시)
   - 갱신: 연 1회 (1월)

2. 약제 급여 목록
   - 약품 코드 + 약가 + 급여 기준
   - 출처: 약제급여 목록 및 급여 상한금액표
   - 갱신: 수시 (신약 등재)

3. 치료재료 급여 목록
   - 재료 코드 + 상한가 + 급여 기준
   - 출처: 치료재료 급여·비급여 목록
   - 갱신: 수시

4. 비급여 항목 마스터
   - 항목코드 + 항목명 + 가격 + 카테고리
   - 출처: 의료기관 자체 결정 (HIRA 보고)
   - 갱신: 가격 변경 시 즉시
```

### 8.3 시행규칙 별표2 — 비급여 대상 상세 (요약)

```
[별표 2] 비급여 대상 (국민건강보험법 시행규칙 제9조 관련)

   - 지방흡입
   - 주름살 제거
   - 점·사마귀 제거 (미용 목적)

   - 구강 검진 (법정 외)

   - 보조생식술 (체외수정 등) — 일부 급여 전환
   - 한방물리요법 (일부)

   - 상급병실 사용 (일반병실 초과분)
   - 제증명 수수료

   - 특수식이 (환자 희망)
   - 추가 영양제·비타민 주사 (치료 목적 외)
```
