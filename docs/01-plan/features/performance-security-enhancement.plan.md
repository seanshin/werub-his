## 1. 현재 상태 분석

### 1.1 보안 현황

| 항목 | 상태 | 비고 |
|------|:----:|------|
| Helmet (보안 헤더) | ✅ | main.ts에 적용 |
| CORS | ✅ | CORS_ORIGIN 환경변수 제어 |
| JWT 인증 | ✅ | Access+Refresh 토큰, HttpOnly 쿠키 |
| RBAC | ✅ | 7개 역할 (ADMIN/DOCTOR/NURSE/PHARMACIST/LAB_TECH/PATIENT/RECEPTIONIST) |
| Rate Limiting | ⚠️ | ThrottlerGuard 전역 200/분, 로그인만 개별 100/분 |
| Input Validation | ✅ | ValidationPipe (whitelist+forbidNonWhitelisted) |
| XSS 방지 | ⚠️ | sanitize.ts 존재, CMS 콘텐츠만 적용 (전체 미적용) |
| SQL Injection | ✅ | Prisma ORM (파라미터 바인딩) |
| CSRF | ❌ | 미구현 (JWT Bearer 사용으로 낮은 위험) |
| 파일 업로드 검증 | ⚠️ | MIME/크기 제한 있으나 바이러스 스캔 없음 |
| 암호화 (at rest) | ❌ | DB 필드 암호화 없음 (주민번호 등) |
| 감사 로그 | ⚠️ | 기본 감사 있으나 민감 데이터 접근 로그 미흡 |
| BTG (Break the Glass) | ✅ | 긴급 접근 로그 구현 |
| CSP (Content Security Policy) | ❌ | 미설정 |
| Cookie Security | ⚠️ | HttpOnly 있으나 Secure/SameSite 미확인 |
| API 키 노출 | ⚠️ | 일부 환경변수 클라이언트 노출 가능성 |

### 1.2 성능 현황

| 항목 | 상태 | 비고 |
|------|:----:|------|
| DB 인덱스 | ⚠️ | 363개 @@index, 주요 쿼리 커버하나 누락 가능 |
| Redis 캐싱 | ⚠️ | RedisService 존재, auth/session만 사용 (쿼리 캐시 미적용) |
| FE 캐싱 (TanStack) | ✅ | staleTime 적용 (352건), refetchInterval 적용 |
| Lazy Loading | ✅ | next/dynamic 적용 (환자 차트 34탭 등) |
| 이미지 최적화 | ✅ | Next.js Image (WebP/AVIF) |
| 번들 사이즈 | ⚠️ | 측정 필요 |
| DB N+1 쿼리 | ⚠️ | Prisma include 사용, 일부 순환 조회 가능 |
| 대용량 쿼리 | ⚠️ | 환자 10만+ 시 full scan 가능 |
| SSE/WebSocket | ❌ | 미구현 (폴링 15~60초 사용) |
| CDN | ❌ | 정적 파일 Nginx 직접 서빙 |
| Compression | ⚠️ | Nginx gzip 있으나 API 응답 압축 미확인 |

## 2. 보안 보완 계획

### Phase S1: 긴급 (OWASP Top 10 대응)

| # | 항목 | 내용 | 영향 | 예상 |
|---|------|------|:----:|:----:|
| S1-1 | **민감 데이터 암호화** | 주민번호/전화번호 AES-256-GCM 암호화 저장 | 높 | 3h |
| S1-2 | **XSS 전역 방지** | 입력 sanitizer 미들웨어 + CSP 헤더 설정 | 높 | 2h |
| S1-3 | **Rate Limit 세분화** | API별 차등 (인증 30/분, 조회 200/분, 쓰기 60/분) | 중 | 1h |
| S1-4 | **Cookie 보안 강화** | Secure + SameSite=Strict + Path 제한 | 중 | 0.5h |
| S1-5 | **환경변수 감사** | NEXT_PUBLIC_ 접두사 검토, 서버 전용 키 분리 | 중 | 1h |

### Phase S2: 중요 (의료 정보 보호)

| # | 항목 | 내용 | 영향 | 예상 |
|---|------|------|:----:|:----:|
| S2-1 | **민감 데이터 접근 로그** | 환자 차트/검사결과/처방 조회 시 감사 로그 자동 기록 | 높 | 2h |
| S2-2 | **세션 관리 강화** | 동시 세션 제한 (3개) + 비활동 30분 자동 로그아웃 | 중 | 2h |
| S2-3 | **비밀번호 정책** | 최소 12자, 대소문자+숫자+특수문자, 90일 변경 주기 | 중 | 1.5h |
| S2-4 | **IP 화이트리스트** | 관리자/의사 역할은 병원 IP에서만 접근 (선택) | 낮 | 1h |
| S2-5 | **API 응답 필드 필터링** | 역할별 응답 필드 제한 (간호사→주민번호 마스킹) | 중 | 2h |

### Phase S3: 강화 (규정 준수)

| # | 항목 | 내용 | 영향 | 예상 |
|---|------|------|:----:|:----:|
| S3-1 | **EMR 인증 기준 대응** | 의료법 시행규칙 제16조 보안 요구사항 매핑 | 높 | 3h |
| S3-2 | **개인정보 영향평가** | 개인정보보호법 제33조 대응 문서화 | 중 | 2h |
| S3-3 | **데이터 백업 암호화** | pg_dump 백업 시 GPG 암호화 + 원격 보관 | 중 | 1.5h |
| S3-4 | **침입 탐지** | fail2ban + 비정상 접근 패턴 알림 | 낮 | 2h |
| S3-5 | **보안 헤더 강화** | X-Frame-Options, X-Content-Type-Options, Referrer-Policy | 낮 | 0.5h |

## 3. 성능 보완 계획

### Phase P1: 즉시 (응답속도 개선)

| # | 항목 | 내용 | 영향 | 예상 |
|---|------|------|:----:|:----:|
| P1-1 | **Redis 쿼리 캐시** | 환자 목록/대시보드 통계 캐싱 (TTL 30~300초) | 높 | 2h |
| P1-2 | **DB 인덱스 보강** | 자주 쿼리되는 복합 인덱스 추가 (billing+status, encounter+date) | 높 | 1h |
| P1-3 | **Prisma select 최적화** | include → select 전환 (불필요 필드 제외) | 중 | 2h |
| P1-4 | **API 응답 압축** | NestJS Compression 미들웨어 적용 | 중 | 0.5h |
| P1-5 | **FE 번들 분석** | @next/bundle-analyzer로 큰 청크 식별 + code splitting | 중 | 1h |

### Phase P2: 중기 (확장성)

| # | 항목 | 내용 | 영향 | 예상 |
|---|------|------|:----:|:----:|
| P2-1 | **SSE 실시간 알림** | 폴링(15초) → SSE 전환 (대기열/오더 상태변경) | 높 | 3h |
| P2-2 | **대용량 쿼리 페이지네이션** | 커서 기반 페이지네이션 (환자/처방/청구) | 중 | 2h |
| P2-3 | **DB 커넥션 풀 최적화** | Prisma connection_limit 조정 + PgBouncer 검토 | 중 | 1h |
| P2-4 | **이미지 CDN** | 홈페이지 이미지 → CDN (Cloudflare/S3) 이전 | 낮 | 2h |
| P2-5 | **API 응답 캐시 (ETag)** | 변경 없는 리소스에 304 Not Modified 반환 | 낮 | 1.5h |

### Phase P3: 장기 (대규모 운영)

| # | 항목 | 내용 | 영향 | 예상 |
|---|------|------|:----:|:----:|
| P3-1 | **읽기 전용 DB 레플리카** | 조회 쿼리를 레플리카로 분산 | 높 | 4h |
| P3-2 | **Materialized View** | 대시보드 통계용 사전 집계 뷰 (월별 매출 등) | 중 | 2h |
| P3-3 | **큐 기반 비동기 처리** | 청구 생성/XML 생성/알림 발송 → Bull Queue | 중 | 3h |
| P3-4 | **APM 모니터링** | Prometheus + Grafana (API 응답시간/에러율/DB 쿼리) | 중 | 3h |
| P3-5 | **데이터 아카이빙** | 1년 이상 진료기록 → 아카이브 테이블 이동 | 낮 | 2h |
