# 아랍어권 에디션 트랙 — 별도 화면 구성 (RTL 포함)

> 2026-09-07 · 사람 결정 2건: ① **아랍어는 별도 진행**(UI 언어 축에서 분리) ② **좌우만 뒤집은 복제가 아니라
> 별도의 화면으로 완전히 다르게 구성**한다.
> 이 문서는 그 트랙의 정본이며 **병행 에이전트로 수행 가능하도록** 소유권·규약·검증까지 명세한다.
> 상위 정본: `ui-locale-i18n.plan.md`(§8 요약·§9 팩 구조) · 자산: `ar` 팩 2,209키(DEFERRED).

## §0 이 트랙이 무엇인가 — 번역이 아니라 **에디션**

🔴 **한국 화면을 아랍어로 번역해 좌우를 뒤집는 작업이 아니다.** 아랍어권 의료기관은
업무 자체가 다르다 — 실측 근거:

| 축 | 한국(현행 화면) | 아랍어권(AE 기준) |
|---|---|---|
| 보험·수납 | 건강보험 단일 지불자 · 본인부담률 고시 · 산정특례 | **민간 보험 다수**(보험사·플랜별 사전승인) · 자비 비중 |
| 청구 | HIRA EDI · 요양기관 기호 · 급여기준 | 보험사별 클레임 규격(DHA eClaim 등) |
| 진단·수가 | KCD-8 · 상대가치점수 | ICD-10-AM/CPT 계열(관할별) |
| 규제·관할 | 복지부·심평원 단일 | **DHA·DoH·MOHAP 셋**(에미리트별 — 개원 축 실측 AE 48항목) |
| 서식 | 의료법 시행규칙 별지 서식 | 관할별 서식·언어 요건 |
| 환자 구성 | 내국인 중심 | **다국어 상주 외국인**(아랍어·영어·힌디·우르두…) |

→ 같은 화면을 번역하면 **화면에 없어야 할 것(건보·KCD·요양기관 기호)이 남고, 있어야 할 것
(보험사 선택·관할 제출처)이 없다.** 그래서 **AE 에디션 화면을 따로 만든다.**

## §1 무엇을 공유하고 무엇을 나누는가

정본이 둘로 갈라지는 것을 막는 것이 이 트랙의 최대 위험이다. 경계를 못박는다.

| 층 | 공유/분리 | 근거 |
|---|---|---|
| **데이터 모델·API** | **공유**(하나) | 환자·오더·결과는 나라가 달라도 같은 사실이다. 모델을 나누면 데이터가 갈라진다 |
| 판정 규칙·정직성 규약 | **공유** | `CLAUDE.md` 판정 규칙은 국가 무관(분모 병기·미판정≠0·기록≠적용) |
| 표시 정본 부품 | **공유**(`<T>`·`<Num>`·`KDate`·`StatusBadge`…) | 부품을 나누면 정직성 규약이 한쪽에서만 지켜진다 |
| 언어 팩 | **공유**(`ar` 팩·§9 구조) | 이미 2,209키 자산이 있다 |
| **화면 구성·동선** | **분리**(`app/(ae)/**`) | 업무가 다르다(§0) |
| 국가별 규칙(보험·청구·서식·관할) | **분리**(모듈 내 country 분기 or 전용 모듈) | 개원 축이 이미 `hospital.country` 로 KR/AE 를 가른다 |
| 용어·라벨 | 팩 + AE 전용 키 | 같은 개념이 다른 이름을 가진다 |

🔴 **기존 `app/(main)/**` 는 이 트랙에서 수정하지 않는다** — 한국·일본 사용자에게 회귀가 간다.

| 단계 | 내용 | 착수 조건 | 실행 |
|---|---|---|---|

| **R-A3** 화면 구현 | 확정된 화면을 **병행 에이전트**로 구현(§4) | R-A2 | **병렬 N기** |
| **R-A4** 국가 규칙 | 보험·청구·서식·관할 분기(모듈 내 country 축 확장 — 개원 레지스트리 선례) | 🧑A3·🧑A4 | 병렬 |

🔴 **최소 에디션부터.** 전 화면(348면)을 다시 만들지 않는다. R-A1 에서 **핵심 동선 화면만**
고르고(권고: 10~15면), 나머지는 "이 에디션에 없음"으로 정직하게 비운다. 규모가 큰 것을
인정하고 범위를 좁히는 것이 이 트랙의 성패다.

## §4 병행 에이전트 실행 설계

### 4.1 공통 규약 (전 에이전트)
- 🔴 **git 명령 금지** — 커밋은 오케스트레이터(CLI)만.
- 🔴 **shared 빌드 금지**(병렬 레이스) — 검증은 `packages/shared` 에서 `npx vitest run`.
- 🔴 **`app/(main)/**` 수정 절대 금지** — 이 트랙은 `app/(ae)/**` **신규 파일만** 만든다.
  (기존 화면을 건드리면 한국·일본 사용자에게 회귀가 간다 — 가드가 커밋 단위로 막는다.)
- 🔴 **KR 화면을 번역 복제하지 마라** — R-A1 에서 확정한 **AE 업무 설계**를 구현한다.
  KR 화면에만 있는 개념(건보 본인부담률·산정특례·요양기관 기호·KCD 전용 UI)을 옮기면 안 된다.
  설계에 없는 것을 발견하면 **만들지 말고 보고**하라(사람 결정 대상).
- 종료 조건: `tsc 0` + 소유 화면 스펙 통과 + **물리 유틸 0 실측** + 변경 파일 목록 보고.
  실패는 실패로(성공인 척 금지).

### 4.2 에디션 화면 규약
| 규약 | 내용 |
|---|---|
| 방향 | 논리 유틸만(`ms-/me-/ps-/pe-/start-/end-/text-start/text-end`) — 물리 유틸 **0건** |
| 텍스트 | `<T k="한국어원문">` — 키는 공유 팩 규약 그대로. AE 전용 개념은 새 키(`원문@AE`) |
| 수치·날짜 | 공유 정본 부품만(`<Num>`·`<KDate>`·`<Money>`·`<Term>`) — 직접 `toLocaleString` 금지 |
| 데이터 | **공유 API** 사용(모델을 새로 만들지 않는다). AE 전용 필드가 필요하면 보고 |
| 없는 기능 | "이 에디션에 없음"을 화면이 말한다 — KR 화면으로 리다이렉트하지 않는다 |
| 방향성 아이콘 | 화살표·chevron 은 `rtl:rotate-180` 또는 논리 아이콘 |
| 정직성 | 기존 판정 규칙 전부 적용(분모 병기·미판정≠0·`.catch(()=>기본값)` 금지·44px) |

### 4.4 검증 프로토콜
- 배치마다: 전체 스위트 + 에디션 가드(§5) + 로컬 build + **표본 재주입 1건**
  (에디션 화면에 물리 유틸 1개 주입 → 가드 실패 확인 → 복원).
- 🔴 **시각 검증은 사람이 한다** — 배치가 어긋났는지, 아랍어 문장이 자연스러운지는 자동 판정이 안 된다.
- 🔴 **업무 적합성 검증도 사람** — 화면이 AE 업무와 맞는지는 코드가 알 수 없다(기관 확인).

## §5 가드 (전부 재주입 역검증)

1. **에디션 화면 물리 유틸 0** — `app/(ae)/**` 에서 `ml-/mr-/pl-/pr-/left-/right-/text-left/text-right` 금지(기준선 0).
2. **기존 화면 불변** — 이 트랙 커밋이 `app/(main)/**` 를 수정하지 않는다(회귀 차단).
3. **모델 분기 금지** — `app/(ae)/**` 가 새 Prisma 모델·중복 API를 만들지 않는다(데이터 정본 하나).
4. **없는 기능 정직 표기** — 에디션 미구현 화면이 KR 화면으로 리다이렉트하지 않고 부재를 말한다.
5. **BiDi 격리 유지** — 공유 수치·날짜 부품의 `<bdi>`(R-A0 회수분 재발 금지).
6. **팩 상태 정합** — `ar` 팩이 `ACTIVE` 이면 `(ae)` 셸이 존재해야 한다(번역만 켜고 화면이 없는 상태 차단).

## §7 열린 질문 (설계 전 답이 필요)

- 한 기관이 **두 에디션을 동시에** 쓰는가(가상 국제병원처럼 내국인+외국인)? 그렇다면 사용자별
  에디션 선택인가, 환자별인가 — 화면 진입 규칙이 달라진다.
- KR 화면의 개선이 AE 에디션에 **자동 반영되지 않는다**(의도된 분리). 그 격차를 무엇으로 관측할 것인가
  — 기능 대조표를 관제 화면에 둘지.
- 공유 API 에 AE 전용 필드가 필요할 때 **모델을 늘릴지, 국가별 확장 테이블로 둘지**.

## §8 진행 기록

### R-A0 격리 — 완료(2026-09-07 · CLI 단독)

공유 표시 정본 부품의 **내용만** `<bdi>` 로 감쌌다(바깥 `<span>`·className·title·data-* 전부 불변).
🔴 **아랍어를 지원하게 된 것이 아니다** — RTL 이 붙을 때 수치·코드가 재배치되지 않도록 하는 **준비**다.

| 파일 | 적용 부품 | 비고 |
|---|---|---|
| `apps/web/src/components/ui/display.tsx` | `KDate`·`Money`·`MoneyText`·`UnitText`·`Num`·`Duration`·`StayDays`·`Ratio`(수치 분기)·`DrugName`(4분기 전부) | `<bdi` 18곳 |
| `apps/web/src/components/ui/term.tsx` | `Term` | `<bdi` 1곳 |

**적용하지 않은 것과 사유** — `PatientName`·`StaffName`(이름은 강한 방향 문자라 스스로 재배치되지 않는다·
MRN 은 인접 LTR 런과 병합) · `Unknown`·`EmptyState`·배지(`AdaptiveBadge`·`TagChip`·`InsuranceBadge`·
`CapabilityBadge`)·`Ratio` 의 '산출 불가' 분기(전부 낱말) · `<T>`(`i18n-text.tsx` — `dir="auto"` 는
**다른 일**이다. 문자열 자신의 기저 방향 판정이고, 겹쳐 쓰면 한쪽이 다른 쪽을 대신한다고 착각한다) ·
문자열 헬퍼(`durationText`·`termTextOf`·`drugNameOf`·`kdate`/`money` 스냅샷 — 마크업을 못 싣는다.
**RTL 에서는 이 자리들이 격리 사각지대다** → R-A2 에서 호출부가 JSX 부품을 쓰게 바꾸는 것이 답).

**LTR 불변 증명** — 56 케이스(부품×분기×용어모드 KO/EN/BOTH)를 변경 전후로 렌더해
`container.innerHTML`·`textContent` 를 덤프하고 대조: **textContent 차이 0**, `<bdi>` 태그만 지운
**HTML 차이 0**. 즉 DOM 델타가 격리 래퍼 **하나뿐**이고 클래스·속성·태그·텍스트는 한 글자도 안 바뀌었다.

**가드** `apps/web/test/ui/bidi-isolation.spec.tsx`(34) — ① 격리 유지 ② LTR 렌더 문자열 동결
