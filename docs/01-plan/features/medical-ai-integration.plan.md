# WeRU.B Medical AI 연동 기획서

> **Summary**: WeRU.B AI Server(qwen2.5:14b + medllama2/meditron)를 Hospital RUN HIS에 연동하여 AI 진료 지원 + CLI 형태 인터페이스 제공
>
> **Project**: Hospital RUN
> **Version**: 0.1.0
> **Author**: user
> **Date**: 2026-05-08
> **AI Server**: https://example.org/ollama (v2.29.0, 22 endpoints)

---

## 1. Overview

### 1.1 WeRU.B Medical AI 제공 기능

| API | 모델 | 설명 |
|-----|------|------|
| `/api/medical/summarize` | qwen2.5:14b | 진료 기록 → SOAP 구조화 |
| `/api/medical/analyze` | qwen2.5:14b | 증상/검사 → 감별진단 3개 + ICD-10 |
| `/api/medical/reference` | qwen2.5:14b + bge-m3 | 의학 지식 RAG 벡터 검색 |
| `/api/medical/explain` | qwen2.5:14b | 환자용 설명문 자동 생성 |
| `/api/medical/draft` | qwen2.5:14b | 의무기록 초안 (경과기록/퇴원요약/의뢰서) |
| `/api/medical/clinical/analyze` | medllama2 | 영어 임상 분석 + 한국어 번역 |
| `/api/medical/clinical/drug` | meditron | 약물 용량/금기/상호작용 |

### 1.2 연동 목표

1. **진료 워크플로우에 AI 자연스럽게 통합** — 별도 앱이 아닌 HIS 내 인라인
2. **CLI(채팅) 인터페이스** — 각 서비스 화면에서 AI 어시스턴트와 대화
3. **의사 검토 필수** — AI 생성물은 항상 초안, 의사가 확인 후 적용

## 2. Scope

### 2.1 In Scope

| ID | 기능 | 위치 | Priority |
|----|------|------|----------|
| AI-01 | **AI 진료 어시스턴트 (CLI)** | 전체 페이지 하단 고정 채팅바 | High |
| AI-02 | **SOAP 자동 구조화** | 진료 작성 페이지 | High |
| AI-03 | **감별진단 제안** | 진료 Assessment 입력 시 | High |
| AI-04 | **약물 참고 (RAG)** | 처방 입력 시 | Medium |
| AI-05 | **환자 설명문 생성** | 진료 완료 후 | Medium |
| AI-06 | **의무기록 초안** | 퇴원요약/경과기록 작성 시 | Medium |
| AI-07 | **AI 서비스 설정 (관리자)** | 관리자 설정 페이지 | Low |

### 2.2 Out of Scope

- 음성인식 (STT) → 별도 Phase
- AI 영상 판독 → 별도 Phase
- 자동 코딩 (AI가 KCD 자동 선택) → 별도 Phase

## 3. 기능 상세

### 3.1 AI-01: AI 진료 어시스턴트 (CLI 채팅바)

**모든 페이지 하단에 고정되는 AI 채팅 인터페이스**

```
┌─────────────────────────────────────────────────────────────┐
│ [페이지 콘텐츠 ...]                                          │
│                                                              │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 🤖 AI 어시스턴트                                    [▼ 접기] │
│                                                              │
│  AI: 안녕하세요, 김내과 선생님. 무엇을 도와드릴까요?            │
│                                                              │
│  You: 고혈압 환자에게 ACE 억제제와 ARB 병용 시 주의사항은?      │
│                                                              │
│  AI: ACE 억제제와 ARB 병용(이중 RAS 차단)은 일반적으로          │
│      권장되지 않습니다. 고칼륨혈증, 저혈압, 신기능 악화 위험이   │
│      증가합니다. 2023 ESC 가이드라인에서도...                   │
│      📚 참고: [메트포르민 약물정보] [고혈압 진료지침]            │
│                                                              │
│  ┌──────────────────────────────────────────── [전송] ─────┐ │
│  │ 메시지를 입력하세요...                                    │ │
│  └────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

**CLI 명령어 (슬래시 커맨드):**

| 명령어 | 기능 | 예시 |
|--------|------|------|
| `/요약` | 현재 진료 기록 SOAP 요약 | `/요약` (현재 SOAP 데이터 자동 전송) |
| `/감별` | 현재 환자 증상 기반 감별진단 | `/감별 흉통, 호흡곤란, 운동시 악화` |
| `/약물` | 약물 정보 조회 | `/약물 메트포르민 금기사항` |
| `/설명` | 환자 설명문 생성 | `/설명 고혈압 치료계획` |
| `/초안` | 의무기록 초안 | `/초안 퇴원요약` |
| `/참고` | 의학 참고자료 검색 | `/참고 당뇨 초기 약물 선택 가이드` |
| `/번역` | 영어 의학 용어 번역 | `/번역 Hashimoto thyroiditis pathogenesis` |
| `/도움` | 명령어 목록 | `/도움` |

**페이지별 컨텍스트 자동 감지:**

| 현재 페이지 | AI가 자동으로 알고 있는 정보 |
|------------|--------------------------|
| 진료 작성 (`encounter/new`) | 현재 환자 정보 + SOAP 입력 내용 + 알레르기 |
| 환자 상세 (`patients/[id]`) | 환자 기본정보 + 문제목록 + 알레르기 + 검사결과 |
| 입원 (`inpatient`) | 입원 정보 + 바이탈 + I/O |
| 수술 (`surgery/[id]`) | 수술 정보 + 마취 + 진단 |
| 검사결과 | 비정상 결과 자동 분석 |

### 3.2 AI-02: SOAP 자동 구조화

**진료 작성 페이지에서:**

```
[자유 메모 입력 영역]
"55세 남자, 3일 전부터 가슴 답답함. 빠르게 걸으면 악화. 
혈압 150/95, 심박수 88. 심전도에서 ST 하강.
트로포닌 0.08. 고혈압 10년, 당뇨 5년 병력."

             [🤖 AI SOAP 변환] 버튼 클릭
                    ↓
S: 3일 전부터 흉부 압박감. 운동 시 악화, 안정 시 호전.
   PMH: 고혈압 10년, 당뇨 5년
O: BP 150/95, HR 88, ECG ST depression V4-V6, 
   Troponin-I 0.08 ng/mL
A: 불안정 협심증 의심 (I20.0)
   고혈압 (I10), 제2형 당뇨 (E11)
P: 심장내과 협진, 관상동맥 CT
   Aspirin 100mg + Clopidogrel 75mg 시작

[SOAP에 적용] [수정 후 적용] [취소]
```

## 4. 기술 설계

### 4.1 백엔드 모듈

```
apps/api/src/modules/medical-ai/
├── medical-ai.module.ts
├── medical-ai.service.ts        // WeRU.B AI API 클라이언트
├── medical-ai.controller.ts     // HIS → AI 프록시 API
└── medical-ai.gateway.ts        // WebSocket (스트리밍 채팅용)
```

### 4.2 환경변수

```env
MEDICAL_AI_URL=https://example.org/ollama
MEDICAL_AI_KEY=CHANGE_ME
```

### 4.3 프록시 API (HIS → AI)

| HIS API | AI API | 설명 |
|---------|--------|------|
| `POST /api/v1/ai/chat` | `/api/medical/reference` | CLI 채팅 (범용) |
| `POST /api/v1/ai/summarize` | `/api/medical/summarize` | SOAP 구조화 |
| `POST /api/v1/ai/diagnose` | `/api/medical/analyze` | 감별진단 |
| `POST /api/v1/ai/drug-info` | `/api/medical/clinical/drug` | 약물 정보 |
| `POST /api/v1/ai/explain` | `/api/medical/explain` | 환자 설명문 |
| `POST /api/v1/ai/draft` | `/api/medical/draft` | 기록 초안 |
| `POST /api/v1/ai/chat/stream` | `/api/medical/summarize/stream` | 스트리밍 |
| `GET /api/v1/ai/status` | `/api/medical/knowledge/stats` | AI 상태 |

