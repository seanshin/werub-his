## 1. 현재 구현 상태

### 1.1 백엔드 API (11개)

| API | 설명 | 상태 |
|-----|------|------|
| GET /specimens | 검체 목록 (필터/페이지네이션) | ✅ |
| GET /specimens/:id | 검체 상세 | ✅ |
| POST /specimens | 검체 접수 | ✅ |
| PATCH /specimens/:id/receive | 검체 수령 확인 | ✅ |
| GET /reports/:specimenId | 판독 보고서 조회 | ✅ |
| POST /reports | 판독 보고서 작성 | ✅ |
| PATCH /reports/:id | 보고서 수정 | ✅ |
| POST /reports/:id/sign | 보고서 서명 | ✅ |
| POST /reports/:id/addendum | 추가 보고서 | ✅ |
| GET /stats | 통계 | ✅ |
| GET /patients | 환자 목록 | ✅ |

### 1.2 프론트엔드 (현재)

- 4탭: 접수 대기 / 처리 중 / 판독 완료 / 전체
- 통계 카드 4개: 접수대기/처리중/판독완료/오늘접수
- 검체 목록 테이블: 접수번호, 환자명, 검체유형, 채취부위, 우선순위, 상태, 접수일
- 검체 상세 패널 (우측): 환자 정보 + 검체 정보

### 1.3 데이터 모델

```
PathologySpecimen: 접수번호, 환자, 검체유형(BIOPSY/EXCISION/CYTOLOGY/FNA/FROZEN),
                   채취부위, 고정액, 임상정보, 우선순위, 상태
PathologyReport: 육안소견, 현미경소견, 최종진단, KCD코드,
                 IHC(면역화학), 분자검사, TNM병기, 종양등급, 절제면
```

## 2. 누락 기능 분석

### 2.1 검체 처리 워크플로우

| # | 기능 | 현재 | 필요 |
|---|------|------|------|
| W-1 | **검체 접수 폼** | API만 있음, UI 없음 | 접수 폼 (환자 선택, 검체유형, 부위, 고정액, 임상정보) |
| W-2 | **검체 수령 확인** | API만 있음, UI 없음 | 수령 버튼 + 바코드 스캔 |
| W-3 | **조직처리 단계 추적** | 상태 PROCESSING만 | 세부 단계: 고정→포매→절편→염색→마운팅 |
| W-4 | **슬라이드 관리** | 없음 | 블록번호, 슬라이드번호, 염색종류 기록 |
| W-5 | **검체 라벨/바코드** | 없음 | 바코드 생성 + 라벨 인쇄 |

### 2.2 판독 기능

| # | 기능 | 현재 | 필요 |
|---|------|------|------|
| R-1 | **판독 보고서 작성 UI** | API만 있음, UI 없음 | 판독 폼 (육안/현미경/진단/IHC/분자검사/TNM) |
| R-2 | **판독 이미지 첨부** | 없음 | 현미경 사진 업로드 (조직 소견 이미지) |
| R-3 | **판독 템플릿** | 없음 | 검체유형별 보고서 템플릿 (유방/갑상선/위/대장 등) |
| R-4 | **판독 서명 UI** | API만 있음, UI 없음 | 전자서명 + 인쇄 |
| R-5 | **추가 보고서 (Addendum)** | API만 있음, UI 없음 | 보완/수정 보고서 UI |
| R-6 | **AI 병리 진단 보조** | 없음 | 조직 이미지 AI 분석 (향후) |

### 2.3 관리 기능

| # | 기능 | 현재 | 필요 |
|---|------|------|------|
| M-1 | **TAT (Turnaround Time) 관리** | 없음 | 접수→보고 소요 시간 추적/경고 |
| M-2 | **QC (Quality Control)** | 없음 | 재검율, 진단 일치율, 오류 추적 |
| M-3 | **장비 관리** | 없음 | 현미경, 조직처리기, 면역염색기 등 장비 관리 |
| M-4 | **시약/소모품 관리** | 없음 | 염색시약, 고정액, 포매제 재고 |
| M-5 | **외부 위탁** | 없음 | 외부 병리 기관 위탁 검사 관리 |
| M-6 | **통계 대시보드** | 기본 통계만 | 검체유형별/진단별/TAT/의뢰과별 통계 |

```
┌─ 검체 접수 ────────────────────────────────────┐
│                                                  │
│  환자: [환자 검색 ▼]                             │

│  채취부위: [위 체부 전벽_________]               │

### Phase 3: 관리 기능 (M-1~M-6)

**TAT 관리:**
- 접수→보고 평균 시간 (일반: 5일, 긴급: 24h, 동결: 30분)
- TAT 초과 경고 알림
- 병목 단계 분석

**통계 대시보드 확장:**
```

## 4. 신규 API 필요

| # | API | 설명 |
|---|-----|------|
| 1 | PATCH /specimens/:id/process | 처리 단계 업데이트 (step: FIXATION→EMBEDDING→SECTIONING→STAINING→MOUNTING) |

| 7 | GET /stats/by-department | 의뢰과별 통계 |
