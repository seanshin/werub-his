## 1. 현황 분석

### 1.1 백엔드 (구현 완료 — 양호)

| API | 기능 | 상태 |
|-----|------|:---:|
| `GET /api/v1/my-codes` | 내 코드 목록 (카테고리 필터, 고정/사용빈도 정렬) | ✅ |
| `POST /api/v1/my-codes` | 코드 추가 (약물/검사, 기본 용법 설정) | ✅ |
| `PATCH /api/v1/my-codes/:id` | 수정 (별명, 기본값, 고정, 정렬) | ✅ |
| `DELETE /api/v1/my-codes/:id` | 제거 | ✅ |
| `POST /api/v1/my-codes/:id/use` | 사용 횟수 증가 | ✅ |
| `GET /api/v1/my-codes/stats` | 최다 사용 약물/검사 Top 20 | ✅ |
| `GET /api/v1/my-codes/search` | 우선순위 검색 (내 목록 > 과 카탈로그 > 전체) | ✅ |
| `GET /api/v1/dept-catalog` | 진료과 코드 카탈로그 | ✅ |

## 2. 보강 기능 설계

### 2.1 약물/검사 검색 + 추가

```
┌─ 코드 추가 ─────────────────────────────────────────────────────────┐
│                                                                      │
│  [약물 🔍 _______________] [검사 🔍 _______________]               │
│                                                                      │
│  ── 검색 결과 ──                                                    │
│  ┌──────────────────────────────────────────────────────────────┐   │
│  │  ⭐ 아스피린 100mg (ASA-100) — 내 목록                     [+] │   │
│  │  📋 아모시실린 500mg (AMX-500) — 과 카탈로그               [+] │   │
│  │     아세트아미노펜 325mg (AAP-325) — 전체                  [+] │   │
│  └──────────────────────────────────────────────────────────────┘   │
│                                                                      │
│  [+] 클릭 시 → 기본 용법 설정 모달                                 │
│                                                                      │
│  ── 기본 용법 설정 (약물) ──                                       │
│  별명: [아스피린___]  (표시명 커스텀)                                │
│  용량: [100mg____]                                                   │
│  용법: [1일 1회__▼]  경로: [경구(PO)__▼]                           │
│  기간: [30일___]                                                     │
│  ☑ 고정 (항상 상단에 표시)                                          │
│                                                                      │
│  [취소]                    [추가]                                    │
└──────────────────────────────────────────────────────────────────────┘
```

**우선순위 표시:**
- ⭐ 내 목록: 파란 배지 `MY_LIST`
- 📋 과 카탈로그: 초록 배지 `DEPT`
- 일반: 배지 없음 `ALL`

### 2.2 기본 용법 인라인 편집

```
┌─ 내 처방 목록 ──────────────────────────────────────────────────────┐
│  [전체 ▼] [약물] [검사] [영상]          [+ 코드 추가]  [과 카탈로그 가져오기] │
│                                                                      │
│  고정 │ 코드        │ 약물명        │ 기본 용법           │ 사용 │ 작업 │
│  ────────────────────────────────────────────────────────────────── │
│  📌   │ ASA-100    │ 아스피린 100mg │ 1T 1일1회 PO 30일  │ 42회 │ ✏️ 🗑  │
│  📌   │ MET-500    │ 메트포르민500  │ 1T 1일2회 PO 90일  │ 38회 │ ✏️ 🗑  │
│       │ AMX-500    │ 아모시실린500  │ 1C 1일3회 PO 7일   │ 15회 │ ✏️ 🗑  │
│       │ CBC        │ 일반혈액검사   │ —                   │ 28회 │ ✏️ 🗑  │
│       │ UA         │ 소변검사       │ —                   │ 22회 │ ✏️ 🗑  │
│                                                                      │
│  ✏️ 클릭 → 인라인 편집 (용량/용법/경로/기간 직접 수정)              │
│  📌 클릭 → 고정 토글                                                │
│  🗑 클릭 → 제거 (확인 후)                                           │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.3 나만의 처방 세트 (묶음)

```
┌─ 나의 처방 세트 ────────────────────────────────────────────────────┐
│                                                                      │
│  세트란? 여러 약물/검사를 하나의 묶음으로 저장하여                  │
│  한 번에 처방할 수 있는 기능입니다.                                  │
│                                                                      │
│  [+ 새 세트 만들기]                                                  │
│                                                                      │
│  ┌─ 고혈압 기본 세트 ──────────────────────────────────────┐       │
│  │  약물 3건:                                              │       │
│  │  • 암로디핀 5mg — 1T 1일1회 PO                          │       │
│  │  • 로사르탄 50mg — 1T 1일1회 PO                         │       │
│  │  • 아스피린 100mg — 1T 1일1회 PO                        │       │
│  │  검사 2건:                                              │       │
│  │  • CBC, BMP                                             │       │
│  │                                         [적용] [편집] [삭제] │   │
│  └──────────────────────────────────────────────────────────┘       │
│                                                                      │
│  ┌─ 당뇨 초진 세트 ────────────────────────────────────────┐       │
│  │  약물 2건 + 검사 4건                   [적용] [편집] [삭제] │   │
│  └──────────────────────────────────────────────────────────┘       │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.4 진료과 카탈로그 가져오기

```
[과 카탈로그 가져오기] 클릭
    │
    ▼
┌─ 내과 기본 처방 카탈로그 ────────────────────────────────────────┐
│                                                                  │
│  ☑ 고혈압 기본약 (5건): 암로디핀, 로사르탄, HCTZ, 아스피린, 스타틴 │
│  ☑ 당뇨 기본약 (4건): 메트포르민, 글리메피리드, 인슐린, DPP4i   │
│  ☑ 기본 검사 (8건): CBC, BMP, LFT, Lipid, HbA1c, UA, EKG, CXR │
│  ☐ 항응고제 (3건): 와파린, 리바록사반, 아픽사반                 │
│                                                                  │
│  [선택한 항목 가져오기 (17건)]                                    │
│                                                                  │
│  → 가져온 항목은 과 카탈로그의 기본 용법이 자동 설정됨           │
└──────────────────────────────────────────────────────────────────┘
```

### 2.5 처방 시 자동 반영

```
진료 화면에서 처방 검색 시:
  
  [아스피린 검색__]
       │
       ▼
  검색 결과 (우선순위):
  ┌─────────────────────────────────────────────────────┐
  │ ⭐ 아스피린 100mg (내 기본: 1T 1일1회 PO 30일)    │  ← 내 목록 1순위
  │ 📋 아스피린 100mg (과 기본: 1T 1일1회 PO 14일)    │  ← 과 카탈로그 2순위
  │    아스피린 500mg                                   │  ← 전체 3순위
  └─────────────────────────────────────────────────────┘
  
  ⭐ 선택 시 → 내 기본 용법 자동 입력 (30일/PO/1일1회)
  📋 선택 시 → 과 기본 용법 자동 입력 (14일/PO/1일1회)
```

## 3. 데이터 모델 추가

### 3.1 처방 세트 (신규)

```prisma
model DoctorPrescriptionSet {
  id          String   @id @default(uuid()) @db.Uuid
  doctorId    String   @map("doctor_id") @db.Uuid
  name        String   @db.VarChar(200)      // "고혈압 기본 세트"
  description String?  @db.Text
  category    String?  @db.VarChar(50)       // 질환 분류
  items       Json     @db.JsonB             // [{codeId, codeType, dosage, frequency, duration, route}]
  useCount    Int      @default(0) @map("use_count")
  sortOrder   Int      @default(0) @map("sort_order")
  isActive    Boolean  @default(true) @map("is_active")
  createdAt   DateTime @default(now()) @map("created_at") @db.Timestamptz()
  updatedAt   DateTime @updatedAt @map("updated_at") @db.Timestamptz()

  doctor      User     @relation("DoctorPrescriptionSets", fields: [doctorId], references: [id])

  @@index([doctorId])
  @@map("doctor_prescription_sets")
}
```

## 6. 진료 화면 연동

### 6.1 처방 검색 연동 (`encounter/new/page.tsx`)

기존 처방 검색 입력란에서 `searchCodes` API를 호출하여 우선순위 검색 결과를 표시.
내 목록 약물 선택 시 기본 용법 자동 입력.

### 6.2 처방 세트 적용 연동

진료 화면에 [세트 적용] 버튼 추가 → 세트 선택 → 세트 내 모든 약물/검사 일괄 처방.

## 7. 구현 단계

### Phase 1: 내 코드 목록 보강 (즉시)

- 약물/검사 검색 + 추가 모달 (CodeSearchModal)
- 기본 용법 인라인 편집 (DosageEditor)
- 카테고리 필터 탭
- 고정 토글 + 사용 빈도 정렬

### Phase 2: 처방 세트

- DoctorPrescriptionSet 모델 + API 5개
- 세트 CRUD UI (PrescriptionSetCard, PrescriptionSetEditor)
- 세트 적용 → 처방 일괄 추가

### Phase 3: 진료 화면 연동

- 처방 검색에 우선순위 반영
- 기본 용법 자동 입력
- [세트 적용] 버튼 추가

### Phase 4: 카탈로그 가져오기

- 과 카탈로그 탭
- 선택 가져오기 (CatalogImporter)
