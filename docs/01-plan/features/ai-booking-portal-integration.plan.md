## 2. 설계: DB 조회 기반 응답

### 접근 방식
모든 질문은 **환자 포털 API를 활용**하여 실제 데이터를 조회합니다.
`ctx.patient.id`로 환자를 식별하고, 포털 API와 동일한 쿼리를 실행합니다.

```
질문 감지 → 키워드 매칭 → DB 조회 → 응답 생성 → 포털 탭 안내
```

### 2.1 예약 확인/변경/취소

```
키워드: /내 예약|예약 확인|다음 예약|예약.*있|예약 취소|예약 변경/
DB 조회: Appointment WHERE patientId AND status='SCHEDULED' ORDER BY scheduledAt
응답:
  예약 있음 → "📅 다음 예약: 5/28(목) 오전 10:30 내과 김의사\n포털 '예약' 탭에서 변경/취소 가능"
  예약 없음 → "예약된 진료가 없습니다. 예약하시겠어요?"
```

### 2.2 진료 이력

```
키워드: /진료 기록|진료 이력|지난 진료|최근 진료|진료 내역/
DB 조회: Encounter WHERE patientId ORDER BY createdAt DESC TAKE 5
응답: "📋 최근 진료:\n• 5/20 내과 (감기)\n• 5/12 정형외과 (허리통증)\n\n포털 '진료이력' 탭에서 상세 확인"
```

### 2.3 문진표

```
키워드: /문진표|문진|미작성|작성해야/
DB 조회: QuestionnaireToken WHERE patientId AND status='SENT'
응답:
  미작성 → "📝 미작성 문진표 1건\n내원 전 작성하시면 진료가 빨라집니다.\n[작성하기 링크]"
  없음 → "현재 미작성 문진표가 없습니다."
```

### 2.4 투약/알레르기

```
키워드: /복용.*약|투약|약 목록|알레르기|부작용/
DB 조회: MedicationAdministration WHERE patientId (최근), Allergy WHERE patientId
응답: "💊 현재 복용 약물:\n• 타이레놀 500mg (1일3회)\n• 메트포르민 500mg\n\n⚠ 알레르기: 페니실린\n\n포털 '투약/알레르기' 탭에서 확인"
```

### 2.5 검사 결과

```
키워드: /검사 결과|혈액검사|피검사|검사.*나왔|검사.*확인/
DB 조회: LabResult → Order → Prescription WHERE encounter.patientId ORDER BY completedAt DESC
응답: "🔬 최근 검사 결과:\n• 5/20 CBC, 간기능 → 정상\n• 5/12 혈당 → 126mg/dL (↑)\n\n포털 '검사결과' 탭에서 상세 확인"
```

### 2.6 영상 검사

```
키워드: /영상|CT|MRI|X-ray|초음파|영상.*결과/
DB 조회: ImagingResult WHERE patientId ORDER BY reportedAt DESC
응답: "📷 최근 영상 검사:\n• 5/15 흉부 X-ray → 정상\n\n포털 '영상검사' 탭에서 확인"
```

### 2.7 진료비

```
키워드: /진료비|수납|미수납|얼마|결제|영수증|납부/
DB 조회: Billing WHERE patientId AND status IN ('PENDING','PARTIAL')
응답:
  미수납 → "💰 미수납 진료비: 45,000원 (5/20 내과)\n포털 '진료비' 탭에서 확인"
  없음 → "미수납 진료비가 없습니다."
```

### 2.8 내 정보

```
키워드: /내 정보|정보 변경|연락처|전화번호.*변경|주소.*변경/
응답: "👤 개인정보 변경은 포털 '내 정보' 탭에서 가능합니다.\n\n변경 가능 항목: 연락처, 주소, 이메일"
```

### 2.9 인증서

```
키워드: /인증서|전자서명|블록체인|인증/
응답: "🔐 전자인증서는 포털 '내 인증서' 섹션에서 발급받을 수 있습니다.\n인증서가 있으면 동의서에 법적 전자서명이 가능합니다."
```

### 2.10 기타 포털 기능

```
키워드: /포털|환자 포털|마이페이지|내 페이지/
응답: "📱 환자 포털에서 이용 가능한 기능:\n• 예약 조회/변경\n• 진료이력\n• 검사/영상 결과\n• 투약 정보\n• 진료비 확인\n• 서류 신청\n• 원격진료\n• 건강검진\n\n[포털 바로가기](/portal)"
```

## 5. 기술 고려사항

### DB 조회 시 주의
- `ctx.patient.id`가 null이면 조회 불가 → 안내 메시지
- 대량 데이터 방지: `TAKE 5~10`으로 제한
- 민감 정보(검사 수치 등): 상세는 포털에서 확인하도록 안내

### 응답 포맷
```
[아이콘] 제목
[데이터 요약 2-3줄]
포털 '[탭명]' 탭에서 상세 확인
[퀵 리플라이: 포털 이동 / 다른 질문]
```

### 안전
- 검사 결과 수치는 표시하되 해석하지 않음
- "정상/비정상 판단은 의사에게 문의" 안내
- 진료비 금액만 표시, 결제는 포털에서
