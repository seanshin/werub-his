## 2. 2차 개선 항목

### 2.1 콘텐츠 정합성 (우선순위: 높음)

#### P1. 의료진 데이터 정비
| 현재 | 개선 |
|------|------|
| "테스트신장", "테스트소화기" 등 더미 이름 | WERUBYHOSP 실제 의료진 or 적절한 한국 이름 |
| SVG 아바타만 사용 | AI 생성 프로필 이미지 or 실사 대체 |
| 29명 (기존 대학병원 규모) | WERUBYHOSP 7개 진료과에 맞는 규모 (10~15명) |

**작업**: 시드 데이터 의사 이름/부서/전문분야 교체, DoctorProfile 이미지 업데이트

#### P2. 진료과/센터 CMS 정합
| 현재 | 개선 |
|------|------|
| 진료과 22개 (대학병원) | WERUBYHOSP 7개 + α (가정의학/내과/피부/진단검사/영상/신경/병리) |
| 센터 5개(기존) + 10개(WERUBYHOSP) 혼재 | WERUBYHOSP 10개 특성화 센터로 통일 |
| 진료과 페이지 내용이 기존 대학병원 | WERUBYHOSP 진료과 설명으로 교체 |

**작업**: CMS DEPARTMENT/CENTER 시드 전면 교체, 불필요 진료과 비활성화

#### P3. 뉴스/공지 콘텐츠 WERUBYHOSP화
| 현재 | 개선 |
|------|------|
| "AI 트리아지 도입" 등 HIS 관련 뉴스 | WERUBYHOSP 실제 소식/공지 |
| "강남역" 등 서울 관련 내용 잔존 | 가상/가상시 관련 내용 |

### 2.2 hospital.example.org 미반영 기능 (우선순위: 중간)

#### P4. 건강 TV 섹션
hospital.example.org에 있는 의료 교육 영상 섹션:
```
┌─ 건강 TV ─────────────────────────────────────┐
│                                                │
│  🎬 건강 TV                                    │
│                                                │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐       │
│  │ 썸네일    │ │ 썸네일    │ │ 썸네일    │       │
│  │          │ │          │ │          │       │
│  │ 5:32     │ │ 8:15     │ │ 12:03    │       │
│  ├──────────┤ ├──────────┤ ├──────────┤       │
│  │ 고혈압의  │ │ 당뇨병   │ │ 건강검진  │       │
│  │ 이해     │ │ 관리법   │ │ 가이드   │       │
│  │ 김내과   │ │ 박내분비 │ │ 이가정   │       │
│  └──────────┘ └──────────┘ └──────────┘       │
│                                                │
│  [건강TV 더보기 →]                               │
└────────────────────────────────────────────────┘
```

**구현**: CMS에 `HEALTH_VIDEO` 카테고리 추가, YouTube/Vimeo 임베드 지원

#### P5. 뉴스레터 구독
hospital.example.org의 이메일 구독 기능:
```
┌─ 뉴스레터 ────────────────────────────────────┐
│                                                │
│  📧 병원 소식을 받아보세요                       │
│                                                │
│  [이메일 입력...          ] [구독하기]           │
│                                                │
└────────────────────────────────────────────────┘
```

**구현**: `NewsletterSubscription` 모델 + 이메일 수집 API

#### P6. 검진권 구매 / VIP 계정
hospital.example.org의 검진권 온라인 구매 시스템:
- 검진 프로그램별 검진권 구매
- VIP 계정 생성/로그인
- 검진권으로 예약

**구현**: `CheckupTicket` 모델 + 결제 연동 (PG사) — 별도 프로젝트 규모

### 2.3 UX/디자인 개선 (우선순위: 중간)

#### P7. 이미지 최적화
| 현재 | 개선 |
|------|------|
| PNG 원본 (2~4MB) | WebP 변환 + 반응형 srcset |
| 즉시 로드 | Lazy loading (Intersection Observer) |
| 고정 크기 | Next.js Image 컴포넌트 활용 |

**효과**: 페이지 로드 시간 50%+ 단축

#### P8. 모바일 UX 강화
| 항목 | 개선 |
|------|------|
| 히어로 이미지 그리드 | 모바일에서 슬라이더만 표시 (현재 구현됨) |
| 빠른 메뉴 | 모바일 하단 고정 바 (앱스러운 UX) |
| 전화 버튼 | 모바일에서 플로팅 전화 버튼 |
| 채팅 버튼 | 우하단 AI 컨시어지 플로팅 |

#### P9. 다크 모드 지원
- 시스템 설정 따르기 (`prefers-color-scheme`)
- 수동 토글 옵션
- 로고/이미지 다크모드 대응

#### P10. 애니메이션 고도화
| 현재 | 개선 |
|------|------|
| ScrollReveal (페이드인) | Framer Motion 기반 세련된 전환 |
| 정적 카운터 | 스크롤 트리거 카운터 애니메이션 |
| 없음 | 페이지 전환 트랜지션 |
