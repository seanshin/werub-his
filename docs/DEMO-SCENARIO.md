# Hospital RUN 시연 시나리오

## 시연 URL: https://his.example.org

---

## 시나리오 1: 외래 진료 전체 흐름 (5분)

### 1-1. 로그인
1. https://his.example.org → 로그인 페이지
2. **"내과 김의사"** 퀵 선택 클릭 → 로그인
3. 역할별 대시보드 확인 (의사 업무 섹션)

### 1-2. 환자 조회
1. 사이드바 **환자 관리** 클릭
2. 검색창에 "김영수" 입력 → 환자 선택
3. **개요 탭**: 최근 진료 기록, 수납 현황 확인
4. **진료 이력 탭**: 타임라인 클릭하여 SOAP 펼침
5. **처방/수납 탭**: 수납 금액, 상태 확인

### 1-3. 진료 시작
1. **"진료 시작"** 버튼 클릭
2. 환자 정보 헤더 확인 (이름, MRN, 보험)
3. **"진료 시작"** 버튼 클릭하여 진료 생성

### 1-4. SOAP 작성
- **S (주관적 증상)**: "두통이 3일 전부터 심해졌고, 혈압약을 1주일 전에 끊었습니다"
- **O (객관적 소견)**: "BP 160/100, HR 85, BT 36.5"
- **A (평가/진단)**: "본태성 고혈압 악화"
- **P (계획)**: "로사르탄 50mg 재처방, 2주 후 재진"

### 1-5. 처방 입력
1. **약 처방** 탭 → "로사르탄" 검색 → 선택
2. 용량: 50mg, 투여경로: 경구, 횟수: 1일 1회, 일수: 14일
3. **"처방 추가"** 클릭 → 토스트 알림 확인
4. **검사** 탭 → "CBC" 검색 → 선택 → 처방 추가

### 1-6. 진료 완료
1. **"서명 완료 + 수납"** 클릭
2. 성공 토스트 확인
3. 환자 상세로 자동 이동 → 진료 기록 확인

## 시나리오 2: 역할별 업무 (3분)

### 2-1. 약사 (조제)
1. 로그아웃 → **"약사 임"** 으로 로그인
2. 대시보드: 조제 대기 카운트 확인
3. **약국** 메뉴 → 대기열에서 **접수** 클릭
4. **조제 완료** → **검수 완료** 순서대로 처리

### 2-2. 검사실 (검체 접수)
1. **"검사실 문"** 으로 로그인
2. **검사실** 메뉴 → 대기 목록에서 **검체 접수** 클릭

### 2-3. 원무과 (수납)
1. **"원무과 이"** 로 로그인
2. **수납** 메뉴 → 미수납 목록 확인
3. **결제** 버튼으로 수납 처리

---

## 시나리오 3: 입원 관리 (3분)

### 3-1. 입원 접수
1. 관리자 로그인
2. **입원 환자** 메뉴 → **입원 접수** 탭
3. 환자 검색 → 병상 선택 → 식이 선택 → 접수

### 3-2. 병상 현황
1. **병상 현황** 메뉴
2. 병동별 비주얼 병상 맵 확인
3. 병상 클릭 → 상태 변경 (이용가능/사용중/정비)

---

## 시나리오 4: 관리자 기능 (3분)

### 4-1. 코드 마스터
1. **관리자 > 코드 마스터** 메뉴
2. **진단코드** 탭 → "고혈압" 검색 → KCD-8/ICD-10/ICD-11 매핑 확인
3. **수가코드** 탭 → 수가 금액, 본인부담률 확인
4. **약품코드** 탭 → 약품 검색, 제약사/단가 확인

### 4-2. 병원 현황
1. **관리자 > 병원 현황** 메뉴
2. 종합 현황 카드, 부서별 직원, 의료장비, 자재/재고 확인

### 4-3. 시설 관리
1. **관리자 > 시설 관리** 메뉴
2. 병동/병상 비주얼 맵
3. 진료실, 원무/접수, 간호 스테이션, 수술실 현황
4. 층별 배치도

### 4-4. PACS (영상)
1. https://his.example.org/pacs/app/explorer.html
2. admin/pacs1234! 로 로그인
3. 환자별 영상 스터디 확인
4. OHIF Viewer: https://his.example.org/viewer/

---

## 시나리오 5: 모바일 반응형 (1분)
1. 브라우저 창 크기를 줄이거나 모바일 기기에서 접속
2. 햄버거 메뉴 → 사이드바 슬라이드
3. 대시보드, 환자 목록 반응형 확인
