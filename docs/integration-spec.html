00 공통 규약

  • 게이트 우선 — 대부분의 연동은 config 플래그로 게이트되며 기본 비활성(시뮬/스텁) 상태에서 점진 활성화합니다.
  • 어댑터 패턴 — 외부 연동은 시뮬레이션 ↔ 실연동을 dev-simulation-registry에서 토글합니다(NHIS·Clinic·심사·SMS·이메일 등).
  • egress 보안 — 외부 호출은 공용 safeFetch/assertEgressUrl로 사설·loopback·메타데이터 IP 차단 및 리다이렉트 재검증(SSRF 방지).
  • PHI 최소화 — 외부(특히 AI) 전송 시 환자 식별정보 비식별([환자명] 후치환)·페이로드 크기 가드.
  • outbox — 이벤트 발행은 integration_outbox(timestamptz) 기반, 소비자 재-pull.

01 ERP 운영

ERP (infra-core)
진료비 책정·계산의 System of Record
역할
진료비 SoT. HIS는 진료라인을 발행하고 invoice를 소비 (D-6 인터페이스 계약)
방향
양방향 (HIS ↔ ERP)
인증
SSO(aud/jti 검증) · 웹훅 HMAC(rawBody 서명) · PII 조회는 piiReadKey 분리(폭발반경 축소)
주요 이벤트
billing.line_recorded(HIS→ERP) · invoice 소비 · sign.completed → ERP 발행 origination
전송
outbox 패턴 · nginx /erp 프록시 · SSO 토큰 핸드오프(ErpLauncher, ADMIN)
계약 원칙 (D-6)ERP가 수가·계산의 SoT입니다. HIS는 billing.line_recorded를 발행할 뿐 금액을 확정하지 않습니다. 자격 필드·상병은 payload에 동봉. 이벤트 카탈로그는 his-erp-event-catalog-v1.md.
보안 강화 (S-1/2/3)S-1 PII 조회 piiReadKey 분리 완료 · S-2 웹훅 HMAC · S-3 IDOR 방지. 통합 키는 폭발반경 최소화 방향.

02 WeRU.B 의료 AI 운영

WeRU.B — Medical AI Server
v2.121.0 · STT · 화자분리 · NER+SOAP · FHIR · Medical Law · 아바타
연동 모듈
medical-ai (HIS 측 92 AI 엔드포인트)
인증
Bearer gpuKey(sk- 키) — ai.server.gpuKey/env GPU_API_KEY. notice/DUR EP는 Bearer만 인정(X-Medical-Key 불인정)
config
ai.server.url · ai.server.apiKey · ai.server.gpuKey · ai.server.enabled(kill-switch→503) · ai.server.timeout
기능군
실시간 감별진단 · 약물대체/DUR(가격·8종 동기화) · SOAP 초안 · 검사/영상 해석 · 간호 NANDA · 응급 트리아지 재평가 · Medical Law · 아바타
PHI
비식별 [환자명] 후치환 · 100KB 페이로드 가드(400) · patient-context 감사
프록시
ollama NDJSON 스트림 병합 · Python UA 403 주의 · 장시간 작업은 비동기 잡(nginx 60s 타임아웃 회피)
앰비언트 스크라이브 (BACKLOG)녹음→STT→화자분리→SOAP 초안 파이프라인은 배선·배포 완료됐으나, STT GPU 자원(large-v3+diarize CUDA OOM)으로 대기 중. 재개 트리거는 AI팀 GPU 자원 확보. 연동 요청서 werub-scribe-integration-request-20260707.md.
정본 가이드docs/05-reference/MEDICAL_AI_INTEGRATION_v2.121.0.md

03 OpenPACS 운영

OpenPACS
DICOM 영상 — Orthanc · OHIF · FastAPI · 별도 저장소
저장소
github.com/seanshin/werub-pacs (HospitalRUN과 분리)
포트
OHIF 3001 · Orthanc 8042 · FastAPI 8001 · DICOM 4242
연동
HIS는 프론트에서 /pacs/ URL로 링크만 제공 (pacs-proxy)
nginx 경로
/pacs-api/ · /dicom-web/ · /wado · /pacs/ · /viewer/
SSO
PACS SSO aud=pacs 분리 · PatientID 매칭
수정 금지docker-compose.yml의 orthanc/ohif/backend, 위 nginx 경로, PostgreSQL openpacs DB는 수정·삭제 금지. hospital/secret DB 비밀번호는 OpenPACS와 공유하므로 변경 금지. 전체 docker compose restart 금지 — 개별 지정.

04 sign — 전자서명 운영 (EXTERNAL)

sign (외부 전자서명 서비스)
CMS/PAdES 서명코어 · HSM 키수탁
연동 모듈
sign-integration · document-sign
모드
sign.mode = EXTERNAL 풀전환 운영(v3.85~) · 오더 서명 로그(his-orders)·거버넌스 의사록/의결 봉인(his-governance) 해시체인+TSA 앵커
현행 상태
운영 — CPOE 5행위 sign 봉인·판독의 SSO(aud=sign)·PACS aud=pacs 분리·audit-events 체인 verify(valid) 실측
키 수탁
HIS는 인증서 개인키 미보관. HSM 키 수탁(KeyCustodyProvider 추상화) · 자체발급 폐지 방향(selfIssuanceEnabled=false 목표)
판독의 SSO
aud=sign · JWKS RS256
e-sign #6
sign.completed → ERP 발행 · 완료본 토큰 다운로드(HMAC·24h) · 다자서명 relay
봉인 스트림오더=his-orders · 위원회 의사록/의결=his-governance(v3.89·sha256만 전송·PHI 미전송). HSM 키 수탁·자체발급 폐지는 법무 게이트 지속.
