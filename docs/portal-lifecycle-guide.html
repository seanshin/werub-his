환자 포털 생애주기 시스템

환자의 병원 이용 상태에 따라 포털이 자동으로 최적화된 화면을 제공합니다

Hospital RUN v3.2.0 — Patient Portal Lifecycle v1.1

1. 개요 — 왜 필요한가?

기존 환자 포털은 외래 환자 중심으로 설계되어, 입원 환자가 접속해도 동일한 화면을 보게 됩니다.
생애주기 시스템은 HIS(병원정보시스템)에서 접수/입원/퇴원 이벤트가 발생하면, 포털 화면이 자동으로 전환됩니다.

2. Phase별 상세 설명

각 Phase에서 환자가 처한 상황, 심리, 포털이 보여주는 화면을 설명합니다.

🏠
Phase ① 원외 건강관리
IDLE — 병원 방문 예정 없음
병원 밖에서 일상생활. 만성질환 관리, 복용약 체크, 건강 추이 확인에 집중.

환자 심리

  • 내 건강 상태가 괜찮은 건지 궁금하다
  • 약을 빼먹지 않고 잘 먹고 있는지 확인하고 싶다
  • 지난 검사 결과가 어떤 의미인지 알고 싶다

포털 화면

  • AI 건강 점수 (원형 게이지, 87점)
  • 복용약 체크리스트 + 주간 복용률
  • 자가 건강 기록 (혈압/혈당/체중)
  • 검사 추이 차트 (6개월)
  • 예방 검진 권장 카드
시나리오

60세 당뇨 환자 박씨. 매일 아침 포털에서 혈당을 기록하고, 메트포르민 복용 체크를 한다. AI가 "이번 주 혈당 평균이 130mg/dL로, 목표(120)보다 높습니다"라고 조언한다. 6개월간의 혈당 추이 그래프에서 점진적 개선을 확인한다.

📋
Phase ② 방문 전 준비
PRE_VISIT — 예약일 D-7 ~ D-0
예약일이 7일 이내. 문진표, 동의서, 금식 안내 등 사전 준비에 집중.

환자 심리

  • 뭘 준비해 가야 하지?
  • 금식해야 하나? 약은 먹어도 되나?
  • 병원 어디로 가야 하지?

포털 화면

  • 방문 준비 체크리스트 (프로그레스 바)
  • 금식/복용 주의사항 카드
  • 병원 길찾기 + 주차 안내
  • 자동 알림: D-7 문진표, D-1 금식
시나리오

45세 직장인 이씨. 내과 정기 진료가 이틀 후. 포털이 "D-2: 문진표 미작성, 금식 검사 있음"을 알린다. 퇴근 후 문진표를 작성하고, 내일 자정부터 금식임을 확인한다. D-0 아침, "오늘 09:30 내과, 본관 3층 302호" 알림을 받는다.

🏥
Phase ③ 당일 외래
OUTPATIENT_TODAY — 접수 ~ 수납
병원 도착 후 접수/대기/진료/수납 과정. 실시간 대기 정보가 핵심.

환자 심리

  • 내 순서가 언제 오지?
  • 얼마나 기다려야 하지?
  • 진료 끝나면 뭘 해야 하지?

포털 화면

  • 진료 여정 타임라인 (접수→대기→진료→수납)
  • 실시간 대기 번호 + 풀스크린 대기 화면
  • 검사 순서 + 위치 안내
  • 처방전 약국 전송
시나리오

이씨가 병원에 도착하여 접수. 포털 홈이 "오늘의 진료 여정" 카드로 자동 전환. "대기 번호 127 · 앞 3명 · 약 15분" — 풀스크린 대기 화면을 켜놓고 기다린다. 진료 후 "혈액검사(2층) → 수납(1층)" 순서 안내가 나타난다.

🛏️
Phase ④⑤ 입원 전 준비 + 입원 중
PRE_ADMISSION + INPATIENT — 가장 중요한 단계
입원 결정 ~ 퇴원 전까지. 매일 회진, 투약, 검사, 식사가 반복되는 일상.

환자 심리

  • 오늘 무슨 검사가 있지? 회진은 언제?
  • 지금 맞고 있는 약이 뭐지?
  • 점심 메뉴가 뭐지? 바꿀 수 있나?
  • 의사 선생님이 뭐라고 하셨지?
  • 입원비가 지금까지 얼마나 나왔지?

포털 화면

  • 입원 현황 Hero (병동/호실/주치의/바이탈)
  • 오늘 일정 타임라인 (시간대별)
  • 투약 현황 MAR (투여 완료/예정)
  • 식단 카드 + 변경 요청
  • 회진 기록 요약
  • 중간 정산 현황
  • 간호사 호출 버튼
시나리오 — 입원 3일차 하루

07:00 포털에 "오늘 일정" 갱신 — 08:00 투약, 09:00 혈액검사, 10:30 회진, 14:00 물리치료
08:10 투약 카드 "메트포르민 500mg 투여 완료" 표시
10:45 회진 기록 등장 — "혈당 안정. 내일 재검사 후 퇴원 여부 결정"
12:00 식단 카드 "점심 — 밥 + 된장찌개 (당뇨식)" → 변경 요청 가능
15:00 검사 결과 "혈당 108 (정상)" 카드 도착
17:00 보호자에게 "오늘 상태 공유" 링크 전송

🎉
Phase ⑥ 퇴원 준비
PRE_DISCHARGE — 퇴원 요약서 서명 후
퇴원 결정 후 퇴원 당일까지. 퇴원약, 주의사항, 다음 예약에 집중.

환자 심리

  • 퇴원하면 약은 뭘 먹어야 하지?
  • 집에서 주의할 점이 뭐지?
  • 다음에 언제 병원에 와야 하지?
  • 보험 청구는 어떻게?

포털 화면

  • 퇴원 체크리스트 (약 수령→예약→수납→서류)
  • 퇴원 약 목록 + 신규 약 강조 + 복용법
  • 퇴원 후 주의사항 (식이/운동/응급 증상)
  • 다음 외래 예약 안내
  • 만족도 조사
💜
Phase ⑦⑧ 퇴원 후 사후 관리
POST_DISCHARGE — D+1 ~ D+30
자택 회복 중. 복약 순응, 추적 검사, 재입원 예방이 핵심.

환자 심리

  • 이 증상은 정상인 건가?
  • 약을 제대로 먹고 있는지 확인하고 싶다
  • 추적 검사 날짜가 언제였지?

포털 화면

  • 퇴원 후 D+N 배너
  • 복용 체크 + 주간 복용률
  • 회복 추적 그래프 (입원 시 ↔ 현재)
  • 추적 관찰 캘린더
  • 응급 증상 안내 + 주치의 메시지
  • 퇴원 서류 다운로드
자동 알림 타임라인

D+1 "퇴원 약 복용 시작하셨나요?" + 복용법 안내
D+3 복용률 70% 미만 시 리마인더
D+7 회복 상태 확인 + 자가 기록 독려
D+14 추적 검사 리마인더
D+30 사후 관리 종료 → IDLE 복귀 (만성질환은 지속)

4. HIS → 포털 상태 전환 트리거

HIS에서 이벤트가 발생하면 포털 화면이 자동으로 전환됩니다. 환자는 전환을 의식하지 않습니다.

HIS 이벤트 트리거 포털 전환 환자에게 보이는 변화
예약 D-7 자동 IDLE → PRE_VISIT 방문 준비 체크리스트 + D-day 카운트
접수(Reception) 생성 HIS PRE_VISIT → OUTPATIENT 진료 여정 타임라인 + 대기 번호
입원 확정 HIS → INPATIENT 입원 현황 Hero + 오늘 일정 + 투약
회진 기록 등록 HIS INPATIENT (갱신) "회진 기록이 등록되었습니다" 카드 등장
퇴원 요약서 서명 HIS INPATIENT → PRE_DISCHARGE 퇴원 체크리스트 + 퇴원약 + 주의사항
퇴원 확정 HIS → POST_DISCHARGE 퇴원 D+N 배너 + 복약 관리 + 추적 일정
30일 경과 자동 POST_DISCHARGE → IDLE 건강 점수 + 복용 체크 (일상 복귀)

5. Phase별 3탭 동작

3탭(홈/내건강/더보기) 구조는 동일하지만, 홈 탭의 카드 구성이 Phase에 따라 바뀝니다.

Phase홈 탭내 건강 탭더보기 탭
IDLE건강 점수, 복용 체크, 자가 기록검사 추이, 복용약, 예방접종동일
PRE_VISIT준비 체크리스트, 금식 안내동일동일
OUTPATIENT진료 여정, 대기 번호, To-Do동일동일
INPATIENT입원 현황, 일정, 투약, 식단, 회진+ 바이탈 추이+ 간호사 호출
PRE_DISCHARGE퇴원 체크리스트, 퇴원약, 주의사항동일+ 퇴원 서류
POST_DISCHARGE복용 체크, 회복 추적, 응급 안내+ 회복 비교+ 보험 청구

6. 전환 UX 5원칙

자동 전환

HIS 이벤트 발생 시 포털 홈이 자동 갱신. 환자가 새로고침할 필요 없음.

소프트 알림

카드 애니메이션(fadeInUp) + 토스트 메시지로 부드럽게 안내.

이전 정보 보존

입원 중에도 "내 건강" 탭에서 외래 검사 결과 조회 가능.

점진적 공개

필요한 정보만 우선 표시. 탭하면 상세 확장.

이중 안전장치

자동 전환 + 1분 폴링 + 풀다운 새로고침 지원.
