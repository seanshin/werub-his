# VoiceEMR 파일럿 프로토콜 · 평가 설계

- **작성일**: 2026-07-29
- **상위**: `voice-emr-expansion.plan.md` §10·§11·§14(G7)
- **원칙**: 파일럿은 **측정이 아니라 판정** — 사전 정의한 임계로 각 티어의 승격/중단을 결정한다(§14 G7). 환자 안전 지표는 **0 목표**.

## 1. 목적·범위
- **가설**: 음성으로 조회·활력·구술·오더의 **입력 시간을 단축**하되 **오류·안전사고 없이** 가능한가.
- **범위**: 티어 순차(T0→T1→T2→T3). 각 티어는 **독립 게이트·독립 판정**. config OFF·`pilotUserIds` 소수(2~3 진료실·§용량 노트).

## 2. 단계별 파일럿

| 단계 | 티어 | 참여 | 기간(예) | 게이트 |
|---|---|---|---|---|
| PA-0 | **T0 조회** | 자원 의사 2~3 | 2주 | `voiceEmr.enabled` ON·write OFF |
| PA-1 | **T1 활력** | 동일 | 2주 | `write.enabled` ON |
| PA-2 | **T2 구술** | 동일 | 3주 | `dictate.enabled` ON(GPU·Q6 후) |
| PA-3 | **T3 오더** | 동일+약제/임상 승인 | 4주 | `order.enabled` ON(BLOCK→WARN 단계) |

- 각 단계 **성공 판정 후 다음 단계 게이트 오픈**. 실패 시 해당 티어 비활성·원인 교정 후 재개.

## 3. 평가 지표 (§11 확장·임계 명시)

### 3.1 안전 (🔴 0 목표 — 미달 시 즉시 중단)
| 지표 | 정의 | 임계 |
|---|---|---|
| **오확자 근접사고** | 다른 환자 차트에 입력 시도(확인 카드서 차단 포함) | **0** |
| **음성 자동서명** | 확인 없이 서명·확정 발생 | **0**(계약 테스트로 이미 차단) |
| **오더 오확정** | 잘못된 약/용량이 DRAFT 확정 | **0**(확인 취소는 정상) |
| **전사 누락 미인지** | `dropped_s>0`인데 경고 없이 서명 | **0**(G5 배지로 차단) |

### 3.2 정확도 (승격 임계)
| 지표 | 정의 | 승격 임계(예) |
|---|---|---|
| intent 매칭률 | 발화 중 올바른 intent 판정 비율 | ≥ 95% |
| **오더 read-back 취소율** | 오더 확인 카드에서 취소된 비율(오인식 지표) | **< 10%**(초과 시 order mode 자동 비활성·G7) |
| 수치 정규화 정확도 | 활력 값 정규화 정오 | ≥ 98% |
| n-best top-1 채택률 | 약/검사 후보 1순위 채택 비율 | 참고(바이어싱 튜닝) |
| STT 용어 정확도 | 약명·검사명 인식(바이어싱 전/후) | Q3 정량화 연동 |

### 3.3 효율·수용성
| 지표 | 정의 |
|---|---|
| 입력 시간 단축 | 음성 vs 키보드 동일 작업 소요(대조) |
| warm 콜드 히트율 | 첫 청크 18s 콜드 발생 비율(운영 규칙 준수 신호) |
| 키보드 폴백률 | 음성 포기→키보드 전환 비율(수용성) |
| SUS/만족도 | 참여 의사 설문(주차별) |

### 3.4 인프라·연동
- 청크 지연 분포·실패/재전송율·동시 세션 실측(용량 노트 갱신)·GPU 콜드/OOM·`dropped_s` 발생률.

## 4. 데이터 수집 (감사 기반)
- `VoiceCommandLog`(intent·slots·nbest·confirmedByUser·droppedS·confidence)에서 집계 → `/admin/ai-settings` 대시보드.
- **PHI 비수집**: 지표는 발화 텍스트 원문 아닌 **판정 결과·통계**. 오분석용 표본은 동의·비식별 후.

## 5. 롤백·킬 트리거 (자동/수동)
- **자동**: 오더 취소율 임계 초과 → `order.enabled` 자동 OFF. `ai.server.enabled` OFF(kill-switch)면 전 티어 503→키보드.
- **수동**: 안전 지표 1건이라도 발생 → 해당 티어 즉시 OFF·근본원인 분석(RCA).

## 6. 종료·확대 기준
- **파일럿 성공** = 3.1 전 0 + 3.2 승격 임계 충족 + 3.3 효율 개선(입력 시간 단축) + 참여 의사 확대 동의.
- **확대**: 동시 진료실 4~5 초과 예상 시 **GPU 증설 선결**(용량 노트). 진료과 확장은 명령어 사전(§lexicon)·개인화 시드 준비 후.

## 7. 사람·외부 게이트
- **임상 승인**: T3 오더 음성확정 워크플로·고위험 2단 대상(약제위·의무기록).
- **법무/IRB**: 진료 중 캡처 동의·실녹음 표본(정확도 정량화용).
- **WeRU.B**: Q4~Q8·Q12(수사)·Q13(화자 게이팅) 회신이 T1~T3 설계 선결.

> 이 프로토콜은 **판정 기준의 사전 고정**이 핵심이다. 지표·임계는 파일럿 착수 전 임상과 합의해 확정(예시값은 출발점).
